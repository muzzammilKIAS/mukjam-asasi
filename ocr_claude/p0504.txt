@رت
§ر ت ت
رَتَّ (رَتِتَ) يَرُتُّ رَتَّةً ورَتَتًا أَرَتُّ : ــ الشخصُ : كان في لسانه رُتَّةٌ (عُجْمَةٌ أو لثغة).
أَرَتُّ مؤ رَتَّاءُ جمعهما رُتٌّ : ألثغ : «هذا الشابُّ لا يصلح مدرسا لأنه أرتُّ».
رَتٌّ : مص رَتَّ.
رَتَّةٌ : مص رَتَّ.
رُتَّةٌ : ١ عُجْمَةٌ في اللسان، ٢ لُثْغَةٌ أو حُبْسَةٌ في اللسان.
§ر ت ج
رَتَجَ يَرْتُجُ رَتْجًا : ــ البابَ : أغلقه إغلاقا محكما.
رَتِجَ يرتج رَتَجًا : استغلق عليه الكلام.
أُرْتِجَ يُرْتَجُ إِرْتَاجًا : ــ الحارسُ البابَ : رَتَجَهُ ◆ أُرْتِجَ عليه : استغلق الكلام عليه.
إِرْتَاجٌ : مص أُرْتِجَ.
رِتَاجٌ ج رُتُجٌ : الباب (قيل العظيم، وقيل المغلق) : «كانت الجَرَادُ تأكُلُ مَسامِيرَ رُتُجِهِمْ» [حديث].
رَتْجٌ : مص رَتَجَ.
مِرْتَاجٌ ج مَرَاتِيجُ : ما يُغْلَقُ به البابُ (مِغْلاق ــ تِرْباس) : «أَحْكِمْ غَلْقَ البابِ بالمرتاج».
§ر ت ع
رَتَعَ يَرْتَعُ رَتْعًا ورُتُوعًا : ــ وا في المكان : أقاموا وتنعموا وأكلوا فيه وشربوا ماشاءوا في خِصْبٍ وسعة : ﴿أَرْسِلْهُ مَعَنَا غَدًا يَرْتَعْ ويَلْعَبْ﴾ [قرآن].
أَرْتَعَ يُرْتِعُ إِرْتَاعًا : ١ ــ المكانُ : أَشْبَعَ الراعية، ٢ ــ الراعي إبِلَهُ : جعلها تَرْتَعُ.
إِرْتَاعٌ : مص أَرْتَعَ.
رَتْعٌ : مص رَتَعَ.
رُتُوعٌ : مص رَتَعَ.
مَرْتَعٌ ج مَرَاتِعُ، اسم مكان من رَتَعَ : موضعٌ تَرْتَعُ فيه الماشيةُ أو الناسُ..
§ر ت ق
رَتَقَ يَرْتُق / يرتِق رَتْقا : ــ الراتقُ الشيءَ : سَدَّهُ أو لَحَمَهُ، عكس فَتَقَهُ «رَتَقَ القميص» ◆ رَتَقَ فَتْقَهُمْ : أصلح ذات بينهم.
رَتْقٌ : ١ مص رَتَقَ، وقد يستعمل صفة بمعنى مرتوق فيستوي فيه المفرد والمثنى والجمع والمذكر والمؤنث : ﴿أَوَلَمْ يَرَ الذِينَ كَفَرُوا أَنَّ السَّمَواتِ والأَرْضَ كانتا رَتْقًا فَفَتَقْنَاهُمَا﴾ [قرآن]، ٢ انسداد خِلْقي أو مرضي لمرٌ أو تجويف.
§ر ت ل
رَتِلَ يَرْتَلُ رَتَلًا : انتظم وحَسُن تأليفه : رَتِلَ الكلام أو الأسنان.
رَتَّلَ يُرَتِّلُ تَرْتِيلا : ١ ــ القارىءُ القرآنَ، جَوَّدَ تلاوته : ﴿وَرَتِّلِ القرآنَ تَرْتِيلًا﴾ [قرآن] ◆ رَتِّلْ على مسامعكم : تعبير إذاعي يَتْبَعُ قراءة القرآن، المُصْحَفُ المُرَتَّلُ : القرآن المجوَّد بدون تَغَنٍّ أو تلحين، ٢ ــ الكلامَ : أحسن تأليفه.
تَرْتِيلٌ : مص رَتَّلَ «كان الشيخ حسن الترتيل للقرآن».
تَرْتِيلَةٌ ج تَرْتِيلاتٌ وتَرَاتِيلُ : ١ اسم المرة من الترتيل، ٢ أنشودة تتلى مُنَغَّمَةً عند المسيحيين في الكنيسة.
رَتَلٌ ج أَرْتَالٌ : جماعة من الخيل أو السيارات... يتبع بعضها بعضا : «تجمعت أرتال السيارات في نقطة الحدود انتظارا لعبورها».
رُتَيْلاء : ضَرْبٌ من العناكب.
§ر ث ث
رَثَّ (رَثِثْتُ / رَثَثْتُ) يَرُثُّ / يَرِثُّ / يَرَثُّ رَثَاثَةً : ــ الشيءُ : بَلِيَ «رث الثوب»، «رث الحبل»، ويقال كذلك : «رثتْ هيئة الرجل» إذا كان لباسه رثا.
أَرَثَّ يُرِثُّ إِرْثَاثًا : ــ الشيءُ : رَثَّ.
إِرْثَاثٌ : مص أَرَثَّ.
رَثَاثَةٌ : مص رَثَّ ◆ في هذا الخبر رَثَاثَةٌ ورَكَاكَةٌ : مشكوك في صحته.
