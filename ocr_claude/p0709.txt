مَشُورَةٌ : ماينصح به من رأي : «عليك بالمشورة في كل أمورك».
مُشِيرٌ : أعلى رتبة عسكرية.
§ش و س
أَشْوَسُ مؤ شوساء جمعهما شُوسٌ وأشاوس : جريء شجاع «رجل أشوس».
§ش و ش
شَوَّشَ يشوش تشويشا : ــ عليه الأمْرَ : خلطه ولبسه عليه.
تَشَوَّشَ يَتَشَوَّشُ تَشَوُّشًا : ــ عليه الأمْرُ : اختلط والتبس.
تَشَوُّشٌ : مص تَشَوَّشَ.
تَشْوِيشٌ : مص شَوَّشَ.
شَاش¹ : نسيجٌ رقيق من القطن تضمد به الجراح ونحوها، ويستخدم كذلك للفّ العمامة أو كغطاء للرأس أو الوجه، القطعة منه شاشة ◆ الشاشة : السينما الشاشة الصغيرة : التلفزيون.
شاش² : الـ ــ : مدينة في بلاد ما وراء النهر من أعمال سمرقند.
شُوشَة : ذؤابة أعلى الرأس (عامية).
مُشَوَّشٌ : مختلط غير مرتب «كلام مُشوَّش» ◆ لَفٌّ ونَشْرٌ مشوش [في البلاغة] : إيجاز ثم تفصيل على غير ترتيب الأول.
§ش و ص
شَوِصَ يَشْوَصُ شَوَصًا فهو أشوص : ــ ت العينِ : اضطرب جفناها.
أشوص مؤ شوصاء : من يضطرب جفناه.
§ش و ط
شَاطَ يَشُوطُ شَوْطًا شائِطٌ مَشُوطٌ : ١ ــ الفرسُ : جرى إلى غايته، ٢ ــ الكرةَ : قذفها برجله.
شَوْطٌ : ١ مص شاط، ٢ ج أَشْوَاطٌ : الجزء من كلِّ عمل «قطع شَوْطًا كبيرا في عمله».
§ش و ظ
شُوَاظٌ / شِوَاظٌ : وَهَجُ الحَرِّ : ﴿يُرْسَلُ عَلَيْكُمَا شُوَاظٌ مِنْ نارٍ ونُحاسٌ فلا تَنْتَصِرانِ﴾ [قرآن].
§ش و ف
شَافَ يَشُوفُ شَوْفًا شائِفٌ : ــ الرجلُ : صعد مكانا مرتفعا ونظر.
تَشَوَّفَ يَتَشَوَّفُ تَشَوُّفًا : ــ إلى فلان : تطلع إلى رؤيته واشتاق.
تَشَوُّفٌ : مص تَشَوَّفَ.
شَوْفٌ : مص شَافَ.
§ش و ق
شَاقَ يَشُوقُ شَوْقًا شائِقٌ مَشُوقٌ : ــ ته رُؤْيَتُهُ : هاجته وحَرَّكَتْ نَفْسَه.
شَوَّقَ يُشَوِّقُ تَشْوِيقًا : ــ ه فيه / إليه : رَغَّبَهُ فيه وحَبَّبَهُ إليه.
تَشَوَّقَ يَتَشَوَّقُ تَشَوُّقًا : ــ إلى الشيء : اشتدَّ شَوْقُهُ إليه.
اِشْتَاقَ يَشْتَاقُ اشْتِيَاقًا : ــ إليه : رَغِبَتْ نَفْسُهُ فيه.
اِشْتِيَاقٌ : مص اشْتَاقَ.
تَشَوُّقٌ : مص تَشَوَّقَ.
تَشْوِيقٌ : مص شَوَّقَ.
شَائِقٌ : يَشُوقُ الإنسانَ بجماله وحسنه «كلامك شائق».
شَوْقٌ : ١ مص شَاقَ «تحرّق شوقا إلى رؤيته»، ٢ ج أَشْوَاقٌ : نُزُوعُ النَّفْسِ إلى الشيء «بَلَغَتْ مِنِّي الأَشْوَاقُ».
شَيِّقٌ : ١ شائق «كَلَامُكَ شَيِّقٌ»، ٢ مَشُوقٌ «أنا شَيِّقٌ إلى عذب حديثك».
شَوْقِي، أحمد (١٢٨٥ ــ ١٣٥١ هـ / ١٨٦٨ ــ ١٩٣٢ م) : شاعر مصري من أشهر شعراء عصره، لقب بأمير الشعراء. له ديوان «الشوقيات»، وعدة مسرحيات شعرية منها «مصرع كليوباترا»، «مجنون ليلى».
