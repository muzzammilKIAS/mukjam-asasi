@مناهزة
مُنَاهَزَةٌ : مص نَاهَزَ.
نَهْزٌ : مص نَهَزَ.
نُهْزَةٌ ج نُهَزٌ : فُرْصَة ◆ هُوَ نُهْزَةُ المُخْتَلِسِ : صَيْدٌ لِكُلِّ أَحَدٍ.
§ن ه ش
نَهَشَ يَنْهَشُ نَهْشًا فهو ناهش : ١ ــ الشَّيْءَ : تَنَاوَلَه بِفَمِه لِيَعَضَّهُ «نَهَشَهُ الكَلْبُ»، ٢ ــ تِ الحَيَّةُ الشَّخصَ : لَسَعَتْهُ ◆ نَهَشَ عِرْضَهُ : اغْتَابَهُ نَهَشَهُ الدَّهْرُ : أَوْقَعَهُ في الحَاجَةِ.
مَنْهُوشٌ ج ـون : قَلِيلُ اللَّحْمِ خَفِيفُه.
نَهْشٌ : ١ مص نَهَشَ، ٢ قلة لحم الفخذين ◆ نَهْشُ اليدين : خفيف اليدين في الحركة قليل اللحم عليهما.
§ن ه ض
نَهَضَ يَنْهَضُ نَهْضًا ونُهُوضًا فهو ناهض : ١ ــ الشَّخصُ : قام يَقِظًا نَشيطا «نَهَضَ قَائِمًا»، ٢ ــ النَّبْتُ : اسْتَوى، ٣ ــ لَهُ : قامَ وتَحَرَّكَ إليهِ مُسرِعا «نَهَضَ لِلأمِيرِ»، ٤ ــ إلى العَدُوِّ : أسرع إلى مُلَاقاتِه، ٥ ــ بالأمرِ : قام بِهِ وتَحَمَّلَهُ «نَهَضَ بالمسْؤُولِيَّةِ».
نَاهَضَ يُنَاهِضُ مُنَاهَضَةً : ــ الشَّخصَ : قَاوَمَهُ «نَاهَضَ خَصْمَهُ».
أَنْهَضَ يُنْهِضُ إِنْهَاضًا : ١ ــ هُ : حَرَّكَه للنُّهُوضِ وَأَقَامَه «أَنْهَضَ الدَّابَّةَ»، «أَنْهَضَ النَّائِمَ»، ٢ ــ الشَّخصَ للأَمْرِ : أَقَامَهُ له وعَهِدَ إليه بِه.
تَنَاهَضَ يَتَنَاهَضُ تَنَاهُضًا : ــ القَوْمُ : أَسْرَعَ كلُّ فريقٍ إلى مُقَاوَمَةِ خَصْمِهِ «تَنَاهَضَ القَوْمُ في الحَرْبِ».
اِسْتَنْهَضَ يَسْتَنْهِضُ اسْتِنْهَاضًا : ــ الشَّخصَ للأَمْرِ : دَعَاهُ إلى سُرْعَةِ القِيَامِ بِهِ «استنهض الكَسُولَ»، «استنهَضَ عُمَّالَهُ»، «استنهض الهِمَمَ».
اِسْتِنْهَاضٌ : مص اسْتَنْهَضَ.
إِنْهَاضٌ : مص أَنْهَضَ.
تَنَاهُضٌ : مص تَنَاهَضَ.
مُنَاهِضٌ ج ـون : مُعارِضٌ «كَثُرَ مُنَاهِضُو الحِزْبِ الحَاكِمِ».
مُنَاهَضَةٌ : مص نَاهَضَ.
نَاهِضٌ : ١ اسم فاعل من نَهَضَ، ٢ ج نَواهِضُ : فَرْخُ الطَّائِرِ الذي قَدَرَ على الطَّيَرَانِ، ٣ المكانُ المُرْتَفِع، ٤ ج نُهَّضٌ : النَشيطُ المَاضِي في عَمَلِه «شَبَابٌ نَاهِضٌ»، «عُمَّالٌ نُهَّضٌ» ◆ دليلٌ نَاهِضٌ : وَاضِحٌ بَيِّنٌ.
نَاهِضَةٌ : ١ مؤ نَاهِضٌ «فتاةٌ نَشِيطةٌ ناهِضَةٌ»، ٢ ج نَوَاهِضُ : ــ الشَّخصِ : بَنُو أبِيهِ الذِينَ يَغْضَبُون له ويَهُبُّون لِمَعُونَتِه، ٣ خَدَمُهُ القائِمونَ بِأَمْرِهِ.
نَهْضٌ : مص نَهَضَ.
نَهْضَةٌ ج نَهَضَاتٌ : ١ مَرَّةٌ من نَهَضَ، ٢ طَاقَةٌ وقُوَّةٌ، ٣ وَثْبَةٌ في سَبِيلِ التَّقَدُّمِ الاجتِماعِي والفِكْرِيِّ وغيْرِهما «عصْرُ النَّهْضَةِ العَرِيَّةِ في القَرنِ التَّاسعِ عَشَرَ»، «النَّهْضَةُ القَوْمِيَّةُ»، «نهضة أدبية»، «نهضة فنية» ◆ كان من فلان نَهْضَةً إلى كذا : حَرَكَةٌ.
نُهُوضٌ : مص نَهَضَ.
§ن ه ق
نَهَقَ يَنْهَقُ نَهْقًا ونَهِيقًا فهو ناهق : ــ الحِمارُ : صَوَّتَ.
نَهْقٌ : مص نَهَقَ.
نَهَقٌ : عُشْب من الفَصِيلة الصَّلِيبِيَّةِ يُعْرَف بالجِرْجِير البَرِّي.
نَهِيقٌ : مص نَهَقَ.
§ن ه ك
نَهَكَ يَنْهَكُ نَهْكًا ونَهَاكَةً فهو ناهِك : ١ ــ ه الأمْرُ : جَهَدَهُ وغَلَبَه «نَهَكَهُ العمل»، «نَهَكَتْهُ الحُمَّى»، ٢ ــ الشيءَ : بالغ فيه «نَهَكَ الضرعَ»، «نَهَكَ الثوبَ» ◆ نَهَكَ عِرْضَ فلان : أَقْذَعَ في شَتْمِه.
أَنْهَكَ يُنْهِكُ إِنْهَاكًا : ــ هُ المَرَضُ أو العَمَلُ : أَتْعَبَه
