@عـاز
§ع و ز
عاز يَعوزُ عَوْزًا عائِزٌ معوُزٌّ : ــ الشيءَ : لم يجده وهو محتاج إليه.
عَوِزَ يَعْوَزُ عَوَزًا أَعْوَزُ : ١ ــ الشخصُ : احتاجَ، ضاق حاله، ٢ ــ الشيءُ : لم يوجد مع الحاجة إليه.
أَعْوَزَ يُعْوِزُ إِعْوَازًا : ١ عَوِزَ «أصبح مُعْوِزًا بعد أن احْتَرَقَ حانوتُه»، ٢ ــ ه : الشيءُ : لم يجده مع احتياجاته إليه «أعوزته الشّجاعةُ»، ٣ ــ ه : الدهرُ : أدخل عليه العَوَز.
إِعْوَازٌ : مص أَعْوَزَ.
عَوَزٌ : ١ مص عَوِزَ، ٢ الحاجة، ضيق الحال «دَفَعَهُ العَوَزُ إلى الهِجْرَة من وَطَنه».
أَعْوَزُ ج عُوزٌ مؤ عَوْزَاءُ ج عَوْزاوات وعُوزٌ : محتاج، ضيِّق الحال «خَسِيرَ ثَرْوَتَه كُلُّها وأصبح أَعْوَزَ».
مُعْوِزٌ ج ــ ون : محتاج، ضيق الحال «كان فقيرا مغوزا».
§ع و س ج
عَوْسَجٌ : نبات شائك من الفصيلة الباذنجانية.
§ع و ص
عاصَ يَعاصُ عَوْصًا فهو عَوِيصٌ : ١ ــ الأمْرُ : صَعُبَ، ٢ ــ الكلامُ : صَعُبَ فهمُه.
عَوِصَ يَعْوَصُ عَوَصًا أَعْوَصُ : عاصَ.
اِعْتاصَ يَعْتاصُ اعْتِياصًا : ــ عليه الأَمْرُ : عاصَ.
اِعْتِياصٌ : مص اعْتاصَ.
عَوْصٌ : مص عاصَ.
عَوَصٌ : مص عَوِصَ.
عَوِيصٌ ج عِواصٌ : صَعْب «هذه مشكلة عويصة».
§ع و ض
عاضَ يَعاضُ عَوْضًا عائِض : ــ ه : بشيء : أُعطاه إياه بدل ما ذهب منه «عاضَهم الله أَفْضَلَ مما فقدوا».
عَوَّضَ يُعَوِّضُ تعويضاً : ــ ه : عاضه «عَوَّضه عن الخسائِر».
أعاضَ يُعيضُ إعاضة : ــ ه : عاضه.
تَعَوَّضَ يَتَعَوَّضُ تَعَوُّضًا : ــ من الشيء : أخذَ عِوَضا منه.
اِعْتَاضَ يَعْتَاضُ اعْتِياضًا : ــ من الشيء : أخذ عِوَضا منه.
اِسْتَعاضَ يَسْتَعِيضُ اسْتِعاضةً : ــ ه : سَأَلَهُ عِوَضًا.
اِسْتِعاضةٌ : مص اسْتَعاضَ.
إِعاضَةٌ : مص أَعاضَ.
اِعْتِياضٌ : مص اعْتاضَ.
تَعَوُّضٌ : مص تَعَوَّضَ.
تَعْوِيضٌ : ١ مص عَوَّضَ، ٢ ج ــ ات : بَدل وخَلَف خاصة على شكل نقود «دفع له تعويضا عن عمله»، ٣ [نفسيا] وسيلة يسد بها الفرد ضعفا أو عجزا، وذلك بالمبالغة في إظهار صفة أخرى.
عَوْضٌ : مص عاض.
عِوَضٌ ج أَعْوَاضٌ (الجمع قليلُ الاستعمال) بَدَلٌ وَخَلَفٌ «خذ هذا عِوَضًا عن /مِن ذاكَ»، «حصل عليه بعوض».
§ع و ق / ع ي ق
عاق يَعُوقُ /يَعِيقُ عَوْقًا /عَيْقًا عائِق : ــ ه عن الشيء : مَنَعه منه، شَغَلَه عنه، عاقَهُ المرضُ عن إنجازِ عَمَلِهِ.
يَعوق : اسم صَنَم في الجاهلية ﴿ولا يَغُوثَ ويَعُوقَ ونَسْرًا﴾ [قرآن].
§ع و ل
عالَ يَعولُ عَوْلًا عائِل : ــ ه : قام بما يحتاجه من طعام وكساء وغيرهما «مات أبوه فعالَه عمُّه».
عِيلَ : ــ صبّْره : نَفِد.
عَوَّلَ١ يُعَوِّلُ تَعْوِيلًا : ــ عليه : اعتمدَ «فلان رَجُلٌ يُعَوَّلُ عَلَيْهِ».
عَوَّلَ٢ يُعَوِّلُ تَعْوِيلًا : رَفَع صوته بالبُكاء والصِّياح.
أَعالَ يُعِيلُ إعالة : كَثُرَ عِيالُه فأثقلوه.
