@استدماء
اِسْتِدْمَاءٌ : مص اسْتَدْمَى.
تَدْمِيَةٌ : مص دَمَّى.
دَمٌ : تثنيته دَمَان ودَمَيَان ودَمَوَان، ج دِمَاءٌ : سائل أحمر يسري في عروق الحيوان ◆ أَهْدَرَ دمه : أباح قتله بَنْكُ الدم : مكان لحفظ الدم البشري دَمُهُ أزرق : أرستقراطي دَمُهُ بارد : صفيق دَمُهُ ثقيل : مكروه دَمُهُ خفيف : مرح ظريف وَلِيُّ الدمِ : الآخذ بالثأر زمرة الدم/مجموعة الدم/فصيلة الدم : النوع الذي ينتمي إليه دم الحيوان الثدييّ باعتبار وجود أو انعدام عوامل التلاصق طَالَبَ بدمه : سعى للأخذ بثأره عَلَيْهِ دَمٌ : ذَبْحٌ لجبر نقص في الفريضة قَرَابَةُ دم : من جهة الأب أو الأم لا يلائم دَمُه دمي : لا يتوافقان.
دَمَوِيٌّ : منسوب إلى الدم «الدورة الدموية» ◆ رَجل دَمِوِيٌّ : يُحِبُّ إراقة الدماء ورؤية منظرها.
دَمِيٌّ : مص دَمِيَ.
دَمًى : مص دَمِيَ.
دُمْيَةٌ ج دُمًى : تمثال صغير يُضرب به المثل في الحسن «كأنَّ عُنُقَهُ عُنُقُ دُمْيَةٍ» [من حديث صفة الرسول]، وتُشَبَّهُ بها المرأة فيقال «نساء كالدُّمَى».
الدُّمَيْرِيّ : (انظر : دمر).
§د م ي ا ط
دِمْيَاط : مدينة ساحلية في مصر برز اسمها أثناء الحروب الصليبية.
§د ن أ
دَنَأَ/دَنُوَ يَدْنَأُ/يَدْنُوُ دَنَاءَةً دَنِيءٌ : ــ الشخصُ : لؤم فعله وخبث.
تَدَنَّأَ : يَتَدَنَّأُ تَدَنُّؤًا : ــ الشخصُ : دَنُؤَ.
تَدَنُّؤٌ : مص تَدَنَّأَ.
دَنَاءَةٌ : مص دَنَأَ.
دَنِيءٌ/دَنِيٌّ ج دُنَآءُ وأَدْنِيَاءُ : خسيس دون.
دَنِيئَةٌ/دَنِيَّةٌ ج دَنايا : نقيصة «المؤمن يتعد عن الدنايا».
§د ن د ن
دَنْدَنَ يُدَنْدِنُ دَنْدَنَةً : ١ ــ المغنّي : تكلم أو غنّى بصوت خفي يسمع ولا يفهم، ٢ ــ الذبابُ : صَوَّتَ وطَنَّ.
دَنْدَنَةٌ : مص دَنْدَنَ.
§د ن ر
دَنَّرَ يُدَنِّرُ تَدْنِيرًا : ١ ــ وَجْهُهُ : أُشْرَقَ وتلألأ كالدينار، ٢ ــ الثَّوْبَ : وشَّاه كهيئة الدينار.
تَدْنِيرٌ : مص دَنَّر.
دِينَارٌ ج دَنَانِيرُ : ١ [في القديم] عُمْلَةٌ ذهبية، ٢ [في الحديث] عُمْلَةٌ وَرَقِيَّةٌ تستعمل في كثير من البلاد العربية (الأردن ــ البحرين ــ تونس ــ العراق ــ ليبيا ــ الكويت...).
§د ن س
دَنِسَ يَدْنَسُ دَنَساً دَنِسٌ : ــ الشيءُ : توسخ وتلطخ «دَنِسَ عِرْضُه»، «دنس ثوبه».
دَنَّسَ يُدَنِّسُ تَدْنِيساً : ــ الشيءَ : وَسَّخَهُ «دنَّس ثَوْبَهُ» ◆ دنس عرضه : فعل ما يَشينه.
تَدَنَّسَ يَتَدَنَّسُ تَدَنُّساً : ــ الشيءُ : اتَّسخ.
تَدَنُّسٌ : مص تَدَنَّسَ.
تَدْنِيسٌ : مص دَنَّسَ.
دَنَسٌ : ١ مص دَنِسَ، ٢ ج أَدْنَاسٌ : لَطْخُ الوَسَخ.
دَنِسٌ ج للعاقل ــ ون : وَسِخٌ.
§د ن ش و ا ى
دِنْشْوَاى : بلدة بمحافظة المنوفية بمصر كان بها حادثة مشهورة أيام الاستعمار الانجليزي أدت إلى إعدام عدد من أهلها وجلد آخرين.
§د ن ف
دَنِفَ يَدْنَفُ دَنَفاً فهو دَنِفٌ : ١ ــ الشخصُ : اشتد مرضه، ٢ تهالك في حبه حتى مرض.
أَدْنَفَ يُدْنِفُ إِدْنَافاً : ــ ه المَرَضُ : أَضْنَاهُ وأتعبه.
إِدْنَافٌ : مص أدنف.
