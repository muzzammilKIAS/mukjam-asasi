@أنغض
↩ طيبًا «شايٌ بالنَّعْنَاعِ».
نُعْنُع : ١ النَّعْنَاع، ٢ ج نعانع، رجل نُعْنُع : مضطرب رخوّ.
نَعْنَعَةٌ : مص نَعْنَعَ.
§ن ع ى
نَعَى يَنْعَى نَعْيًا ونَعِيًّا فهوَ نَاعٍ (الناعي) مَنْعِيٌّ : ١ ــ فلانًا : أذَاعَ خبَر مَوْتِه «ترك الدار تنعى من بناها»، ٢ ــ عَلَيْهِ كذا : عابَهُ عليْهِ وشَهَّر بهِ «نَعَى عَلَيْهِ شُرْبَ الخَمْرِ».
أَنْعَى يُنْعِي إنْعَاءً مُنْعٍ (المُنْعِي) مُنْعَى عليه : ــ عليهِ قَبيحًا : قاله تَشْنِيعًا عليه «أنعى عليهِ ارتكابَ الفَوَاحِشِ».
تَناعَى يَتَنَاعَى تَنَاعِيًا مُتَنَاعٍ (المتناعي) : ــ القَوْمُ : نَعَوْا قَتْلاهُمْ لِيُحَرِّضُوا على الثَّأْرِ.
إنْعَاءٌ : مص أنْعَى.
تَنَاعٍ (التناعي) : مص تَنَاعَى.
مَنْعًى / مَنْعَاةٌ ج مَنَاعٍ (الْمَنَاعِي) : خَبَرُ المَوْتِ «أتانا مَنْعاهُ صَبيحَةَ هَذَا اليَوْمِ».
ناعٍ (النَّاعِي) ج ناعُونَ ونُعَاةٌ مؤ نَاعِيَةٌ ج نَاعِيَاتٌ : ١ مَنْ يأتي بخبرِ المَوْتِ، ٢ مَنْ يُشَيِّعُ المَيِّتَ إِلَى قبْرِهِ.
نَعْيٌ : مص نَعَى.
نَعِيٌّ : ١ مص نَعَى، ٢ ج نَعَايَا : رَجُلٌ مَيِّتٌ.
§ن غ ب
نَغَبَ يَنْغَبُ نَغْبًا فهو ناغب : ١ ــ الطَّائرُ : حَسَا من الماء، ٢ ــ الرِّيقَ : ابْتَلَعَهُ.
نَغْبٌ : مص نَغَبَ.
نُغْبَةٌ ج نُغَبٌ : جَرْعَةٌ «سَقَاهُ نُغْبَةً مِنْ لَبَنٍ».
§ن غ ر
نَغِرَ يَنْغَرُ نَغَرًا فهو نَغِرٌ : ــ الشَّخْصُ : غَلَى جَوْفُهُ وغَضِبَ.
نَغَّرَ يُنَغِّرُ تَنْغِيرًا : ١ ــ الصَّبِيَّ : دَغْدَغَهُ، ٢ ــ مِنه وبه : صَاحَ «نَغَّر بالنَّاقةِ لِتُسْرِعَ».
تَنْغِيرٌ : مص نَغَّر.
نَغَرٌ : مص نَغِرَ.
نَغِرٌ : مغتاظ غضبان.
نَغَّارٌ : ١ كثيرُ النَّغَرِ «وَلَدٌ نَغَّارٌ»، ٢ سَيَّالٌ «جُرْحٌ نَغَّارٌ».
§ن غ ز
نَغَزَ يَنْغِزُ نَغْزًا فهو ناغز : ١ ــ الصَّبِيَّ : دَغْدَغَهُ، ٢ ــ الشَّخصَ : اغْتَابَهُ وقالَ فيهِ شرًّا، ٣ ــ بينَ القومِ : حَرَّكَ بينهُمْ العَدَاوَاتِ وأغْرَى بَعْضَهم ببَعضٍ.
نَغْزٌ : مص نَغَزَ.
§ن غ ص
نَغَصَ يَنْغَصُ نَغْصًا فهو ناغص : ١ ــ الشَّخصَ : منعه نصيبَه من الماءِ، ٢ ــ عليهِ : كَدَّرَ «نَغَصَ عليهِ حَياتَه بالضَّجيجِ المُسْتَمِرِّ».
نَغِصَ ينغص نَغَصًا : ١ ــ الشيءُ لم يتم، ٢ ــ الشارِبُ : لم يُتمَّ شُرْبَه.
نَغَّصَ يُنَغِّصُ تَنْغِيصًا : ١ ــ الشّخصَ : كدَّره «أنغص عيشه»، ٢ ــ عَلَيْهِ : قَطَعَ عَلَيْهِ مَا كَانَ يُحِبُّ الاسْتِكْثَارَ مِنْهُ.
تَنَغَّصَ يَتَنَغَّصُ تَنَغُّصًا : ــ العَيْشُ : تَكَدَّرَ واضْطَرَبَ «تَنَغَّصَتْ حَيَاةُ العَائِلَةِ بَعْدَ غَلَاءِ المَعِيشَةِ».
تَنَغُّصٌ : مص تَنَغَّصَ.
تَنْغِيصٌ : مص نَغَّصَ.
مُنَغِّصَاتٌ مف مُنَغِّصٌ : مَا يُكَدِّر الحَيَاةَ مِن مَشَاكِلَ مَادِّيَةٍ ومَعْنَويَّةٍ «لَا حَوْلَ لهُ ولَا قُوَّةَ على مُوَاجَهةِ مُنَغِّصَاتِ الحَيَاةِ».
نَغْصٌ : مص نَغَصَ.
§ن غ ض
أَنْغَضَ يُنْغِضُ إنغاضا : ــ رأسَه : حركه كالمتعجب من شيء ﴿فَسَيُنْغِضُونَ إِلَيْكَ رُؤُوسَهُمْ﴾ [قرآن].
