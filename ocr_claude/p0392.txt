@خرق
↩ اختلقه ﴿وخَرَقُوا لَهُ بَنينَ وبَنَاتٍ بِغَيْرِ عِلْمٍ﴾ [قرآن].
خَرِقَ / خَرُقَ يَخْرَقُ / يَخْرُقُ خَرَقًا فهو خَرِقٌ وأَخْرَقُ : ــ الرجلُ : حَمُقَ.
خَرَّقَ يُخَرِّقُ تَخْرِيقًا ١ ــ الثوبَ : وَسَّعَ شَقَّه، ٢ ــ الورقةَ ونحوها : مَزَّقها
تَخَرَّقَ يَتَخَرَّقُ تَخَرُّقًا : ــ الثوبُ : اتسع شَقُّه.
اِنْخَرَقَ يَنْخَرِقُ انْخِرَاقًا : ــ الشيءُ : انشقَّ.
اِخْتَرَقَ يَخْتَرِقُ اخْتِرَاقا : ــ الصفوفَ : خرقها ونفذ منها ◆ اِخترق الجيشُ الحصار : خَرَقَهُ ونَفَذَ منه اِخترق الرجلُ القومَ : مضى وَسطَهُمْ اِخترق السهمُ الرَّمِيَّةَ : نفذ فيها اِخترق العدوُّ الحدودَ : عبرها مهاجما اِخترق الكلامُ مسامعه : وصل إليه بقوة اِخترق المسافرُ الأرضَ : مَرَّ فيها عَرْضًا على غير طريق.
اِخْتِرَاقٌ : مص اخْتَرَقَ «سمع السكان فرقعة نتيجة اختراق الطائرة حاجز الصوت».
أَخْرَقُ مؤ خَرْقَاءُ جمعهما خُرْقٌ : أحمق «لا تكن أخرق بمغامراتك الهوجاء» ◆ سياسة خرقاء : لا تأبه بعواقب الأمور.
اِنْخِرَاقٌ : مص انْخَرَقَ.
تَخَرُّقٌ : مص تَخَرَّقَ.
تَخْرِيقٌ : مص خَرَّقَ.
خارِقٌ ج خَوارِقُ : ١ قاطع «سيف خارق»، ٢ غير عادي «كانت ذاكرته مفعمة بحيوية خارقة تتحدى الزمن»، ٣ [في علم الكلام] أمر خارق للعادة : مجاوز لقدرة العبد أو طبيعة المخلوقات كالمعجزة والكرامة.
خَرْقٌ : ١ مص خَرَقَ، ٢ ج خُرُوقٌ : ثَقْبٌ في الثوب وغيره «اتَّسَعَ الخَرْقُ على الرَّاقِع» [مثل] يضرب للمشكلة التي تتعاظم فيَصْعب حَلُّها ◆ خَرْقُ العادة : ما ينسب إلى الصالحين أو الأولياء من كرامات تخرج عن المألوف.
خَرْقٌ : مص خَرِقَ.
خِرْقَةٌ ج خِرَقٌ : قطعة من الثوب الممزَّق «يؤلمني منظر الفقراء يرتدون خِرَقًا ممزقةً».
§خ ر م
خَرَمَ يَخْرِمُ خَرْمًا : ١ ــ الشيءَ : ثَقَبَهُ، ٢ ــ الجذاذةَ : ثقبها لتوضع في الحاسب الآلي، ٣ ــ الثوبَ : شقه، ٤ ــ الحديثَ : أنقص منه وأسقط بعضه «ما خَرَمَ من الحديث حرفا».
خَرَّمَ يُخَرِّم تخريما : ــ الشيءَ : بالغ في ثَقبه أو شَقِّه.
تَخَرَّمَ يَتَخَرَّمُ تَخَرُّمًا : ١ ــ الثوبُ : تَشَقَّق، ٢ ــ الوباءُ القومَ : أفناهم.
اِنْخَرَمَ يَنْخَرِمُ انْخِرَامًا : ١ ــ الشيءُ : انشقَّ، ٢ ــ العامُ : ذهب وانقضى، ٣ ــ الأمرُ : فسد.
اِخْتَرَمَ يَخْتَرِمُ اخْتِرَامًا : ــ الدهرُ / المنيةُ فُلانًا : أهلكه.
اِخْتِرَام : مص اخْتَرَمَ.
أَخْرَمُ مؤ خَرْمَاءُ جمعهما خُرْمٌ : ــ الرأي : ضعيفه.
اِنْخِرَامٌ : مص انْخَرَمَ.
تَخَرُّمٌ : مص تَخَرَّمَ.
تَخْرِيمٌ : مص خَرَّمَ ◆ آلة تخريم : خرَّامة.
خَرَّامَةٌ ج خَرَّامَات : آلة لثَقْب الورق على مسافات معينة لوضعه في السجلات.
خرّم شهر : مدينة ومرفأ في إيران على الخليج العربي قريبا من شط العرب.
خُرَّمِي : الـ ــ، بابك (ت ٢٢٤ هـ/٨٣٨ م) : زعيم فرقة الخرّمية في خلافة المأمون والمعتصم. هزم بغا الأكبر عند جبل مراغة. قضى عليه الأفشين قائد المعتصم. حكم حوالي عشرين سنة.
الخُرَّمِيَّة : مذهب رأسه بابك الخرّمي يقول برجعة أبي مسلم الخراساني، وأنه سيملأ الأرض عدلا كما ملئت جورا، وبالتالي فإن أبا مسلم لم يمت.
خَرْمٌ : مص خَرَمَ.
