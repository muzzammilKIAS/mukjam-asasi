@إرهاق
إِرْهَاقٌ : مص أَرْهَقَ.
رَهَقٌ : مص رَهِقَ.
مُرَاهِقٌ ج ــ ون مؤ مراهقة ج مراهقات : الفرد في فترة المراهقة.
مُرَاهَقَةٌ : ١ مص رَاهَقَ، ٢ الفترة من بلوغ الحلم إلى سنّ الرشد «نضج تفكيره وتخطى مرحلة المراهقة».
§ر ه ل
رَهِلَ يَرْهَلُ رَهَلا رَهِلٌ : ــ الشخصُ : وَرِمَ وانتفخ واسترخى لَحْمُهُ.
رَهَّلَ يُرَهِّلُ تَرْهِيلا : ــ ه النَّوْمُ : أصاب وَجْهَهُ ومَحَاجِرَهُ بالانتفاخ لكثرة النوم.
تَرَهَّلَ يَتَرَهَّلُ تَرَهُّلا : ــ الشخصُ : رَهِلَ.
تَرَهُّلٌ : مص تَرَهَّلَ.
تَرْهِيلٌ : مص رَهَّلَ.
رَهَلٌ : مص رَهِلَ.
رَهِلٌ مؤ رَهِلَةٌ : وَرِمٌ منتفخ مسترخي اللحم.
§ر ه م
رَهْمَةٌ ج رِهَامٌ ورَهَمَاتٌ : مَطْرَةٌ ضَعِيفَةٌ صغيرة القَطْر.
مَرْهَمٌ ج مَرَاهِمُ : دِهَانٌ طِبِّيٌّ يوضع على الجروح والقروح ونحوها.
§ر ه ن
رَهَنَ¹ يَرْهَنُ رُهُونًا : ــ الشخصُ بالمكان : ثبت وأقام، ويقال كذلك : «نعمة راهنة»، «طعام راهن».
رَهَنَ² يَرْهَنُ رَهْنًا : ــ الشيءَ عند فلان : حَبَسَهُ عنده بدَيْنٍ ◆ الأمورُ مرهونةٌ بأوقاتها : لكل شيء وَقْتٌ وأَوَانٌ.
رَاهَنَ يُرَاهِنُ رِهَانًا ومُرَاهَنَةً : ــ ه على كذا : سابقه وخاطره.
أَرْهَنَ يُرْهِنُ إِرْهَانًا : ١ ــ ه الشيءَ : دَفَعَهُ إليه لِيَرْهَنَهُ عند أحد، أو رَهَنَهُ إياه، ٢ ــ ه للموت : أَسْلَمَهُ.
تَرَاهَنَ يَتَرَاهَنُ تَرَاهُنًا : ــ القومُ : أخرج كل واحد منهم رَهْنا ليفوز السابق بالجميع.
اِرْتَهَنَ يَرْتَهِنُ ارْتِهَانا : ــ الشيءَ منه : أخذه رَهْنًا، فالشيء المأخوذ مُرْتَهَنٌ.
اِسْتَرْهَنَ يَسْتَرْهِنُ اسْتِرْهَانا : ــ ه الشيءَ : طلبه منه رَهْنًا.
اِرْتِهَانٌ : مص ارْتَهَنَ.
إِرْهَانٌ : مص أَرْهَنَ.
اِسْتِرْهَانٌ : مص اسْتَرْهَنَ.
تَرَاهُنٌ : مص تَرَاهَنَ.
رَاهِنٌ : ١ مُعَدٌّ دائم «هذا رَاهِنٌ لك» : أي دائم محبوس عليك، و«طعام راهن» : دائم، ٢ حاصِلٌ في الوقت الحاضر «الظروف الراهنة».
رِهَانٌ : ١ مص رَاهَنَ : «هما كَفَرَسَيْ رِهَانٍ» [مثل]، يضرب للمتساويين في الفضل وغيره، ٢ مف رَهْن.
رَهْنٌ : ١ مص رَهَنَ، ٢ ج رِهَانٌ ورُهُونٌ ج ج رُهُونَاتٌ : الشيء المحبوس نظير دَيْن (فَعْلٌ بمعنى مفعول) : ﴿وَإِنْ كُنْتُمْ عَلَى سَفَرٍ وَلَمْ تَجِدُوا كَاتِبًا فَرِهَانٌ مَقْبُوضَةٌ﴾ [قرآن] ◆ أُعْتُقِلَ رَهْنَ التحقيق : وُضِعَ في الحبس استعدادا لمحاكمته، أنا رَهْنَ إشارتك : تحت طلبك، أنا لك رَهْنٌ بكذا : كفيل به ضامن له، الإنسان رَهْنُ عمله : مأخوذ به، مَحَلُّ رُهُونَاتٍ : يقوم بالإقراض مقابل احتفاظه برهن.
رُهُونٌ : ١ مص رَهَنَ¹ ٢ مف رَهْن.
رَهِينٌ ج رَهَائِنُ، فعيل بمعنى مفعول : مرهون مأخوذ بالشيء : ﴿كُلُّ امرئٍ بِما كَسَبَ رَهِينٌ﴾ [قرآن] ◆ أنا لك رهين بكذا : ضامن.
رَهِينَةٌ ج رَهَائِنُ : ١ مُؤَنَّثُ رهين : ﴿كُلُّ نَفْسٍ بِمَا كَسَبَتْ رَهِينَةٌ﴾ [قرآن]، ٢ شخص ذو مركز كانت تسلمه سلطة مختصة لسلطة أخرى إظهارًا لحسن النية في تنفيذ معاهدةٍ أو لضمان ولاءِ مَدِينَةٍ أو دَوْلَةٍ، ٣ مَنْ يُقْبَضُ عليه من جماعة متطرفة للضغط على حكومة ما لتنفذ رغبات هذه الجماعة، كما هو الحال في حوادث خطف الطائرات، وكما حدث للرهائن الأمريكيين في
