@شر
مَشْرَحَةٌ ج مَشَارِحُ : ١ منضدة تهيأ للتشريح، ٢ غرفة كبيرة تعد لتشريح الأجسام بعد موتها.
شُرَحْبِيلُ بن حَسَنَة (ت ١٨ هـ / ٦٣٩ م) : صحابي من القواد الفاتحين.
§ش ر خ
شَرَخَ¹ يَشْرُخُ شَرْخًا : ــ الزجاجَ أو العظمَ أو الحائطَ أو نحوها : أحدث به شَقًّا غير نافذ.
شَرَخَ² يَشْرُخُ شُرُوخًا : ــ الصبيُّ : بلغ أول شبابه.
شَرْخٌ : ١ مص شَرَخَ¹، ٢ شَرْخُ الشيء : أصله، ٣ شَرْخُ الشباب : أوّله ونضارته.
شُرُوخٌ : مص شَرَخَ².
§ش ر د
شَرَدَ يَشْرُدُ شَرْدًا وشُرُودًا وشِرَادًا شارِدٌ وشَرُودٌ : ١ ــ البعيرُ ونحوه : نفر واستعصى : «أَمَا يَشْرُدُ بك بَعِيرُك» [حديث]، ٢ ــ المسافرُ عن الطريق : حاد ◆ شَرَدَ ذِهْنُه / فكرُه / نظرُه / شرد به الفكر : سَرَحَ خاطره وغفل عما حوله.
شَرَّدَ يُشَرِّدُ تَشْرِيدًا : ــ هم / بهم : فَرَّقهم وطردهم من ديارهم وتركهم بلا مأوى «شرد العدو الصهيوني الفلسطينيين» ﴿فَشَرِّدْ بِهِمْ مِنْ خَلْفِهِمْ﴾ [قرآن].
تَشَرَّدَ يَتَشَرَّدُ تَشَرُّدًا : ١ ــ القومُ : تفرقوا، ويقال : تشردوا في الأرض، ٢ ــ الرجلُ : هام على وجهه لعدم وجود مأوى له.
تَشَرُّدٌ : مص تَشَرَّدَ.
تَشْرِيدٌ : مص شَرَّدَ.
شَارِدٌ ج ــ ون مؤ شاردة ج شوارِدُ وشاردات : ١ رجل شاردُ البَصَر / الفكر : ينظر إلى الشيء دون أن يراه لانشغال خاطره، ٢ قصيدة شاردة : سائرة في البلاد ◆ لا تفوته شاردةٌ ولا واردةٌ : لا يغفل عن أي شيء.
شِرَادٌ : مص شَرَدَ.
شَرْدٌ : مص شَرَدَ.
شَرُودٌ ج شُرَّدٌ وشُرُودٌ : نافر ◆ قافية شَرُودٌ : قصيدة منتشرة ذائعة.
شُرُودٌ : ١ مص شَرَدَ، ٢ [في علم النفس] : حالة يفقد فيها المريض ذاكرته عن جميع تصرفاته السابقة مع الاحتفاظ بعاداته ومهاراته.
شَرِيدٌ ج ــ ون : طريد لا مأوى له.
شَوَارِدُ مف شَارِدَةٌ : شوارد اللغة : غرائبها ونوادرها.
مُتَشَرِّدٌ ج ــ ون : مُتَبَطِّلٌ متسكع لا مأوى له.
§ش ر ذ م
شِرْذِمَةٌ ج شَرَاذِمُ : قطعة أو جزء من الشيء : «جاء شِرْذِمة من الناس»، ﴿إِنَّ هَؤُلَاءِ لَشِرْذِمَةٌ قَلِيلُونَ﴾ [قرآن].
§ش ر ر
شَرَّ¹ (شَرَرْتُ / شَرِرْتُ / شَرُرْتُ) يَشِرُّ / يَشَرُّ / يَشُرُّ شَرًّا وشَرَارَةً شِرِّيرٌ : ١ ــ الرجلُ : مال إلى الشر وتعوده «الشرُّ ليس إليك» [حديث] ينفي الظلم والفساد عن الله لأن أفعاله تعالى صادرة عن حكمة بالغة والموجودات كلها ملكه، ٢ ــ الشيءُ : كان موضع استهجان أو ذم.
شَرَّ² (شَرَرْتُ) يَشِرُّ / يَشُرُّ شَرًّا شَارٌّ : ــ الشيءَ في الشمس : نشره وبسطه : «شَرَّ اللحم».
أَشَرَّ يُشِرُّ إِشْرَارًا : ١ ــ الرَّجُلُ فُلانًا : نسبه إلى الشَّرّ، ٢ ــ الرجلُ اللحمَ : شَرَّه.
شَارَّ يُشَارُّ مُشَارَّةً : ــ الرجلُ فلانا : خاصمه.
إِشْرَارٌ : مص أَشَرَّ.
شَرَارٌ مف شَرَارَةٌ ج شَرَارَاتٌ : ١ أجزاء صغيرة متوهجة تنفصل عادة عن جسم يحترق، ٢ ضوء حادث من تفريغ كهربي.
شَرَارَةٌ : ١ مص شَرَّ¹، ٢ واحدة الشَّرَار.
شَرٌّ : ١ مص شَرَّ¹،²، ٢ ج شرور : عكسه خير «مطبوع على الشر»، سوء وفساد. «بَعْضُ الشَّرِّ أَهْوَنُ من بعض»
