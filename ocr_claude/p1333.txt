@والى
§و ل غ
وَلَغَ يَلَغُ وَلْغًا وُلُوغًا وَوَلَغَانًا فهو وَالِغٌ : ــ الكَلْبُ الاناءَ وفي الاناءِ : شَرِبَ ما فيه بِطَرَفِ لِسَانِه ◆ فُلانٌ يَأْكُلُ لُحومَ النَّاسِ «يَلَغُ في دِمَائِهِم : يغتابُهُمْ.
وَلَغَ يُولِغُ إِيلاغًا : ــ الكَلْبَ : جَعَلَ له مَاء أو شيئا يَلَغُ فيه.
إِيلاَغٌ : مص أَوْلَغَ.
وَلْغٌ : مص وَلَغَ.
وَلَغَانٌ : مص وَلَغَ.
وُلُوغٌ : مص وَلَغَ.
§و ل ف
وَالَفَ يُوَالِفُ مُوَالَفَةً : ١ ــ هُ : أَلِفَهُ، ٢ ــ هُ : اتَّصَلَ به وانتَسَبَ إِلَيْهِ.
تَوَالَفَ يَتَوَالَفُ تَوَالُفًا : ــ الشيءُ : ائْتَلَفَ بعضُهُ إلى بَعْض.
وَلِيفٌ : أَلِيفٌ.
تَوَالُفٌ : مص تَوَالَفَ.
تَوْلِيفَةٌ ج تَوْلِيفَاتٌ : مخلوط من مواد مختلفة بنسب معيّنة.
مُوَالَفَةٌ : مص وَالَفَ.
وَلاْدَةُ بنت المستكفي : (انظر : ولد).
§و ل م
أَوْلَمَ يُولِمُ إِيلامًا : ــ الشخصُ : أَعَدَّ وَلِيمَة.
إِيلاَمٌ : مص أَوْلَمَ.
وَلِيمَةٌ ج وَلاَئِمُ : كُلُّ طَعَامٍ يُتَّخَذُ لِجَمْعٍ أو لدَعْوَة «وَلِيمَةُ الخِتَانِ»، «وَلاَئِمُ الأَعْرَاسِ».
§و ل هـ
وَلَهَ يَلِهُ وِلْهًا/وَلَهًا فهو وَالِهٌ وَوَلْهَانُ : ١ ــ الشخصُ : اشتَدَّ حُزْنُهُ حَتَّى كادَ يذهب عقلُهُ، ٢ ــ الشخصُ : تحيَّر من شِدَّةِ الوَجْدِ، ٣ ــ تِ الأُمُّ إلى طِفْلِهَا : حَنَّتْ إِلَيْهِ.
وَلِهَ يَلِهُ أو يَوْلَهُ وَلَهًا ووَلَهانًا فهو وَالِهٌ وَوَلْهَانُ : وَلَهَ.
وَلَّهَ يُوَلِّهُ تَوْلِيهًا : ١ ــ الشخصَ : أَوْقَعَهُ في الوَلَهِ، ٢ ــ هُ الحُزْنُ أوِ الوَجْدُ : صَيَّرَهُ وَالِهًا.
أَوْلَهَ يُولِهُ إِيلاَهًا : ١ ــ هُ الحُزْنُ : صَيَّرَهُ وَالِهًا وَأَفْقَدَ عَقْلَهُ، ٢ ــ الأُمَّ : فَجَعَهَا بِوَلَدِهَا.
إِيلاَهٌ : مص أَوْلَهَ.
تَوْلِيهٌ : مص وَلَّهَ.
وَلْهٌ : مص وَلِهَ.
وَلَهٌ مص وَلِهَ : ١ حُزْنٌ شديد، ٢ حُبٌّ شَدِيدٌ.
وَلْهَانُ مؤ وَلْهَى جمعهما وُلَّهٌ : ١ حزين حُزنا شديدا، ٢ مُتَحَيِّر من كثرة الحُبِّ.
§و ل و ل
وَلْوَلَ يُوَلْوِلُ وَلْوَلَةً وَوَلْوَالاً : ١ ــ تِ المرأةُ : دَعَتْ بالوَيْلِ، ٢ ــ تِ المرأةُ : أَعْوَلَتْ «يُوَلْوِلْنَ على الْمَيِّتِ».
وَلْوَالٌ : مص وَلْوَلَ.
وَلْوَلَةٌ : مص وَلْوَلَ.
§و ل ى
وَلِيَ يَلِي وَلْيًا وَالٍ (الوَالي) مَوْلِيٌّ : ــ هُ : قَرُبَ مِنْهُ.
وَلِيَ يَلِي وَلْيًا وَالٍ (الوالي) مَوْلِيٌّ : ١ ــ هُ قَرُبَ منه، ٢ ــ هُ : تَبِعَهُ بعد قليل «سَيَأْتِي شَرْحُ الكلامِ فيما يَلِي...».
وَلِيَ يَلِي وِلاَيَةً وَالٍ (الوَالِي) مَوْلِيٌّ : ١ ــ الشَّيْءَ وعليه : مَلَكَ أمْرَهُ وقام به، ٢ ــ البَلَدَ : حَكَمَهُ وَتَسَلَّطَ عليه، ٣ ــ هُ : أَحَبَّهُ.
وَلَّى يُوَلِّي تَوْلِيَةً مُوَلٍّ (المُوَلِّي) مُوَلًّى : ١ ــ الشَّخصُ : أَدْبَرَ «وَلَّى فُلانٌ هَارِبًا»، ٢ ــ الشَّيْءَ وعَنه : أَعْرَضَ عنه وابتَعَدَ عنه، ٣ ــ فلانا الأمرَ : جَعَلَهُ وَالِيا عليهِ «وَلاَّهُ البَصْرَةَ» ◆ وَلاَّهُ ظَهْرَهُ : جَعَلَهُ وَرَاءَهُ وَلَّى عن فُلانٍ بِوُدِّهِ : تَغَيَّرَ عليه.
وَالَى يُوَالِي مُوَالاَةً مُوَالٍ (الْمُوَالِي) مُوَالًى : ١ ــ الشَّيْءَ : تَابَعَهُ، ٢ ــ الشَّخصَ : نَاصَرَهُ، ٣ ــ الشخصَ : أَحَبَّهُ، ٤ ــ بين الأَمْرَيْنِ : تَابَعَ بَيْنَهُمَا.
