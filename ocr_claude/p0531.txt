رَطَنَ يَرْطُنُ رَطَانَةً / رِطَانَةً : ١ ــ الأعجميُّ : تكلم بلغته، ٢ ــ المتكلمُ : تكلم بكلام غير مفهوم.
تَرَاطَنَ يَتَرَاطَنُ تَرَاطُنًا : ــ الشخصان : تخاطبا بالأعجمية أو بالرّطانة.
تَرَاطُنٌ : مص تَرَاطَنَ.
رَطَانَةٌ / رِطَانَةٌ : مص رَطَنَ.
§ر ع ب
رَعَبَ يَرْعَبُ رُعْبًا : ١ ــ الشخصُ : خاف وفزع، ٢ ــ ه : خَوَّفَه وأفزعه.
رَعَّبَ يُرَعِّبُ تَرْعِيبًا : ــ ه : رَعَبَهُ.
أَرْعَبَ يُرْعِبُ إِرْعَابًا : ــ ه : رَعَبَهُ.
اِرْتَعَبَ يَرْتَعِبُ ارْتِعَابا : ــ الشَّخْصُ : خاف وفزع.
اِرْتِعَابٌ : مص ارْتَعَبَ.
إِرْعَابٌ : مص أَرْعَبَ.
تَرْعِيبٌ : مص رَعَّبَ.
رُعْبٌ : مص رَعَبَ ﴿ وَقَذَفَ في قُلُوبِهِمُ الرُّعْبَ﴾ [قرآن] ◆ فَعَلَ ذلك رُعْبًا لا رُغْبًا : خوفا لا رغبة.
رَعِيبٌ ج رُعَبَاءُ : مَرْعُوبٌ جَبَانٌ.
§ر ع د
رَعَدَ يَرْعَدُ / يَرْعُدُ رَعْدًا ورُعُودًا فهو راعد : ــ السحابُ : صوَّت للإمطار، ويقال كذلك «رعدت السماء» «رعدتنا السماء» ◆ رَعَدَ له وبَرَقَ : توعده وتهدده بالشر.
أَرْعَدَ يُرْعِدُ إِرْعَادًا : ١ ــ السحابُ : رَعَدَ، ٢ الشخصَ : جعله يرتعد ◆ أَرْعَدَ له وأَبْرَقَ : رَعَدَ له وبَرَقَ.
اِرْتَعَدَ يَرْتَعِدُ ارْتِعَادًا : ــ الشخصُ : ارتعش واضطرب ◆ ارتعدت فَرائِصُهُ : خاف وفزع.
اِرْتِعَادٌ : مص ارْتَعَدَ.
إِرْعَادٌ : مص أَرْعَدَ.
رَاعِدٌ مؤ رَاعِدَةٌ ج رَوَاعِدُ : ذو رَعْد «سَحَابٌ راعِدٌ» ◆ ذات الرَّواعد : المصيبة والداهية.
رَعْدٌ : ١ مص رَعَدَ، ٢ ج رُعُودٌ : صوت يُدَوِّي في السماء عقب وميض البَرْقِ : ﴿أَوْ كَصَيِّبٍ مِنَ السَّمَاءِ فِيهِ ظُلُمَاتٌ ورَعْدٌ وبَرْقٌ﴾ [قرآن].
رِعْدَةٌ : اضطراب الجسم من فزع أو خوف أو حُمَّى أو غيرها : «أصابته رعدة».
رَعَّادٌ : ١ سَحَابٌ كثير الرَّعْدِ، ٢ نوع من السمك إذا مَسَّه الإنسان ارتعدت يداه مادام السمك حيا.
رُعُودٌ : ١ مص رَعَدَ، ٢ مف رَعْد.
§ر ع د د
رِعْدِيدٌ ج رَعَادِيدُ : جبان يرتعد ويضطرب من شدة الخوف «رجل رعديد».
§ر ع ر ع
رَعْرَعَ يُرَعْرِعُ رَعْرَعَةً : ــ الغِذَاءُ الغُلَامَ : جَعَلَهُ ينبت وينمو.
تَرَعْرَعَ يَتَرَعْرَعُ تَرَعْرُعًا : ــ الصبيُّ : نشأ وشب ونما.
تَرَعْرُعٌ : مص تَرَعْرَعَ.
رَعْرَعَةٌ : مص رَعْرَعَ.
§ر ع ش
رَعَشَ / رَعِشَ يَرْعَشُ رَعْشًا ورَعَشًا رَعِشٌ : ١ ــ الشيخُ : ارتعش وارتجف واضطرب، ٢ ــ الشخصُ : جَبُنَ ◆ رعشت يداه : جبن.
رُعِشَ يُرْعَشُ ــ الرَّجُلُ : اعترته رِعْشَةٌ فهو مرعوش.
أَرْعَشَ يُرْعِشُ إِرْعَاشًا : ــ ه الكِبَرُ : سبب له الارتعاش ◆ أَرْعِشَتْ يَدَاهُ : تقدمت به السنّ.
اِرْتَعَشَ يَرْتَعِشُ ارْتِعَاشًا : ــ الجَبَانُ : ارتجف واضطرب «ارتعدت مفاصله، وارتعشت أنامله».
اِرْتِعَاشٌ : مص اِرْتَعَشَ.
إِرْعَاشٌ : مص أَرْعَشَ.
رُعَاشٌ : رِعْدَةً أو رِعْشَةً تعتري الانسان من داء يُصيبه
