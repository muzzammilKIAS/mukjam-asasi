@شجن
أشجر : ــ ت الأرض : كَثُرَ شَجرُها.
شَجَّرَ يُشَجِّرُ تَشْجِيرًا : ١ ــ النباتُ : صار شجرا، ٢ ــ الشارعَ : زرعه بالأشجار، ٣ ــ الثوبَ : رسم فيه صورة الشجر.
شَاجَرَ يُشَاجِرُ شِجَارًا ومُشَاجَرَةً : ــه : نازعه.
تَشَاجَرَ يتشاجر تشاجُرًا : ــ الرجلان : تنازعا واختلفا.
اِشْتَجَرَ يَشْتَجِرُ اشْتِجَارًا : ١ ــ الشيءُ : تداخل بَعضُه في بعض : «اشتجرت الأصابعُ»، «اشتجرت الرماحُ»، ٢ ــ القومُ : تنازعوا وتخالفوا.
اِشْتِجَارٌ : مص اشْتَجَرَ.
تَشَاجُرٌ : مص تَشَاجَرَ.
تَشْجِيرٌ : مص شَجَّرَ.
شِجَارٌ : مص شَاجَرَ.
شَجْرٌ : مص شَجَرَ.
شَجَرٌ مف شَجَرَةٌ ج أَشْجَارٌ : نَبَاتٌ يقوم على ساق صُلْبة ◆ الشجرة الملعونة (في القرآن) : شجرة الزَّقُّوم شجرة النَّسَب : بيان على صورة شجرة يُفَصِّلُ تسلسل النسب من الجد الأعلى إلى الفروع الدنيا، ويقال كذلك «هو من شجرة النبوة» هو من شجرة طيبة : من أصل كريم.
شَجِرٌ : كثير الشجر «أرض شجرة».
شَجَرَةُ الدُّرِّ : (ت ٦٥٥ هـ/ ١٢٥٧ م) : جارية الملك الصالح أيوب ثم زوجته، تدخلت في السياسة وتولت الحكم (٦٤٨ هـ/ ١٢٥٠ م)، قتلت غيلة.
شَجَرِيٌّ : منسوب إلى الشَّجَر ◆ رسم شجري : متفرع على هيئة أغصان الشجرة.
الشَّجَرِيُّ، ابن ــ، الشريف أبو السعادات هبة الله بن علي (٤٥٠ ــ ٥٤٣ هـ / ١٠٥٨ ــ ١١٤٨ م) : لغوي بغدادي له «الأمالي»، «الحماسة».
شُجُورٌ : مص شَجَرَ.
شُجَيْرَةٌ ج شُجَيْرَاتٌ : شَجَرَةٌ صغيرة.
مُشَاجَرَةٌ : مص شَاجَرَ.
مُشَجَّرٌ : ١ ما كان فيه صُورَةُ الشَّجَرِ «ثوب مُشَجَّر»، ٢ [في الجغرافيا] : كل مساحة من الأرض يغطيها الشجر قليلا أو كثيرا.
§ش ج ع
شَجُعَ يَشْجُعُ شَجَاعَةً شُجَاعٌ وشَجِيعٌ : ــ الرجلُ : قوي قلبه واستهان بالحروب جراءة وإقداما.
شَجَّعَ يُشَجِّعُ تَشْجِيعًا : ١ ــه : قَوَّى قلبه وأيده «شجع المشاهدون فريقهم القومي»، ٢ ــه على فعل كذا : جَرَّأَه.
تَشَجَّعَ يَتَشَجَّعُ تَشَجُّعًا : ١ ــ المحاربُ : تقوى وأقدم «تشجعوا فحملوا على العدو»، ٢ ــ الجبانُ : تكلف الشجاعة.
تَشَجُّعٌ : مص تَشَجَّعَ.
تَشْجِيعٌ : مص شَجَّعَ.
شُجَاعٌ ج شُجْعَانٌ / شِجْعَانٌ مؤ شُجَاعَةٌ ج شُجَاعَاتٌ : جريء مقدام، عكسه جبان.
شَجَاعَةٌ : ١ مص شَجُعَ، ٢ [في الفلسفة] : إحدى أمهات الفضائل الأربع عند أفلاطون وهي الحكمة والشجاعة والعفة والعدالة.
شَجِيعٌ ج شُجَعَاءُ مؤ شجيعة ج شَجَائِعُ وشَجِيعَاتٌ : شُجَاعٌ.
§ش ج ن
شَجَنَ١ يَشْجُنُ شُجُونًا : ــ الحَمَامُ : ردد صوته.
شَجَنَ٢ يَشْجُنُ شَجْنًا فهو شاجن : ــ الأمرُ فلانا : أهمَّه وشغله وأحزنه.
شَجِنَ يَشْجَنُ شَجَنًا شَجِنٌ : ــ الشَّخْصُ : حزن.
أَشْجَنَ يُشْجِنُ إِشْجَانًا : ــه الأمرُ : أحزنه وأهاج ذكرياته.
إِشْجَانٌ : مص أَشْجَنَ.
شَجْنٌ : مص شَجَنَ٢.
شَجَنٌ : ١ مص شَجِنَ، ٢ ج أَشْجَانٌ وشُجُونٌ : حُزْنٌ وهَمٌّ «أثار هذا الخبر شجوني»، «فلان أخو شَجَن» ◆
