@نصص
↩ وَعَيَّنَهُ «نَصَّتِ الاتِّفَاقِيَّةُ عَلَى طريقة سداد القرض».
نَصَّصَ يُنَصِّصُ تَنْصِيصًا : ١ ـــ المتاعَ : جَعَل بعضه فوق بعض، ٢ ـــ غَرِيمَه : نَاقَشَهُ واسْتَقْصَى عَلَيْهِ، ٣ ـــ الشيءَ : حدده وعينه، ٤ ـــ العَرُوسَ : وضعها على المنصة.
تَنْصِيصٌ : مص نَصَّصَ ◆ عَلامَةُ التَّنْصِيصِ [في الكِتَابَةِ] : قوسان مزدوجان (« ») يوضع بينهما كل ما ينقله الكاتب من كلام غيره بالنص.
مِنَصَّةٌ ج مَنَاصُّ ومِنَصَّات : ١ كُرْسِيٌّ مُرتَفِع أو شِبْهُ سَرِير يُعَدُّ للخطيبِ ليَخْطُبَ أو الممثل ليمثل أَوْ للعَرُوسِ لتُجْلَى وَقد يُزَيَّنُ بثِيَابٍ وفُرُش «جَلَس مَعَ الوزِيرِ عَلى المِنَصَّةِ»، «منصة التصوير»، «منصة المسرح» ◆ وُضِعَ فلان على المِنَصّةِ : افْتَضَحَ وشُهِرَ، ٢ حُكْمٌ وسُلطَةٌ «سَعَى ووَصَلَ إلى مِنَصَّةِ الحُكْمِ».
نَصٌّ : ١ مص نَصَّ، ٢ ج نصوص : مَا لَا يَحْتَمِل إلَّا معنًى واحدًا أَوْ لَا يَحْتَمِلُ التَّأْويلَ «لَا اجْتِهَادَ مَعَ النَّصِّ»، ٣ صِيغَةُ الكَلَامِ الأَصْلِيَّةِ كَمَا وَرَدَتْ مِنَ المُؤَلِّفِ «وَثِيقَةٌ بِنَصِّهَا الحَرْفِيِّ»، «تُرْجِمَ الكَلَامُ نَصًّا وَرُوحًا»، «نقل الكلام بنصه ونصه»، ٤ مُنْتَهَى الشيء ومَبْلَغُه «بَلَغَ من الأَمرِ نَصَّه»، ٥ [عند الأصوليين] الـ ـــ : الكِتَابُ والسُّنَّةُ، ٦ [عند الأدباء] أثر مكتوب شعرا أو نثرا «مختارات من النصوص الأدبية».
§ن ص ع
نَصَعَ يَنْصَعُ نُصُوعًا ونَصَاعَةً فهو نَاصِعٌ : ١ ـــ الشَّيءُ : وَضَحَ وصفًا «نَصَعَ لَوْنُه» «نصعَ الأَمرُ»، «نَصَعَ الحقُّ»، ٢ ـــ بالحقِّ : أَقَرَّ بِهِ وَأدَّاهُ.
نَاصِعٌ : خَالِصٌ صاف «ثَوْبٌ ناصِعُ البَيَاضِ»، «أَحْمَرُ ناصِعٌ»، «حَقٌّ ناصِعٌ»، «أَحْسَابٌ ناصِعَةٌ»، «صورة ناصعة».
نَصَاعَةٌ : مص نَصَعَ.
نُصُوعٌ : مص نَصَعَ.
§ن ص ف
نَصَفَ يَنْصُفُ نَصْفًا ونُصُوفًا فهو ناصف : ١ ـــ النَّهارُ : بَلَغَتِ الشَّمْسُ فيهِ وَسَطَ السَّماءِ، انتصف، ٢ ـــ الشَّيْءَ نَصْفًا : بَلَغَ نِصْفَهُ «نَصَفَ الشَّيْبُ رَأْسَهُ»، «نصف الكتاب»، ٣ ـــ الشيءَ : قسمه نصفين «نصف النقود بينهما».
نَصَّفَ يُنَصِّفُ تَنْصِيفًا : ١ ـــ النَّهارُ : انتصف، ٢ ـــ النَّخْلُ : احْمَرَّ بعضُ بُسْرِهِ واخْضَرَّ بعضه، ٣ ـــ آلرَّجُلُ : صار كهلًا كأنَّه بلغَ نصف عمُره، ٤ ـــ الشّيءَ : جَعله نِصْفَيْن «نَصَّفَ التُّفَاحَةَ».
نَاصَفَ يُنَاصِفُ مُنَاصَفَةً : ـــ هُ الشّيءَ : قَاسَمَهُ إياه، أخذ نِصْفَهُ «نَاصَفَهُ مَالَهُ»، «اقتسما المالَ مناصفة».
أَنْصَفَ يُنْصِفُ إنْصَافًا : ١ ـــ الشَّخصُ : عَدَل «أَنْصَفَ القَاضِي»، ٢ ـــ الماءُ الإنَاءَ : بلَغ نِصفَه، ٣ ـــ هُ منه : اسْتَوْفَى لهُ حقَّه مِنه «أُنْصِفَ المظلومَ»، «أنصف المرؤوسَ من رئيسه».
تَنَصَّفَ يتنصف تنصفًا : ١ ـــ تِ المرأة لبست النصيف، ٢ تنصفه الشيب : بلغ نصفَ رأسه.
اِنْتَصَفَ يَنْتَصِفُ انْتِصَافًا : ١ ـــ الشّيءُ : بلغ نِصفه «انْتَصَفَ اللَّيْلُ»، ٢ ـــ الشّخصُ : طَلَبَ الإنصَافَ، ٣ ـــ مِنه : انْتَقَمَ، ٤ ـــ مِنه : اسْتَوْفَى حَقَّهُ منه كامِلًا.
اِنْتِصَافٌ : مص انْتَصَفَ.
إنْصَافٌ : مص أَنْصَفَ.
تَنْصِيفٌ : مص نَصَّفَ.
مُنَاصَفَةٌ : مص نَاصَفَ «قسمت الجائزة مناصفة بينهما».
مُنْتَصَفٌ : ـــ مِن كلِّ شيءٍ : وَسَطُه «مُنتصَف الطَّرِيقِ»، «مُنْتَصَف النَّهار»، «منتصف الساعة الثانية»، «منتصف العام»، «منتصف السبعينيات».
نَصْفٌ : مص نَصَفَ.
