@اشمأز
↩ الله فُلانًا / يَدَ فُلانٍ : أصابه / أصابها بالشَّلَلِ.
اِنْشَلَّ يَنْشَلُّ انْشِلَالًا : ــ فلانٌ : مطاوع شلّ.
إِشْلَالٌ : مص أَشَلَّ.
أَشَلُّ مؤ شلاءُ جمعهما شُلٌّ : مصاب بالشلل «عضو أشل».
اِنْشِلَالٌ : مص انْشَلَّ.
تَشْلِيلٌ : مص شَلَّلَ.
شِلَالَةٌ : خياطة خفيفة متباعدة.
شَلٌّ : مص شَلَّ¹٬².
شَلَلٌ : مص شَلَّ² «أصيب بشلل نصفي».
شَلَّاءُ : ١ مؤ أَشَلُّ، ٢ عين ــ : ذاهبة البصر.
شَلَّالٌ ج ــ ات : انحدار فجائي في مجرى النهر.
§ش ل و
أَشْلَاءٌ مف شِلْوٌ : أعضاء «ائتني بِشِلْوٍ من أشلاء هذه الشَّاة».
§ش م أ ز
اِشْمَأَزَّ يَشْمَئِزُّ اشْمِئْزَازًا : ــ من الأمر : ضاق به ونفر منه كراهة : ﴿إذا ذُكِرَ اللهُ وَحْدَهُ اشْمَأَزَّتْ قُلُوبُ الَّذِينَ لا يُؤْمِنونَ بالآخِرَةِ﴾ [قرآن].
اِشْمِئْزَازٌ : مص اشْمَأَزَّ.
§ش م ب ا ن ز ي
شَمْبَانْزِي ج ــ ات : قرد كبير من الرئيسيات.
§ش م ت
شَمِتَ يَشْمَتُ شَمَاتَةً فهو شامت : ــ بِعَدُوِّه : فرح بمكروه أصابه.
شَمَّتَ¹ يُشَمِّتُ تَشْمِيتًا : ــ ه بِعَدُوِّه : جعله يَشْمَتُ به،
شَمَّتَ² يُشَمِّتُ تَشْمِيتًا : ــ العاطسَ : دعا له بالخير قائلا : «يرحمك الله».
أَشْمَتَ يُشْمِتُ إِشْمَاتًا : ــ ه بعدوه : شَمَّتَهُ ﴿فلا تُشْمِتْ بِيَ الأَعْدَاءَ﴾ [قرآن].
إِشْمَاتٌ : مص أشمت.
تَشْمِيتٌ : مص شَمَّتَ «من السُّنة تشميت العاطس».
شَمَاتَةٌ : مص شَمِتَ، الفرح بمصيبة العدو.
§ش م خ
شَمَخَ يَشْمَخُ شُمُوخًا فهو شامخ : ١ ــ الجَبَلُ : ارتفع، ٢ ــ أَنْفُه / بأنفه : ارتفع كِبْرًا.
شَامِخٌ ج شَوَامِخُ وشُمَّخٌ : ١ مرتفع «جبل شامخ»، ﴿وَجَعَلْنَا فِيهَا رَوَاسِيَ شَامِخَاتٍ﴾ [قرآن]، ٢ رفيع عريق «نسب شامخ».
شُمُوخٌ : مص شَمَخَ.
§ش م ر
شَمَرَ يَشْمُرُ شَمْرًا : ــ الشيءَ : قَلَّصه وضم بعضه إلى بعض «شَمَرَ كُمَّهُ»، «شمر عن ساقيه».
شَمَّرَ يُشَمِّرُ تَشْمِيرًا : ــ الشيءَ : شَمَرَهُ ◆ شَمَّرَ عن ساعده / عن ساقه / عن ساعد الجد : استعد وتهيأ في أمره : خف ونَهَضَ ◆ شَمَّرَتِ الحرب عن ساقها : اشتدت.
تَشَمَّرَ يَتَشَمَّرُ تَشَمُّرًا : ــ للأمر : اسْتَعَدَّ.
تَشَمُّرٌ : مص تَشَمَّرَ.
تَشْمِيرٌ : مص شَمَّرَ.
شَمْرٌ : مص شَمَرَ.
شَمَرٌ : ١ نبات عطري من الفصيلة الخيمية، ٢ ثمر هذا النبات.
شَمَّرٌ : (انظر ألفبائيا).
§ش م ر خ
شِمْرَاخٌ ج شَمَارِيخُ : ١ سُبَاطَةُ البلح، ٢ العنقود عليه العنب.
شُمْرُوخٌ ج شَمَارِيخُ : شِمْرَاخٌ.
§ش م ز
اِشْمَأَزٌّ : (انظر : شمأز).
