↩ من الخُبَرَاءِ المَنْهَجِيِّينَ».
مَنْهَجِيَّةٌ ج مَنْهَجِيَّاتٌ : نِظَامُ طُرُقِ البَحْثِ «له دُرُوسٌ في المَنْهَجِيَّةِ».
نَهْجٌ : ١ مص نَهَجَ، ٢ ج أَنْهَجٌ ونُهُوجٌ : طَرِيقٌ مُسْتَقِيمٌ واضِحٌ «النَّهْجُ القَوِيمُ»، «نَهَجَ نَهْجَهُ»، ٣ شارِعٌ «نَهْجُ الاسْتِقْلَالِ» (تونس).
نَهَجٌ : ١ مص نَهِجَ، ٢ رَبْوٌ.
§ن ه د
نَهَدَ يَنْهَدُ نُهُودًا فهو ناهد : ١ ــ الثَّدْيُ : بَرَزَ وارْتَفَعَ، ٢ ــ تِ المرأةُ : كَعَبَ ثَدْيُها، ٣ ــ فلانٌ : نهض ⟦?⟧ضى، ٤ ــ لعدوّه : برز له وصمد.
نَاهَدَ يُنَاهِدُ نِهَادًا وَمُنَاهَدَةً : ــ الشَّخصَ : خَاصَمَهُ وَنَاهَضَه «نَاهَدَ العَدُوَّ».
تَنَاهَدَ يَتَنَاهَدُ تَنَاهُدًا : ــ القَوْمُ : خرجوا لمقاتلةِ بعضهم.
تَنَهَّدَ يَتَنَهَّدُ تَنَهُّدًا : ــ الشَّخصُ : أَخْرَجَ نَفَسَهُ بعد مَدِّهِ أَلَمًا أَوْ حُزْنًا «تَنَهَّدَتِ المريضةُ مِنَ الأَلَمِ»، «تَنَهَّدَ عن كَبِدٍ حَرَّى».
تَنَهُّدٌ : مص تَنَهَّدَ.
مُنَاهَدَةٌ : مص نَاهَدَ.
نَاهِدٌ / نَاهِدَةٌ ج نَوَاهِدُ : المرأة التي نهد ثَدْيُها.
نُهَادٌ : زُهَاءُ «هَؤُلَاءِ نُهَادُ مِائَةٍ».
نِهَادٌ : مص نَاهَدَ.
نَهْدٌ ج نُهُودٌ : ١ ثَدْيٌ، ٢ شَيْءٌ مُرْتَفِع.
نُهُودٌ : ١ مص نَهَدَ، ٢ مف نَهْد.
§ن ه ر
نَهَرَ يَنْهَرُ نَهْرًا فهو ناهر : ١ ــ الماءُ : جَرى في الأرضِ وجَعَلَ لنفسِه مَجْرًى، ٢ ــ الأرضَ : شَقَّها، ٣ ــ الشَّخصَ : زَجَرَهُ وأغضَبَه ﴿وَأَمَّا السَّائِلَ فَلَا تَنْهَرْ﴾ [قرآن].
اِنْتَهَرَ يَنْتَهِرُ انْتِهَارًا : ١ ــ النَّهْرُ : أخذ مَجْرَاهُ، ٢ ــ العرقُ : سَالَ دَمُهُ ولم يَنْقَطِعْ، ٣ ــ هُ : زَجَرَهُ بِعُنْفٍ «انْتَهَرَ السَّائِلَ».
اِنْتِهَارٌ : مص انْتَهَر.
نَهَارٌ ج أَنْهُرٌ ونُهُرٌ : ضِيَاءُ ما بَيْنَ طُلُوعِ الفَجْرِ إلى غُرُوبِ الشَّمْس ◆ نَهَارًا ولَيْلًا / لَيْلَ نهار : بدون انقطاع «يعمل المصنع نهارًا ولَيْلًا»، «يَعْمَلُ لَيْلَ نَهَارَ».
نَهَارِيٌّ : ١ منسوب إلى النَّهَار «عَمَلٌ نَهَارِيٌّ»، ٢ طَعَامٌ يُوكَلُ أَوَّلَ النَّهَارِ.
نَهْرٌ : ١ مص نَهَرَ، ٢ ج أَنْهَارٌ وأَنْهُرٌ : مَاء عَذْبٌ غَزِيرٌ جَارٍ «نَهْرُ النِّيلِ»، ٣ مَجْرَى الماءِ العَذْبِ ◆ سالَتْ تآليفُهُ أنهارًا : غَزُرت وكَثُرَتْ.
نَهَرٌ : ١ سَعَةٌ، ٢ ضياءٌ، ٣ ج أَنْهَارٌ : نَهْرٌ ﴿إِنَّ الْمُتَّقِينَ فِي جَنَّاتٍ وَنَهَرٍ﴾ [قرآن].
نَهْرِيٌّ : منسوب إلى النَّهْر «انْجِرَافٌ نَهْرِيٌّ».
§ن ه ز
نَهَزَ يَنْهَزُ نَهْزًا فهو ناهز : ١ ــ هُ : دَفَعَهُ وضَرَبَه «نَهَزَ الدَّابَّةَ»، ٢ ــ رأسَه : حَرَّكَه، ٣ ــ الدَّلْوَ من البِئْرِ : أخرجها ◆ نَهَزَتْنِي إِلَيْكَ حاجَةٌ : حَفَزَتْنِي وجاءَتْ بي إِلَيْك.
أنهز ينهز إنهازا : ــ هُ : أَنْهَضَهُ.
ناهَزَ يُنَاهِزُ مُنَاهَزَةً : ١ ــ الأمرَ : قارَبَه «نَاهَزَ الرَّضِيعُ الفِطَامَ»، «نَاهَزَتِ البُلُوغَ»، «نَاهَزَ الخَمْسِينَ مِنْ عُمُرِهِ»، ٢ ــ تْهُ الفُرْصَةُ : دَنَتْ مِنه ◆ نَاهَزَ الفُرْصَةَ : اغْتَنَمَها.
اِنْتَهَزَ يَنْتَهِزُ اِنْتِهَازًا : ــ الشَّيْءَ : قَبِلَهُ وأَسْرَعَ إلى تَنَاوُلِه ◆ انْتَهَزَ الْفُرْصَةَ : اغتنمها وبَادر إليها.
اِنْتِهَازٌ : مص انْتَهَزَ.
اِنْتِهَازِيٌّ ج ـون : مَنْ يَغْتَنِم الفُرصةَ لِمَصْلَحَتِهِ الشَّخْصِيَّةِ.
اِنْتِهَازِيَّةٌ : مص صناعي، اغْتِنَام الفُرَص واسْتِغْلَالُ جَمِيع الوَسائِلِ لِتَأْمِين المَصَالِحِ الشَّخْصِيَّةِ.
