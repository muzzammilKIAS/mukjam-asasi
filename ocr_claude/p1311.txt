@صفة
تَوَشْوَشَ يَتَوَشْوَشُ تَوَشْوُشًا : ــ القومُ : هَمَسَ بعضهم إلى بعض.
وَشْوَشَةٌ : مص وَشْوَشَ.
§و ش ي
وَشَى١ يَشِي وَشْيًا وَشِيَةً فهو وَاشٍ : ١ ــ الثّوبَ ونحوَهُ : حَسَّنَهُ بالأَلْوَانِ ونَمْنَمَهُ ونَقَشَهُ، ٢ ــ الكلامَ : كَذَبَ فيه.
وَشَى٢ يَشِي وَشْيًا وِشَايَةً واشٍ : ــ الشخصُ به : نَمَّ عليه وسَعَى به «وَشَى بِهِ لَدَى أَعْدَائِهِ».
وَشَّى يُوَشِّي تَوْشِيَةً : ١ ــ الثَّوْبَ : وَشَاهُ، ٢ ــ الشّخصَ ثَوْبًا : أَلْبَسَهُ إيَّاهُ.
تَوْشِيَةٌ : مص وَشَّى.
شِيَةٌ : ١ مص وَشَى١، ٢ ج شِيَاتٌ : كل ما خالف اللّون في جميع الجسد وفي جميع الدواب ﴿مُسَلَّمَةٌ لاَ شِيَةَ فِيهَا﴾ [قرآن].
مُوَشًّى : مُزَيَّنٌ منقوش «فُسْتَانٌ مُوَشًّى بِالفِضَّةِ».
واشٍ (الواشِي) ج ــ ون وَوُشَاةٌ : ١ حائك، ٢ ضَرَّابٌ للذَّهَب، ٣ نَمَّام.
وِشَايَةٌ : ١ مص وَشَى٢، ٢ ج وِشَايَاتٌ : السَّعْيُ بالشَّرِّ والنَّمِيمة.
وَشَّاءٌ ج ــ ون : ١ من يَبِيع الثِّيَابَ المُوَشَّاة، ٢ نَمَّامٌ مُفْسِد، ٣ كَذَّاب.
الوَشَّاءُ : (انظر : ألفبائيا).
وَشْيٌ : ١ مص وَشَى٢٬١ ٢ ج وِشَاءٌ : نَقْشُ الثَّوب.
§و ص ب
وَصَبَ يَصِبُ وُصُوبًا فهو وَاصِبٌ : ١ ــ الشّيْءُ : دَامَ وثَبَتَ، ٢ ــ الشّخصُ على الأمر : وَاظَبَ وأَحْسَنَ القِيَامَ عليه.
وَصِبَ يَوْصَبُ وَصَبًا فهو وَصِبٌ : ــ الشّخصُ : مَرِضَ ووجد وَجَعًا.
وَصَبٌ : ١ مص وَصِبَ، ٢ ج أَوْصَابٌ : مَرَضٌ وَوَجَعٌ، ٣ تَعَبٌ وفُتُورٌ في البَدَنِ.
وَصِبٌ ج وِصَابٌ : مريض متوجّع.
وُصُوبٌ : مص وَصَبَ.
§و ص د
وَصَدَ يَصِدُ وَصْدًا فهو وَاصِدٌ : ١ ــ الشّيْءُ : ثَبَتَ، ٢ ــ الشّخصُ الثّوبَ : نَسَجَهُ، ٣ ــ الشّخصُ بالمكان : أقام فيه.
أَوْصَدَ يُوصِدُ إِيصَادًا : ١ ــ البَابَ : أَغْلَقَهُ «أَبْوَابُ الوَظَائِفِ مُوصَدَة في وُجُوه الشّباب»، ٢ ــ عَلَيْهِ : ضَيَّقَ عليه وأَرْهَقَهُ.
إِيصَادٌ : مص أَوْصَدَ.
وَصْدٌ : مص وَصَدَ.
وَصِيدٌ ج وُصُدٌ وَوَصَائِدُ : ١ بيت كالحظيرة في الجِبَال للغنم وغيرها، ٢ عَتَبَةُ البَابِ، ٣ فِنَاءُ الدّارِ والبَيْتِ ﴿وَكَلْبُهُمْ بَاسِطٌ ذِرَاعَيْهِ بِالْوَصِيدِ﴾ [قرآن].
§و ص ف
وَصَفَ يَصِفُ وَصْفًا وَصِفَةً فهو وَاصِفٌ : ١ ــ الشّيْءَ : نَعَتَهُ بِمَا فيه «وَصَفَهُ بالكَرَم»، «قَالَ فيه كلاما لا يُوصَفُ»، ٢ ــ الطبيبُ الدواءَ : عيّنه باسمه ومقداره وكيفية التداوي به.
اِتَّصَفَ يَتَّصِفُ اتِّصَافًا : ١ ــ الشّيْءُ : أَمْكَنَ وَصْفُهُ، ٢ ــ الشّخصُ : صَارَ منعوتا بصفة أو صِفَاتٍ مُعَيَّنَة «اتّصَفَتْ بالكَرَمِ»، «اتّصَفُوا بالبُخْلِ».
اِتِّصَافٌ : مص اتَّصَفَ.
صِفَةٌ : ١ مص وَصَفَ، ٢ ج صِفَاتٌ : حالةٌ يكون عليها الانسانُ أو الشّيءُ كالجَمَالِ والسّوَادِ والعِلْمِ والجَهْلِ، ٣ عَلاَمَةٌ يُعْرف بها المَوْصُوف «له صِفَةُ الكَرَمِ»، ٤ [عند النحويين] : النّعت والمشتقات الوصفيّة كاسم الفاعل واسم المفعول، والصِّفَة المُشَبَّهَة، واسم التفضيل، ٥ الحالة التي تجعل المَرْءَ يتدخّلُ في أمر أو قضيّة أو نحوهما «أشرف على الاجتماع بصِفَتِهِ وَزِيرا»، «حَضَرَ بصفة غير رَسْمِيّة»، «دَافع عنه
