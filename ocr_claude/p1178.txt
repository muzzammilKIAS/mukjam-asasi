@نحس
§ن ح س
نَحَسَ يَنحَسُ نَحْسًا : ــ الشخصَ : ضَرَّهُ وآذاه
نُحِسَ : الشخصُ : أصابه النحس فهو منحوس.
نَحُسَ يَنْحُسُ نَحْسًا ونُحوسَةً فهو نَحِيسٌ : ــ الشَّخْصُ : أصَابَهُ الجهد والضُّرّ.
نَحَّسَ يُنَحِّسُ تَنْحِيسًا : ١ ــ الأخْبَارَ : تَجَسَّسَها، ٢ ــ الشّيْءَ : غَطَّاه بالنُّحاسِ «نَحَّسَ الآنِيَةَ».
اِنتحس ينتحس انتحاسًا : ــ حَظُّه : ساء وفسد.
تَنْحِيسٌ : مص نَحَّسَ.
نُحَاسٌ : مَعْدِنٌ قابِلٌ للطَّرْقِ والذَّوبان يَميلُ لونُه إلى الحُمْرَةِ أوِ الصُّفْرَةِ «نُحاسٌ أحمرُ»، «نُحاسٌ أصفرُ».
نِحَاسَةٌ : حرفة النَّحَّاس.
نُحَاسِيٌّ : منسوب إلى النُّحاس «نُحَاسِيُّ اللَّوْن»، «نُقودٌ نُحاسِيَّةٌ»، «العصر النحاسي» ◆ الآلاتُ النُّحَاسِيَّةُ : الآلاتُ الموسيقِيَّةُ النَّفْخِيَّةُ.
نَحَّاسٌ ج ــ ون : ١ صانع النحاس، ٢ بائع النحاس.
نَحْسٌ : ١ مص نَحُسَ، ٢ ج نُحُوسٌ : شَقَاءٌ بعد سَعَادَةٍ «لازمه النحس»، «جلب له النحس» ◆ أَمْرٌ نَحْسٌ : مُظْلِمٌ يومٌ نَحْسٌ : لم يُصادَف فيه خيرٌ.
نُحوسَةٌ : مص نَحُسَ.
نَحِيسٌ : ١ شديد مُجْدِبٌ «عامٌ نَحِيسٌ»، ٢ ج نُحَسَاءُ : شَقِيٌّ منحوس لا حَظَّ لَهُ «رجلٌ نَحِيسٌ».
§ن ح ف
نَحُفَ يَنْحُفُ نَحَافَةً فهو نَحِيفٌ : ــ الشَّخْصُ : كانَ رقيق الجِسْمِ خِلْقَةً، عَكسه سَمِنَ.
أَنْحَفَ يُنْحِفُ إنحافا : ــ ه المرضُ أو الهم : أهزله.
إنْحَافٌ : مص أَنْحَفَ.
نَحَافَةٌ : مص نَحُفَ.
نَحِيفٌ ج نُحَفَاءُ : رَقِيقُ الجِسْمِ مَهْزُولٌ «أجْسَامٌ نَحِيفَةٌ» ◆ هُوَ نَحِيفُ الدِّينِ : ضَعِيفُهُ.
§ن ح ل
نَحَلَ يَنْحَلُ نَحْلًا فهو ناحل : ٢ ــ الشَّخْصَ القَوْلَ : نَسَبَه إليه وليسَ بِقائِله، ٢ ــ هُ المرضُ : أرقَّ جِسمَه وأضْنَاهُ «نَحَلَهُ السُّلُّ».
نَحُلَ يَنْحُلُ نُحولًا نَحِيلٌ : ــ الشّخصُ : هُزِلَ وضَعُفَ جسمُهُ «نَحُلَتِ الفتاةُ».
أَنْحَلَ يُنْحِلُ إنحالًا : ــ المرضُ الشخصَ : أهزله وأضعفه.
اِنْتَحَلَ يَنْتَحِلُ انْتِحالًا : ١ ــ الشّيْءَ : ادِّعاهُ لنفسِه وهُوَ لغَيْرِه «انْتَحَلَ فُلانٌ هَذَا الشِّعْرَ»، «انتحل اسمَهُ»، «انْتَحَلَتْ شَخْصِيَّةَ فُلانَةَ»، ٢ ــ الشّيْءَ : انْتَسَبَ إليه وَدَانَ به «انْتَحَلَ مَذْهَبَ التَّقَدُّمِيِّينَ» ◆ انْتَحَلَ الأعْذار : التَمسَها.
اِنْتِحالٌ : مص انْتَحَلَ.
مُنْتَحَلٌ : كُلُّ وَثيقَةٍ أو مُؤَلَّفٍ مشكوكٌ في نِسْبَتِه إلى صاحِبه «وَثيقةٌ تاريخيةٌ مُنْتَحَلَة»، «أحاديثُ مُنْتَحَلَة»، «اسْمٌ مُنْتَحَل».
مُنْتَحِلٌ ج ـون : من يَنْسِبُ قَوْلًا أو كتابةً لنفسِه وهُوَ ليسَ له «خطيبٌ مُنْتَحِلٌ خُطَبَ غَيْرِه».
مَنْحَلَةٌ ج مَناحِلُ : مجموع خلايا النحل في حديقة أو سقيفة أو غيرهما من الأرض.
مَنْحُولٌ : مُنْتَحَل.
نِحَالَةٌ : تَرْبِيةُ النَّحْلِ للحُصول على العَسَل والشَّمَع «تُشَجِّعُ الدَّوْلَةُ النِّحَالَةَ».
نَحَّالٌ ج ـون : مُرَبِّي النَّحْل.
نَحْلٌ : ١ مص نَحَلَ، ٢ مف نَحْلَة : حَشَرَةٌ تُرَبَّى للحُصول على عَسَلِهَا وشَمْعِهَا ﴿وَأَوْحَى رَبُّكَ إِلَى النَّحْلِ أَنِ اتَّخِذِي مِنَ الجِبَالِ بُيُوتًا﴾ [قرآن].
نِحْلَةٌ : ١ عَطَاءٌ وفَرْضٌ ﴿وَآتُوا النِّسَاءَ صَدُقَاتِهِنَّ نِحْلَةً﴾ [قرآن]، ٢ ج نِحَلٌ : مَذْهَبٌ وعَقِيدَةٌ ودِينٌ «كِتَابُ المِلَلِ والنِّحَلِ».
نُحُولٌ : مص نَحَلَ.
