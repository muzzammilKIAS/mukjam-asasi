@نكران
مَنْكُودٌ : ١ سَيِّءٌ «حظٌّ منكود»، ٢ ج مَنَاكِيدُ : شَقِيّ غَيرُ مَحْظُوظ «مَنَاكِيدُ الحَظِّ».
نَاكِدٌ ج نَوَاكِدُ : ١ امْرَأةٌ لا يَعِيشُ ها وَلَدٌ، ٢ دَابَّةٌ قَلِيلَةُ اللَّبَنِ.
نَكَادٌ : مص نَكِدَ.
نَكَدٌ : ١ مص نَكِدَ، ٢ ج نِكَادٌ : كُلُّ شيءٍ جَلَبَ لِصَاحِبه شَرًّا «أرضٌ نَكَدٌ» ◆ رَجُلٌ نَكَدٌ : شُؤْمٌ عَسِيرٌ.
نَكِدٌ ج أَنْكَادٌ : ١ ذُو النَّكَدِ، ٢ شَاقٌّ «عَيْشٌ نَكِدٌ»، ٣ شَحِيحٌ قَلِيلُ النَّفْعِ ﴿وَالَّذِي خَبُثَ لَا يَخْرُجُ إِلَّا نَكِدًا﴾ [قرآن].
نُكْدٌ : قلة في العطاء.
§ن ك ر
نَكُرَ يَنْكُرُ نَكَارَةً فهو نَكُرٌ : ١ ــ الأمرُ : صَعُبَ واشْتَدَّ، ٢ ــ الأمرُ : صَارَ مُنْكَرًا.
نَكِرَ يَنْكَرُ نَكَرًا ونُكْرًا ونَكَارَةً فهو نَكِرٌ : ــ الشّيْءَ : جَهِلَهُ ﴿فَلَمَّا رَأَى أَيْدِيَهُمْ لَا تَصِلُ إِلَيْهِ نَكِرَهُمْ﴾ [قرآن].
نَكَّرَ يُنَكِّرُ تَنْكِيرًا : ١ ــ الشّيْءَ : غَيَّرَهُ حَتَّى أُصْبِحَ لا يُعْرَف ﴿قَالَ نَكِّرُوا لَهَا عَرْشَهَا﴾ [قرآن]، ٢ [في النّحو] ــ الإسْمَ : جَعَلَه نَكِرَةً (الرَّجُلُ ← رَجُلٌ).
نَاكَرَ يُنَاكِرُ مُنَاكَرَةً : ١ ــ هُ : خادَعَه وَرَاوَغَه، ٢ ــ هُ : قَاتَلَه وحَارَبَه.
أَنْكَرَ يُنْكِرُ إِنْكَارًا : ١ ــ الشّيْءَ : جَهِلَه «أَنْكَرَ الْمَوْضُوعَ»، ٢ ــ الأَمْرَ : جحده، لَمْ يَعْتَرِف به «أَنْكَرَ تُهْمَةَ السَّرِقَةِ المَنْسُوبةِ إليه»، «أَنْكَرَ فَضْلَهُ عليه» ﴿يَعْرِفُونَ نِعْمَةَ اللهِ ثُمَّ يُنْكِرُونَهَا﴾ [قرآن]، ٣ ــ عَلَى فلانٍ فِعْلَه : عَابَهُ ونَهاه.
تَنَاكَرَ يَتَنَاكَرُ تَنَاكُرًا : ــ القومُ : تعادَوا وأنكر بعضهم بعضا.
تَنَكَّرَ يَتَنَكَّرُ تَنَكُّرًا : ــ الشّخصُ : تغيَّرَ عنْ حالِهِ حتّى لَا يُعْرَف «تنكر في زيّ شرطي»، «تنكر المشاركون في الحفل» ◆ تَنَكَّرَ له فلان : أُخِذَ يُسِيءُ إليه بَعْدَ أن كَانَ يُحْسِنُ.
اسْتَنْكَرَ يَسْتَنْكِرُ اسْتِنْكَارًا : ــ الأَمْرَ : اسْتَقْبَحَهُ «اسْتَنْكَرَ سُلُوكَهُ».
اسْتِنْكَارٌ : مص اسْتَنْكَرَ «أثار الاستنكار».
إِنْكَارٌ : مص أَنْكَرَ ◆ إنكار الذّاتِ : اجْتِنَابُ الأَثَرَةِ والتَّضْحِيَةُ في سبيل الغَيْرِ.
أَنْكَرُ : أَقْبَحُ «صوته أَنْكَرُ الأصواتِ».
إِنْكَارِيٌّ : منسوب إلى الإنكار : كلُّ ما لَهُ عَلَاقة بالسَّلْبِ والنَّفْيِ «مَوْقِفٌ إِنْكَارِيٌّ»، «سُؤَالٌ إِنْكَارِيٌّ».
تَنَكُّرٌ : مص تَنَكَّرَ.
تَنَكُّرِيٌّ : منسوب إلى التَّنَكُّرِ «لِبَاسٌ تَنَكُّرِيٌّ» ◆ حَفْلَةٌ تَنَكُّرِيَّةٌ : حَفْلَةٌ رَاقِصة يَتَحَجَّبُ فيهَا الأَشْخَاصُ بِوُجُوهٍ مُسْتَعَارَةٍ وثِيَابٍ مُتَغَيِّرَةٍ حَتَّى لَا يُعْرَفُوا.
تَنْكِيرٌ : مص نَكَّرَ.
مُنَاكَرَةٌ : مص نَاكَرَ.
مُنْكَرٌ ج ــ ات : كل فعل أو قول تَحْكُمُ العقولُ الصَّحيحَةُ بِقُبْحِهِ أَوْ يُقَبِّحُهُ الشَّرْعُ أَوْ يَكْرَهُهُ ﴿وَيَنْهَى عَنِ الْفَحْشَاءِ وَالْمُنْكَرِ﴾ [قرآن] «النَّمِيمَةُ مِنَ المُنْكَرَاتِ» ◆ مُنْكَرٌ ونَكِيرٌ : مَلَكَانِ يَسْأَلَانِ الْمَيِّتَ في القبر.
مُنَكَّرٌ : [في النحو] غَيْرُ مُعَرَّفٍ «وَلَدٌ» اسْمٌ مُنَكَّرٌ.
نَكَارَةٌ : مص نَكُرَ ونَكِرَ.
نَكْرٌ : مص نَكِرَ.
نُكْرٌ : مص نَكِرَ.
نُكُرٌ ج أَنْكَارٌ : ١ أمر منكر، ٢ شديد ﴿يَوْمَ يَدْعُ الدَّاعِ إلى شَيْءٍ نُكُرٍ﴾ [قرآن].
نَكْرَاءُ : ١ مُنْكَرٌ «فَعْلَةٌ نَكْرَاءُ»، ٢ دَهَاءٌ وفِطْنَةٌ «امْرَأَةٌ نَكْرَاءُ»، ٣ شِدَّةٌ «أَصَابَتْهُمْ مِنَ الدَّهْرِ نَكْرَاءُ».
نُكْرَانٌ : جُحُودٌ «نُكْرَانُ الْجَمِيل» ◆ نُكْرَانُ الذَّاتِ : اجْتِنَابُ الأَثَرَةِ والتَّضْحِيَةُ في سَبِيلِ الغَيْرِ.
