@إملاص
إِمْلاصٌ : مص أَمْلَصَ.
أَمْلَصُ ج مُلْصٌ مؤ مَلْصَاءُ ج مُلْصٌ ومَلْصَاوَاتٌ : ١ ــ الرَّأْسِ : لا شَعَرَ عليهِ، ٢ رَطْبٌ لَيِّنٌ «الصَّابُونُ أَمْلَصُ».
تَمَلُّصٌ : مص تَمَلَّصَ.
مَلَصٌ : مص مَلِصَ.
مَلِصٌ : ما يسقط لملاسته ولينه.
مَلِيصٌ ج مِلاَصٌ ومَلْصَى : ١ ما يَنْزَلِقُ في الكَفِّ ولا يُمْكِنُ القَبْضُ عليه، ٢ جَنِينٌ أَسْقَطَتْه أُمُّهُ.
§م ل ط
مَلَطَ يَمْلُطُ مَلْطًا فهو مِلْطٌ : ١ ــ البَنَّاءُ الحائِطَ : طَلاهُ بالْمِلاطِ، ٢ ــ الحَلاَّقُ الشَّعَرَ : حَلَقَهُ.
مَلِطَ يَمْلَطُ مَلَطًا فهو أَمْلَطُ : ــ الشخصُ : لم يَكُنْ على جَسَدِهِ شَعَرٌ.
مالَطَ يُمَالِطُ مُمَالَطَةً : ١ ــ هُ : خَالَطَهُ، ٢ ــ هُ : قال الشَّاعِرُ نِصْفَ بَيْتٍ وأَتَمَّهُ الآخَرُ.
أَمْلَطُ مؤ مَلْطَاءُ جمعهما مُلْطٌ : مَنْ لا شعر على جسده.
مَلِيط : أملط لا شعر على جسمه.
مِلاطٌ ج مُلُطٌ : ١ اسْمَنْتٌ أو طِينٌ يُطْلَى بِهِ الحائِطُ، ٢ طين يُجْعَل بين حجرين أو آجرتين في البناء.
مَلْطٌ : مص مَلَطَ.
مَلَطٌ : مص مَلِطَ.
مُمَالَطَةٌ : مص مالط.
§م ل ق
مَلِقَ يَمْلَقُ مَلَقًا فهو مَلِقٌ : ــ الشَّخصَ وَلَهُ : تَوَدَّدَ إليه وأَعْطَاهُ بِلِسَانِه من الوُدِّ ما لَيْسَ في قَلْبِهِ.
مَلَّقَ يُمَلِّقُ تَمْلِيقًا : ١ ــ هُ بالعَصا : ضَرَبَهُ بها، ٢ ــ الأرضَ والجِدَارَ : مَلَّسَهُمَا بالْمَالَقِ.
أَمْلَقَ يُمْلِقُ إِمْلاقًا : ١ ــ تِ المرأةُ : أَسْقَطَتْ ولدَها، ٢ ــ الشَّخصُ : افْتَقَرَ ﴿وَلَا تَقْتُلُوا أَوْلَادَكُمْ مِنْ إِمْلَاقٍ﴾ [قرآن]، ٣ ــ الجِلْدَ : دَلَكَهُ حتّى يَلِينَ ◆ أَمْلَقَ الدَّهْرُ مَالَهُ : أذهبه وأخرَجهُ من يَدِهِ.
تَمَلَّقَ يَتَمَلَّقُ تَمَلُّقًا : الشَّخصَ وله : تَوَدَّدَ إليه وَلَيَّنَ كَلامَه وتَذَلَّلَ «احْذَرِ المُتَمَلِّقِينَ».
إِمْلاقٌ : مص أَمْلَقَ.
تَمَلُّقٌ : مص تَمَلَّقَ.
تَمْلِيقٌ : مص مَلَّقَ.
مالَقٌ : خَشبة عريضة تُشَدُّ إلى ثورين تُمَلَّسُ بها الأرض المثارة.
مَلَقٌ : مص مَلِقَ.
مَلِقٌ : متذلل متودد.
§م ل ك
مَلَكَ١ يَمْلِكُ مُلْكًا فهو مالك : ــ الشيءَ : استولى عليه وكان في قدرته أن يتصرف فيه بما يريد «ملك ضيعة» ◆ مِلْكُ يمينه : طوع إرادته، ملك عليه حواسه : شغله وأثر فيه ملكه الغيظ : أخذه واستبد به.
مَلَكَ٢ يَمْلِكُ مَلْكًا / مِلْكًا : ــ الشيءَ : قدر عليه وتحكّم فيه ﴿مَا أَخْلَفْنَا مَوْعِدَكَ بِمَلْكِنَا﴾ [قرآن].
مَلَكَ٣ يَمْلِكُ مُلْكًا فهو مَلِكٌ ومليك : ــ الناسَ : صار ملكا عليهم، أو كان له التصرف فيهم بالأمر والنهي وكان منهم الطاعة له ﴿إِنِّي وَجَدتُّ امْرَأَةً تَمْلِكُهُمْ﴾ [قرآن].
مَلَّكَ يُمَلِّكُ تَمْلِيكًا : ١ ــ هُ الشَّيْءَ : جعله مِلْكًا له «مَلَّكَهُ أَرْضًا»، ٢ ــ هُ القومُ عليهم : صَيَّرُوهُ مَلِكًا.
أَمْلَكَ يُمْلِكُ إِمْلاكًا : ١ ــ هُ الشَّيْءَ : جَعَلَهُ مِلْكًا لهُ، ٢ ــ القومُ فلانًا عليهم : صَيَّرُوهُ مَلِكًا عليهم، ٣ ــ هُ امرأةً : زَوَّجَه إيَّاهَا ◆ أُمْلِكَتْ فُلانَةُ أَمْرَهَا : طُلِّقَتْ أو جُعِلَ أمرُ طَلاقِها بِيَدِهَا.
تَمَلَّكَ يَتَمَلَّكُ تَمَلُّكًا : ١ ــ الشَّيْءَ : مَلَكَهُ قَهْرًا، ٢ ــ على القوم : صار مَلِكًا عَلَيْهِمْ.
