@رضا
اِرْتَضَعَ يَرْتَضِعُ ارْتِضَاعًا : ــ الطِّفْلُ ثَدْيَ أُمِّهِ : رَضَعَهُ.
اِسْتَرْضَعَ يَسْتَرْضِعُ اسْتِرْضَاعًا : ١ ــ الأبُ وَلَدَهُ : طَلَبَ له مُرْضِعَةً : ﴿وَإِنْ أَرَدْتُمْ أَنْ تَسْتَرْضِعُوا أَوْلَادَكُمْ فَلَا جُنَاحَ عَلَيْكُمْ﴾ [قرآن]، ٢ ــ الطفلُ أمَّه : طلب منها أن ترضعه.
اِرْتِضَاعٌ : مص ارتَضَعَ.
إِرْضَاعٌ : مص أَرْضَعَ.
اِسْتِرْضَاعٌ : مص استَرْضَعَ.
رَضَاعٌ : مص رَضَعَ.
رِضَاعٌ : مص رَضَعَ وراضَعَ.
رَضَاعَةٌ / رِضَاعَةٌ : مص رَضَعَ.
رَضَّاعَةٌ ج رَضَّاعَاتٌ : أداة تُمْلَأُ باللبن لإرضاع الطفل (مِرْضَعَةٌ).
رَضْعٌ : مص رَضَعَ.
رَضِيعٌ ج رُضَّعٌ ورُضْعٌ ورُضَعَاءُ : ١ طفل دون السَّنَتَيْنِ، ٢ راضِعٌ «هو رَضيعي» : راضعٌ معي : أخي من الرُّضاعة.
مُرَاضَعَةٌ : مص رَاضَعَ.
مُرْضِعَةٌ ج مَرَاضِعُ ومُرْضِعَاتٌ : من تقوم بإرضاع وَلَدِها أو وَلَدِ غيرها : ﴿وَحَرَّمْنَا عَلَيْهِ الْمَرَاضِعَ مِنْ قَبْلُ﴾ [قرآن].
مِرْضَعَةٌ ج مَرَاضِعُ : آلَةٌ يُرْضَعُ منها الطفل (رضّاعة).

رَضِيَ يَرْضَى / رِضًا / رِضًى ورِضَاءً ورُضْوَانًا / رِضْوَانًا ومَرْضَاةً راضٍ (الراضي) ورَضٍ ورَضِيٌّ مَرْضُوٌّ ومَرْضِيٌّ : ١ ــ ه / به / عنه / عليه : اختاره وقَبِلَهُ «رَضِيَ فُلانًا / بفلانٍ صاحبا»، ٢ ــ مُحَمَّدٌ فُلانَةَ زَوْجَةً لَهُ : رآها أهلا له، ٣ ــ عنه أَحَبَّهُ ﴿لَقَدْ رَضِيَ اللهُ عن المُؤْمِنِينَ إِذْ يُبَايِعُونَكَ تَحْتَ الشَّجَرَةِ﴾ [قرآن] ◆ رَضِيَ أو أَبَى : مهما كانت الظروف ، رَضِيَ اللهُ عنه : عبارة تعقب أسماء الصحابة وذوي المكانة الدينية، رَضِيَ من الغنيمة بالإياب : لم يُحَقِّقْ رِبْحا.
رَضَّى يُرَضِّي تَرْضِيَةً مُرَضٍّ (المُرَضِّي) مُرَضًّى : ــ فلانٌ أخاه : جعله يَرْضَى أو أعطاه حتى رَضَّاهُ.
رَاضَى يُرَاضِي رِضَاءً ومُرَاضَاةً مُراضٍ (المُرَاضِي) مُرَاضًى : ١ ــ ه : رَضَّاه : «راض أباك بعد أن أغضبته»، ٢ ــ ه : باراه في الرِّضَا.
أَرْضَى يُرْضِي إِرْضَاءً مُرْضٍ (المُرْضِي) مُرْضًى : ــ ه : رَضَّاه ◆ نتيجة مُرْضِيَةٌ : مقبولة.
تَرَضَّى يَتَرَضَّى تَرَضِّيًا مُتَرَضٍّ (المُتَرَضِّي) مُتَرَضًّى : ــ ه : طلب رِضَاءَهُ.
تَرَاضَى يَتَرَاضَى تَرَاضِيًا مُتَرَاضٍ (المتراضي) متراضًى عليه : ــ الرجلان : أرضى كلُّ منهما الاخر : ﴿ولا جُنَاحَ عَلَيْكُمْ فيما تَرَاضَيْتُمْ بِهِ مِنْ بَعْدِ الفَرِيضَةِ﴾ [قرآن].
اِرْتَضَى يَرْتَضِي ارْتِضَاءً مُرْتَضٍ (المُرْتَضِي) مُرْتَضًى : ١ ــ ه : رَضِيَهُ : ﴿ولا يَشْفَعُونَ إِلَّا لِمَنِ ارْتَضَى﴾ [قرآن]، ٢ ــ ه لِصُحْبَتِهِ : اختاره ورآه أَهْلًا لها.
اِسْتَرْضَى يَسْتَرْضِي اسْتِرْضَاءً مُسْتَرْضٍ (المُسْتَرْضِي) مُسْتَرْضًى : ــ ه : طلب رضاءه.
اِرْتِضَاءٌ : مص ارتَضَى.
إِرْضَاءٌ : مص أَرْضَى.
اِسْتِرْضَاءٌ : مص استَرْضَى.
تَرَاضٍ (التَّراضِي) : مص تَرَاضَى «اتفقا على حل الخلاف بينهما بالتراضي».
تَرَضٍّ (التَّرَضِّي) : مص تَرَضَّى.
تَرْضِيَةٌ : مص رَضَّى «أُعطي مكافأةً ترضية».
رَاضِيَةٌ : ١ فاعلة من الرِّضا، ٢ مَرْضِيَّةٌ ﴿فَهُوَ في عِيشَةٍ راضِيَةٍ﴾ [قرآن].
رَضٍ (الرَّضِي) ج رَضُونَ : راضٍ مُكْتَفٍ.
رِضًا / رِضًى : ١ مص رَضِيَ «أعطاه إشارة رضا»، «شعر برضا عميق»، ٢ إذن، ومنه قول الفقهاء : «يُشْهِدُ على رِضَاهَا» أي إذنها، جعلوا الإذن رِضًا لدلالته عليه، ٣ [في علم النفس] حالة من التوافق بين الكائن
