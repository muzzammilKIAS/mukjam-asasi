§خ ر ع
خَرِعَ / خَرُعَ يَخْرَعُ / يَخْرُعُ خَرَعًا وخَرَاعَةً خَرِعٌ وخَرِيعٌ : ــ الشخصُ : ضعف واسترخى.
اِخْتَرَعَ يَخْتَرِعُ اخْتِرَاعًا : ــ الشيءَ : ابتدعه وأنشأه على غير مثال سابق «اخترع للمذياع».
اِخْتِرَاعٌ : ١ مص اخْتَرَعَ، ٢ ج ــ ات : ابتداع / اكتشاف في مجال علمي «تتركز الاختراعات في الجامعات ومراكز البحوث» ◆ براءة الاختراع : شهادة من الجهة المختصة تثبت اسم صاحب الاختراع الحاجة أم الاختراع : الاحتياج يشحذ الذهن، ٣ [في المنطق] : وضع الفروض العلمية أثناء تطبيق المنهج التجريبي.
خَرَاعَةٌ : مص خَرِعَ.
خَرَعٌ : ١ مص خَرِعَ، ٢ [في الطب] : داء الكساح.
خَرِعٌ مؤ خَرِعَةٌ : ضعيف مُسْتَرْخٍ.
خِرْوَعٌ : (انظر ألفبائيا).
مُخْتَرَعٌ ج ــ ات : ما يبدعه المخترعون من أجهزة وآلات وغيرها «مخترعات علمية».
مُخْتَرِعٌ ج ــ ون : من يُبدع الشيء ويُنشئه.
§خ ر ف
خَرِف / خَرُف يَخْرَف / يَخْرُف خَرَفًا خَرِفٌ : ــ الشيخُ : فسد عقله ، وكذلك المتكلم إذا أتى بكلام ينكره العقل.
خَرَّف يُخَرِّفُ تَخْرِيفًا : ١ ــ الشخصُ : خَرِف، ٢ ــ غَيْرَهُ : نَسَبَهُ إلى الخَرَفِ.
أَخْرَف¹ يُخْرِفُ إخرافا : ــ الشخصُ بمكان كذا : أقام فيه مُدَّة الخريف.
أَخْرَف² يُخْرِفُ إخْرَافًا : ــ ه الكِبَرُ : أفسد عقله.
إخراف : مص أَخْرَف¹،².
تخريف : مص خَرَّفَ.
خُرَافَةٌ ج خُرَافَاتٌ : ١ أُسطورة أو قصة قصيرة ذاتُ مغزًى أخلاقيٌّ غالبا ما يكون أشخاصها وحوشا أو جمادات، ٢ حديثٌ باطل لا يمكن تصديقه، ٣ جملة الأفعال أو الألفاظ أو الأعداد التي يظن أنها تجلب السعد أو النحس «يسعى المجتمع العربي إلى التحرر من مخلفات عصور الجهل والخرافة».
خُرَافِيٌّ : ١ منسوب إلى الخرافة، ٢ غير علمي «مازال الفكر الخرافي يمارس تأثيره على عقول الناس حتى يومنا هذا» ◆ حكاية خرافية : (انظر : حكى).
خَرَفٌ : مص خَرِفَ.
خَرِفٌ مؤ خَرِفَةٌ فاسد العقل «خَرِفٌ لكنه متفلسف».
خَرَفِيٌّ / خَرْفِيٌّ : خريفي.
خَرُوف ج خِرَاف و خِرْفَانٌ مؤ شاةٌ ونعجة وخروفة : ذَكَرُ الضَّأْنُ «هو خروف بين شاتين» [مثل] يُضرب لمن يتزوج امرأتين «انقاد المظلوم لظالمه انقياد الخروف لجزاره».
خَرِيفٌ : الـ ــ : أحد فصول السنة، وهو بين نهاية الصيف وبداية الشتاء، والنسبة إليه : خَرِيفيٌّ وخَرَفِيٌّ وخَرْفِيٌّ ◆ خريف العمر : فترة ما بعد الشباب.
خَرِيفِيٌّ : منسوب إلى الخريف.
§خ ر ف ش
خَرْفَشَ يُخَرْفِشُ خَرْفَشَةً : ــ الشيءَ : جعله خَشِنَ الملمس، عكسه نَعَّمَ.
خَرْفَشَةٌ : مص خَرْفَشَ «يأتون بالخربشة والخرفشة. ويسمونه فنا حديثا».
§خ ر ق
خَرَقَ يَخْرُقُ خَرْقًا ١ ــ الثَّوْبَ ونحوه : شقه وثقبه، ٢ ــ الاتفاقَ / الاتفاقيةَ : نقضه / نقضها ◆ خرق إشارة المرور : لم يتوقف انتظارا لظهور الضوء الأخضر، ٣ ــ الحِصَارَ : نفذ منه ومرَّ من خلاله، ٤ ــ الأرضَ : قطعها حتى بلغ أقصاها، ٥ ــ الشيءَ
