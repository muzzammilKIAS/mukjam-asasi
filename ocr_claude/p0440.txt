@دجن
§د ج ن
دَجَنَ يَدْجُنُ دَجْناً ودُجُوناً فهو داجن : ١ ــ بالمكان : أقام به ولزمه، ٢ ــ اليومُ : كان فيه غَيْمٌ ومطر.
دَجَّنَ يُدَجِّنُ تَدْجِيناً : ــ المُدَرِّبُ الحيوانَ الوحشيَّ : جعله أليفا.
أَدْجَنَ يُدْجِنُ إِدْجَاناً : ١ ــ الشَّخْصُ بالمكان : دَجَنَ «أدجن في بيته»، ٢ ــ يومُنا : أظلم.
دَاجَنَ يُدَاجِنُ مُدَاجَنَةً : ــ ه : داهنه واستخدم الخداع معه.
إدجان : مص أَدْجَنَ.
أَدْجَنُ مؤ دَجْناءُ جمعهما دُجْنٌ : أسود «بعير أدجن».
تَدْجِين : مص دَجَّنَ.
دَاجِنٌ ج دَوَاجِنُ : ١ كُلُّ ما ألف البيوت من حيوان أو طير، ٢ مُمْطِر «سحابةٌ داجنة».
دَجْنٌ : مص دَجَنَ.
دُجْنَةٌ : ١ سَوَادٌ «دجنة الليل» ٢ ج دُجَنٌ : غيمٌ ممطر قاتم يغطي مساحة واسعة من السماء «يَوْمٌ ذو دُجْنَةٍ».
دُجُونٌ : مص دَجَنَ.
§د ج و
دَجَا يَدْجُو دُجُوًّا دَاج (الدَّاجي) : ١ ــ الليلُ : عَمَّتْ ظلمته «ليل داج»، ٢ ــ عليه الثوبُ : سَبَغَ وغَطَّى «ثوب داج»، «أَنَّهُ بَعَثَ عُيَيْنَةَ ابنَ بَدْرٍ حين أَسْلَمَ النّاسُ ودَجَا الإسلامُ» [حديث].
دَاجَى يُدَاجِي مُدَاجَاةً مُداج (المداجي) مُدَاجًى : ــ الشخصَ : داراه وجامَلَهُ، كأنه سائرَةُ العداوة.
دُجُوٌّ : مص دَجَا.
دُجَى : دُجَى اللَّيْلِ : سواده وظلمته «هي أَجْمَلُ من بدر الدُّجَى».
دَيَاج (الدياجي) : دَيَاجِي اللَّيْلِ : ظُلُمَاتُهُ.
مُدَاجَاةٌ : مص دَاجَى.
§د ح د ر
دَحْدَرَ يُدَحْدِرُ دَحْدَرَةً : ــ الحجرَ : دحرجه.
دَحْدَرَةٌ : مص دَحْدَرَ.
§د ح ر
دَحَرَ يَدْحَرُ دَحْراً ودُحُوراً : ــ ه : دفعه وطرده وأبعده «اللَّهُمَّ ادْحَرْ عنا الشّيطانَ» [دعاء مأثور]، ﴿قَالَ اخْرُجْ مِنْهَا مَذْؤُومًا مَدْحُورًا﴾ [قرآن].
اِنْدَحَرَ يَنْدَحِرُ انْدِحارًا : مطاوع دَحَر.
اِنْدِحار : مص انْدَحَرَ.
دَحْرٌ : مص دَحَرَ.
دُحُورٌ : مص دَحَرَ.
§د ح ر ج
دَحْرَجَ يُدَحْرِجُ دَحْرَجَةً : ــ الحَجَرَ : حَرَّكه فاندفع مُنْحَدِرًا.
تَدَحْرَجَ يَتَدَحْرَجُ تَدَحْرُجًا : مطاوع دَحْرَجَ.
تَدَحْرُجٌ : مص تَدَحْرَجَ.
دَحْرَجَةٌ : مص دَحْرَجَ.
§د ح س
دُحِسَ يُدْحَسُ دَحْساً مَدْحُوسٌ : ــ تِ الإصْبَعُ : أصابها الدَّاحس.
داحِسٌ : ١ بَثْرَةٌ تَظهر بين الظُّفُر واللحم، ٢ اسم فرس لقيس بن زهير العبسي ◆ داحِسٌ والغَبْراءُ (انظر ألفبائيا).
§د ح ض
دَحَضَ يَدْحَضُ دَحْضاً ودُحُوضًا فهو داحض : ١ ــ ت حُجَّتُهُ : بَطَلَتْ «حُجَّتُهُمْ داحِضَةٌ» [قرآن]، ٢ ــ ت رِجْلُهُ : زَلَقَتْ في الطين ونحوه «إنَّ دون جِسْرِ جَهَنَّمَ طَريقاً ذا دَحْضٍ» [حديث].
أَدْحَضَ يُدْحِضُ إدْحَاضًا : ١ ــ الحُجَّةَ : أبطلها، ٢ ــ قَدَمَ فلانٍ : أزلقها.
إدْحَاضٌ : مص أَدْحَضَ.
دَحْضٌ : ١ مص دَحَضَ «حجتك لا يمكن دحضها»، ٢ مكان دَحْضٌ : زَلِقٌ.
