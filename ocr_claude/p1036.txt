@كرسع
↩ الثلاثة (أ و ى).
§ك ر س ع
كَرْسَعَ يُكَرْسِعُ كَرْسَعَةً : ـــ الشَّخْصَ : ضَرَبَ كُرْسُوعَهُ.
كَرْسَعَةٌ : مص كَرْسَعَ.
كُرْسُوعٌ مذكّر ج كَرَاسِيعُ : ١ طَرَفُ الزَّنْدِ الذي يلي الخنصر وهو الناتئ عند الرُّسغ، ٢ كُرْسوعُ القَدَمِ : مَفْصِلُهَا مِن السَّاقِ.
§ك ر س ف
كُرْسُفٌ : قُطْنٌ.
كِرْسِنَّةٌ : عشب حبّه يصلح علفا للبقر والماشية.
§ك ر ش
كَرِشَ يَكْرَشُ كَرَشًا : ـــ الجِلْدُ : مسّتْهُ النارُ فَتَقَبَّضَ.
تَكَرَّشَ يَتَكَرَّشُ تَكَرُّشًا : ١ ـــ الوجهُ : تَقَبَّضَ جِلْدُهُ، ٢ ـــ القَوْمُ : تَجَمَّعُوا.
اسْتَكْرَشَ يَسْتَكْرِشُ اسْتِكْرَاشًا : ١ ـــ الجَدْيُ : عَظُمَ بَطْنُهُ، ٢ ـــ الشخصُ : عَبَسَ وتَقَبَّضَ وقَطَّبَ جَبِينَهُ.
اسْتِكْرَاشٌ : مص اسْتَكْرَشَ.
أَكْرَشُ ج كُرْشٌ مؤ كَرْشَاءُ ج كُرْشٌ وكَرْشَاوَاتٌ : عَظِيمُ البَطْنِ.
تَكَرُّشٌ : مص تَكَرَّشَ.
كَرَشٌ : مص كَرِشَ.
كَرِشٌ/كِرْشٌ مؤنث ج أَكْرَاشٌ وكُرُوشٌ : ١ في الحيوانات المجترة، هي بمثابة المعدة للانسان، ٢ عيالُ الرَّجُلِ وأصحابُهُ المقرَّبون «الأنصار كَرِشِي وَعَيْبَتِي» [حديث].
§ك ر ع
كَرَعَ يَكْرَعُ كَرْعًا وكُرُوعًا فهو كَارِعٌ : ـــ في الْمَاءِ أو الاناءِ : تناوَلَهُ بفمِهِ مُبَاشَرَةً مِنْ غَيْرِ أَنْ يشرَبَ بكَفَّيْهِ ولا بإناءٍ ◆ كَرَعَ من مَنَاهِلِ العِلْمِ : تعلّم بشغف.
تَكَرَّعَ يَتَكَرَّعُ تَكَرُّعًا : ١ غَسَلَ أَكَارِعَهُ للصَّلاةِ، ٢ تَجَشَّأَ «أكل كثيرا فأخذ يتكرّع».
تَكَرُّعٌ : مص تَكَرَّعَ.
كُرَاعٌ ج أَكْرُعٌ وَأَكَارِعُ : مادون الرُّكْبَةِ مِن الانسَانِ وما دُونَ الكَعْبِ مِنَ الدَّوَابِّ.
كُرَاعِيٌّ ج ـــ ون : بَائِعُ الأَكَارِعِ.
كَرْعٌ : مص كَرَعَ.
كُرُوعٌ : مص كَرَعَ.
§ك ر ف س
كَرْفَسَ يُكَرْفِسُ كَرْفَسَةً : ١ مشى مِشْيَةَ المُقَيَّدِ، ٢ ـــ الحيوانَ : قَيَّدَهُ فضيّقَ عليه «كرْفَسَ البعيرَ»، ٣ ـــ الشخصَ : ضيّق عليه وأَرْبَكَهُ «كَرْفَسَهُ المديرُ اليومَ» (في المغرب).
تَكَرْفَسَ يَتَكَرْفَسُ تَكَرْفُسًا : انْضَمَّ ودَخَلَ بعضه في بعض، ارتبَكَ «تَكَرْفَستُ تماما»، «تكرفس العملُ» (في المغرب).
تَكَرْفُسٌ : مص تَكَرْفَسَ.
كَرْفَسَةٌ : مص كَرْفَسَ.
كَرَفْسٌ : عشبٌ مِن فصيلة الخيميات، يُزرع كنبات طبّي كما تؤكل ضلوع أوراقه أو جذوره خضرا أو مطبوخة.
§ك ر ك
كَرَّكَ يُكَرِّكُ تَكْرِيكًا : ـــ تِ الدَّجَاجَةُ : وقَفَتْ عَنِ البَيْضِ.
تَكْرِيكٌ : مص كَرَّكَ.
كَرَّاكَةٌ ج كَرَّاكَاتٌ : آلة كبيرة لتطهير الأنهر والقنوات مِنَ الرَّمْل أو الطّين الرّاسب فيها.
كُرْكِيٌّ ج كَرَاكِيُّ : طائر كبير طويل العنق والساقين أبتر الذنب يأوي إلى الماء أحيانا.
كُرَيْكٌ ج ـــ ات : ١ خشبة يدفع بها الخباز الأرغفة ويجذبها، ٢ آلة حديدية ترفع بها عجلة السيّارة.
§ك ر ك د ن
كَرْكَدَنٌ : حَيوان مِن ذواتِ الحَوافِرِ ضخْم الجِسم
