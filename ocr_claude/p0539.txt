§ر ف ه
رَفَهَ / رَفُهَ يَرْفَهُ / يَرْفُهُ رَفَاهَةً ورَفَاهِيَةً رافِهٌ ورَفِيهٌ : ــ الشخصُ : أصاب نعمة واسعة من الرزق فلان عَيْشُهُ، ويقال كذلك : «رَفُهَ عيشُه»، «ليلة رافهة» إذا كانت لينة.
رَفَّهَ يُرَفِّهُ تَرْفِيهًا : ١ ــ الشَّخْصُ عن نفسه : نَفَّس ووسَّع وخفَّف وأزال عنها الضيق والتعب، ٢ ــ ه : نَعَّمَه وأراحه «رفّه الأبُ ابْنَهُ».
تَرَفَّهَ يَتَرَفَّهُ تَرَفُّهًا : ــ الشخصُ : رَفَهَ.
تَرَفُّهٌ : مص تَرَفَّهَ.
تَرْفِيهٌ : مص رَفَّه.
رَفَاهَةٌ : مص رَفَهَ.
رَفَاهِيَةٌ : مص رَفَهَ «يجب العمل على تحقيق مجتمع الرفاهية».
§ر ف و
رَفَا يَرْفُو رَفْوًا رافٍ (الرافي) مَرْفُوٌّ : ١ ــ الرجلُ : تزوج، ٢ ــ الرَّفَّاءُ الثوبَ ونحوه : ضم بعضه إلى بعض وأصلح ما به من ثقوب وخروق «خرق ثوب المودة بإساءته ثم رفاه بإحسانه» (وانظر : رفأ).
أَرْفَى يُرْفِي إِرْفَاءً مُرْفٍ (المُرْفِي) مُرْفًى : ١ ــ أرفتِ السفينةُ : دنت من المرفأ، ٢ ــ الرُّبَّانُ السفينةَ : أدناها من المرفأ (وانظر : رفأ).
إِرْفَاءٌ : مص أَرْفَى.
رِفَاءٌ : التئام واتفاق (وانظر : رفأ) ◆ بالرِّفَاءِ والبنين : دعاء بالالتئام والاتفاق وجمع الشمل واستيلاد البنين (يقال للمتزوج حديثا).
رَفَّاءٌ ج ــ ون : مَنْ صناعته رفو الثياب ونحوها (وانظر : رفأ).
رَفْوٌ : مص رَفَا.

رُفَيْدَة : صحابية كانت تمرض جرحى المسلمين، فاعتبرت أول ممرضة للميدان في الاسلام.
§ر ق أ
رَقَأَ يَرْقَأُ رَقْئًا ورُقُوءًا : ١ ــ الدمعُ أو الدمُ أو نحوهما : سكن وجفّ وانقطع بعد جريانه، ٢ ــ بينهم / ما بينهم : أصلح ◆ لا رَقَأَتْ دَمْعَتُهُ فلان : دعاء عليه باستمرار حزنه.
أَرْقَأَ يُرْقِئُ إِرْقَاءً : ــ الدمعَ أو الدَّمَ أو نَحْوَهُمَا : سَكَّنَهُ ◆ لا أَرْقَأَ الله دمعته / عينه : دعاء عليه باستمرار حزنه.
إِرْقَاءٌ : مص أَرْقَأَ.
رَقْءٌ : مص رَقَأَ.
رَقُوءٌ : ما / من يوقف النزف «رجل رَقُوءٌ بين القوم»، إذا كان مصلحا، «رَقُوءُ الجُرْحِ» : ما يوضع عليه من دواء ليسكنه ◆ الديةُ رَقُوءُ الدَّمِ : تُحْقِنُ دم القاتل : «لا تَسُبُّوا الإبِل فإنَّ فيها رَقُوءَ الدَّمِ ومَهْرَ الكَرِيمَةِ» [حديث].
رُقُوءٌ : مص رَقَأَ.
§ر ق ب
رَقَبَ يَرْقُبُ رَقْبًا ورُقُوبًا ورَقَابَةً فهو راقب : ١ ــ ه : انتظره : «يرقب وصول الطائرة بلهفة»، ٢ ــ ه : حَرَسَهُ وحفظه : «اُرْقُبُوا مُحَمَّدًا في أَهْلِ بَيْتِهِ» [حديث]، ٣ ــ ه : لاحظه وراعاه : «ارقب المسجون حتى لا يهرب»، ﴿إِنِّي خَشِيتُ أَنْ تَقُولَ فَرَّقْتَ بَيْنَ بَنِي إِسْرَائِيلَ وَلَمْ تَرْقُبْ قَوْلِي﴾ [قرآن]، ٤ ــ النجمَ : رصده ◆ بات يرقب النجم : أرق فلم ينم، لا يَرْقُبُ فيه إِلًّا ولا ذِمَّةً : لا يراعي عهدا ولا حقا.
رَقِبَ يَرْقَبُ رَقَبًا أَرْقَبُ : ــ الشخصُ : غَلُظَتْ رَقَبَتُهُ.
رَاقَبَ يُرَاقِبُ مُرَاقَبَةً : ١ ــ السجينَ : رَقَبَهُ أي حرسه ولاحظه، ومنه «راقب النجم» إذا لاحظه ورصده، ٢ ــ اللهَ في عَمَلِهِ : خافه وخشيه.
