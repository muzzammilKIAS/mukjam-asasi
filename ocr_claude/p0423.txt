خَلَوِيٌّ : نسبة إلى «الخَلا» (الخلاء) «منزل خَلَوِيٌّ» «نُزْهَةٌ خَلَوِيَّةٌ».
خَلِيٌّ : ١ مف خَلِيَّة، ٢ رَجُلٌ فارغ البال من الهَمّ عكسه شَجِيّ «وَيْلُ الشَّجِي من الخَلِي» [مثل].
خَلِيَّةٌ ج خَلاَيَا وخَلِيٌّ : ١ بيت النَّحْل الذي تُعَسَّل فيه، ٢ من الإبل : المُطْلَقَةُ من عِقال ترعى حيث شاءت، ٣ وَحْدَةُ بناء الأحياء من نبات أو حيوانٍ «علم الخلايا»، ٤ وحدة صغيرة من وحدات حزب أو حركة «خلايا الضباط الأحرار» ◆ الخلية الجرثومية : الخلية التي تنتج الجراثيم بعد انقسامات متتالية الخلية الدموية : المادة الحمراء في جسيمات الدم الحُمْر الخلية الذَّكَرِية : خلية تناسلية تمثل المشيج الذكر خلية نشاط : مكان يعج بالحركة والعمل.
خَوَالٍ (الخوالي) مف خالية : ١ الأمم الخوالي : البائدة، ٢ القرون الخوالي : الماضية.
مِخْلًى / مِخْلاَةٌ ج مَخَالٍ (المخالي) : كِيسٌ يُعَلَّقُ على رقبة الدابَّة يُوضَعُ فيه عَلَفُها.
§خ م د
خَمَد / خَمِد يَخْمُدُ / يَخْمَدُ خَمْدًا وخُمُودًا فهو خامد : ١ ــ الشخصُ : ماتَ / أُغْمِيَ عليه، ٢ ــ المتكلمُ : سَكَتَ، ٣ ــ النَّفَسُ : سَكَنَ وكذلك النار إذا سكن لَهَبُها وبقي جَمْرُها.
أَخْمَدَ يُخْمِدُ إِخْمَادًا : ١ ــ النارَ : أطفأها، ٢ ــ الفِتْنَةَ : أوقف انتشارها.
إِخْمَادٌ : ١ مص أَخْمَدَ، ٢ [في الكهرباء] : إيقاف التفريغ الكهربائيّ المتعدد أو المستمر، ٣ [في الكيمياء] : تحويل مادة ما من حالتها النشطة إلى حالة أخرى تكون فيها غير فعالة.
خامِدٌ : ١ ج خَوَامِدُ : ساكنٌ «هذا البركان خامدٌ منذ عام»، ٢ ج ــ ون : مَيِّتٌ ﴿إنْ كانَتْ إلَّا صَيْحَةً وَاحِدَةً فَإِذا هُمْ خامِدُونَ﴾ [قرآن].
خَمْدٌ : مص خَمَدَ.
خُمُودٌ : ١ مص خَمَدَ، ٢ [في الطب] نقص شدة الألم أو غيره من الأعراض المرضية.
§خ م ر
خَمَرَ¹ يَخْمُرُ خَمْرًا : ــ الشيءَ : ستره وكتمه.
خَمَرَ² يَخْمُرُ خَمْرًا : ــ ه : جعل فيه الخمير «خمر العجين» «خمر عصير العنب».
خَمَّرَ يُخَمِّرُ تَخْمِيرًا : ١ خَمَرَ، ٢ ــ الشيءَ : غَطاه «خَمَّرَتِ المرأة رأسها بالخِمَار».
خامَرَ يُخامِرُ مُخَامَرَةً : ــ ه داءٌ / شكٌّ : خالطه ولحقه.
تَخَمَّرَ¹ يتخمَّرُ تَخَمُّرًا : ١ ــ عصيرُ العنب / العجينُ : عَمِلَ فيه الخميرُ عَمَلَهُ، ٢ ــ تِ الفكرة : اكتملت.
تَخَمَّرَ² يتخمّر تَخَمُّرًا : ــ تِ المرأةُ بالخِمار : تَنَقَّبَتْ.
اِخْتَمَرَ يَخْتَمِرُ اخْتِمارًا : ١ ــ العصيرُ / العجينُ : تَخَمَّرَ، ٢ ــ تِ الفكرةُ : اكتملت.
اِخْتِمارٌ : مص اخْتَمَرَ.
تَخَمُّرٌ : ١ مص تَخَمَّرَ، ٢ تحلل المواد العضوية بواسطة أنزيمات الكائنات الحية.
تَخْمِيرٌ : مص خَمَّرَ.
خُمارٌ : ما يصيبُ شاربَ الخمر من سُكْرٍ أو ألم أو صداع.
