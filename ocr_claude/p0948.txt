@فك
فَكٌّ¹ : مص فَكَّ «فكُّ الاشتباك بين القوات» ◆ فَكُّ الخَطِّ : أ ــ حل رموز الكتابات القديمة ب ــ تعلم مبادىء القراءة والكتابة.
فَكٌّ² ج فُكُوكٌ : لَحْيٌ، مَغْرِسُ الأَسْنَانِ وهُمَا فَكَّانِ : أَعْلَى وَأَسْفَل.
مِفَكٌّ ج ــ ات وَمَفَاكُّ : آلة تُفَكُّ بها المسامير اللولبية ونحوها (محدثة).
§ف ك ه
فَكِهَ يَفْكَهُ فَكَهًا وفَكَاهَة فهو فَكِهٌ : ١ كان طَيِّبَ النفسِ مَزَّاحا، ٢ ــ منه : تَعَجَّبَ.
فَكَّهَ يُفَكِّهُ تَفْكِيهًا : ١ ــ ه : أطرفه بِمُلَحِ الكلام، ٢ ــ ه : أطعمه الفاكهة.
فَاكَهَ يُفَاكِهُ مُفَاكَهَةً : ــ هُ : مازحه «تَحَدَّثُوا إِلَيْهِ وفاكَهُوه حتى أَنِسَ بِهِمْ».
تَفَكَّهَ¹ يَتَفَكَّهُ تَفَكُّهًا : ١ ــ تَنَدَّمَ ﴿لَوْ نَشَاءُ لَجَعَلْنَاهُ حُطَامًا فَظَلْتُمْ تَفَكَّهُونَ﴾ [قرآن]، ٢ ــ منه : تَعَجَّبَ، ٣ ــ بالشيء : تمتع به وتلذذ.
تَفَكَّهَ² يَتَفَكَّهُ تَفَكُّهًا : أَكَلَ الفَاكِهَةَ.
تَفَاكَهَ يَتَفَاكَهُ تَفَاكُهًا : ــ وا : تمازحوا.
تَفَاكُهٌ : مص تَفَاكَهَ.
تَفَكُّهٌ : مص تَفَكَّهَ.
تَفْكِهَةٌ : مص فَكَّهَ.
فَاكِهَانِيٌّ ج ــ ون : بائِع الفاكهة، فَاكِهِيّ.
فَاكِهَةٌ ج فَوَاكِهُ : ثمار كالتُّفَّاح والعِنَب والخوخ «عصير فاكهة/فواكه»، «بستان فواكه» ◆ فاكهة الشتاء : النّار.
فَاكِهِيٌّ : فَاكِهَانِيٌّ.
فَكَاهَةٌ : مص فَكِهَ.
فُكَاهَةٌ ج فُكَاهَاتٌ : مِزَاح، ما يُتَمَتَّعُ به من طُرَف الكلام «زودنا بملحه وفكاهته».
فَكْهٌ : مص فَكِهَ.
فَكِهٌ ج ــ ون : من يُكثر من الدُّعابة والمزاح ﴿وَإِذَا انْقَلَبُوا إِلَى أَهْلِهِمُ انْقَلَبُوا فَكِهِينَ﴾ [قرآن].
مُفَاكَهَةٌ : مص فَاكَهَ.
§ف ل ت
فَلَتَ يَفْلِتُ فَلْتًا : فهو فَالِتٌ : تَخَلَّصَ «فَلَتَ الحِصَانُ مِنْ مِرْبَطِهِ».
فَلَّتَ يُفَلِّتُ تَفْلِيتًا : ــ هُ : خلصه «فَلَّتَ الابِلَ مِنْ عُقُلِهَا».
أَفْلَتَ يُفْلِتُ إِفْلاتًا : ١ نَجَا، تَخَلَّصَ «أَفْلَتَ مِنَ الْمَوْتِ»، «أَفْلَتَ مِنَ الْعِقَابِ»، ٢ ــ الشيءَ : خَلَّصَهُ «أفلتَ الدَّابَّةَ».
تَفَلَّتَ يَتَفَلَّتُ تَفَلُّتًا : تخلَّصَ «تَفَلَّتَ الجَمَلُ مِنْ عِقَالِهِ».
اِنْفَلَتَ يَنْفَلِتُ انْفِلاتًا : تخلَّصَ، نجا «انْفَلَتَ مِنْ قَيْدِهِ».
إِفْلاتٌ : مص أَفْلَتَ.
اِنْفِلاتٌ : مص انْفَلَتَ.
تَفَلُّتٌ : مص تَفَلَّتَ.
تَفْلِيتٌ : مص فَلَّتَ.
فَلْتٌ : مص فَلَتَ.
فَلْتَةٌ ج فَلَتَاتٌ : ١ هَفْوَة غير مقصودة «ما قالَهُ كان فَلْتَةَ لِسَانٍ»، ٢ حالة متميّزة «كان فلتة زمانه».
§ف ل ج
فُلِجَ يُفْلَجُ فهو مَفْلُوجٌ : أصابه داءُ الفالج «انهارت المؤسسةُ عندما فُلِجَ مُدِيرُهَا».
فَالِجٌ : شَلَل يُصيب أحد شِقَّي الجِسْم «أصابه فَالِجٌ أَلْزَمَهُ الفِرَاشَ».
§ف ل ح
فَلَحَ¹ يَفْلَحُ فَلاحًا فهو فَالِحٌ : ظَفِرَ بما يُرِيدُ ⟦?⟧ «بَذَلَ جُهْدًا كبيرًا ولكنه لم يَفْلَحْ».
فَلَحَ² يَفلَحُ فَلْحًا فهو فَالِحٌ : ــ الشيءَ ⟦?⟧ الحديد بالحديد يُفْلَحُ» [مثل]، «فلح الأرضَ للزراعة».
