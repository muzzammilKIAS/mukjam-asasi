§ب ش ر
بَشَرَ¹ يَبْشُرُ بِشْرًا / بُشْرًا : ١ ــ الشخصُ بالخبر : فرح به، ٢ ــ الشخصَ بالأمر : فرّحه به «بشر صديقه بخبر نجاحه».
بَشَرَ² يَبْشُرُ بَشْرًا : ١ ــ الخُضَرَ أو الفاكهة أو نحوهما : قَشَرها، ٢ ــ الجُبْنَ أو البصلَة أو البرتقالة أو نحوها : حكها بالمبشرة ليقطعها قطعا صغيرة.
بَشُرَ يَبْشُرُ بَشارةً بَشيرٌ : ــ الشخصُ : حَسُنَ وجَمُل.
بَشِرَ يَبْشَرُ بِشْرًا : ــ الشخصُ به : بَشَرَ به.
بَشَّرَ يُبَشِّرُ تَبْشيرًا : ١ ــ صديقه أزجى اليه خبرًا سارًا ﴿يازَكَرِيّا إِنّا نُبَشِّرُكَ بِغُلامٍ اسْمُهُ يَحْيى﴾ [قرآن]، ٢ ــ بالخير : وعد «ظهرت بوادِرُ تُبَشِّرُ بحلّ الأزمة» ﴿وَبَشِّرِ الَّذينَ آمَنوا وَ عَمِلوا الصّالِحاتِ أَنَّ لَهُمْ جَنّاتٍ﴾ [قرآن]، ٣ ــ بفكرة أو دين : عرف بها ودعا اليها «مازال لبعض الكنائس الغربية مُبَشِّرون يدعون الناس الى المسيحية».
باشَرَ يُباشِرُ مباشَرةً : ١ ــ العَمَلَ وبِه : زاوله ونهض بعبئه «باشر الوزراء أعمالهم بعد تأليف الحكومة الجديدة» «باشر مسؤوليته»، «باشر المفاوضات»، ٢ ــ الصناعة : تعاطاها وبدأ ممارستها، ٣ ــ المرأةَ : لامَسَها ودخل عليها.
أَبْشَرَ يُبْشِرُ إِبْشارًا : ــ الشخصُ : فرح وسُرّ ﴿وَأَبْشِروا بِالْجَنَّةِ الَّتي كُنتُم تُوعَدونَ﴾ [قرآن].
اِسْتَبْشَرَ يَسْتَبْشِرُ اسْتِبْشارًا : ١ ــ الشخصُ : فرح وسُرّ ﴿يَسْتَبْشِرون بِنِعْمَةٍ مِنَ اللّهِ وَفَضْلٍ﴾ [قرآن]، ٢ ــ صديقَه : بَشّره ◆ استَبْشَرَ به خيرًا : تأمل منه خيرًا وتفاءل به.
