@أذاق
↩ فُلانَة : مَسَّها ◆ ذاق منه الذُّلَّ، عانى من ظلمه وإهانته ذُقْتُ فلانا/ما عِنْدَ فُلانٍ : خَبَرْتُهُ وعرفت حقيقته ما ذاق طَعْمَ النَّوْمِ : ظل مُؤَرَّقًا.
أَذَاقَ يُذِيقُ إِذَاقَةً : ــ ه العَذابَ : جعله يذوقه ﴿فَأَذَاقَهَا اللهُ لِبَاسَ الجُوعِ والخَوْفِ﴾ [قرآن] ◆ أذاقه الأَمَرَّيْنِ : بالغ في إيذائه.
تَذَوَّقَ يَتَذَوَّقُ تَذَوُّقًا : ١ ــ الطعامَ : ذاقه مرة بعد مرة، ٢ ــ العملَ الفنّي : استمتع بما فيه من جمال «تذوق الموسيقى».
إِذَاقَةٌ : مص أَذَاقَ.
تَذَوُّقٌ : مص تَذَوَّقَ.
ذَوَاقٌ : ١ مص ذَاقَ، ٢ أَيُّ مأكولٍ أو مشروب : «ماذُقْتُ ذَوَاقًا» أي شيئا، «لَمْ يَكُنْ يَذُمُّ ذَوَاقًا» [حديث] .
ذَوْقٌ : ١ مص ذَاقَ، ٢ حَاسَّةٌ تُمَيَّزُ بها خواص الأجسام الطَّعْمِيَّة بوساطة الجهاز الحسي في الفم ومركزه اللسان، ٣ ج أذواق : حاسَّةٌ معنوية تُمَيِّزُ في العمل الفني بين الجيد والرديء «أنت تتمتع بذوق سليم»، «هو حسن الذوق للشعر».
ذَوَقَانٌ : مص ذَاقَ.
ذَوَّاقٌ / ذَوَّاقَةٌ : ١ متميز في تذوقه الفني «أديب ذوّاقة»، ٢ كثير النكاح «رجل ذَوَّاق» «إنَّ الله لا يُحِبُّ الذَّوَّاقينَ والذَّوَّاقَاتِ» [حديث].
مَذَاقٌ : ١ مص ذاق، ٢ طَعْمُ الشيء «مَذَاقُهُ طَيِّبٌ».
§ذ و ل ق
ذَوْلَقٌ : ــ اللسان : طَرَفُهُ.
§ذ و ى
ذَوَى / ذَوِيَ يَذْوِي / يَذْوَى ذُوِيًّا ذَاوٍ (الذاوي) : ١ ــ العودُ : ذَبَلَ نتيجة قلة مائه أو ضرب الحَرِّ له، ٢ ــ الشيخُ : ضَعُفَ.
أَذْوَى يُذْوِي إِذْوَاءً مُذْوٍ (المذوي) مُذْوًى : ــ ه الحَرُّ / العطشُ : أذبله.
إِذْوَاءٌ : مص أذوى.
ذُوِيٌّ : مص ذَوَى.
§ذ ي
ذي : ١ اسم اشارة للمفردة المؤنثة، وتَرِدُ بهاء التنبيه وبدونها، ٢ بمعنى صاحب (من الأسماء الخمسة) في حالة الجر ◆ جاء من ذي نفسه : طائعا كان ذلك من ذي قَبْلُ : أي من الزمان الماضي غَيْرُ ذي موضوع : لا أهمية له.
§ذ ي ع
ذَاعَ يَذِيعُ ذُيُوعًا فهو ذائع : ــ الأَمْرُ / الشيء : فشا وانتشر «ذاع الخبر» «ذاع السِّرُّ»، «ذاع الجَرَبُ في جلده» ◆ ذائعُ الصِّيتِ : منتشر الذكر.
أَذَاعَ يُذِيعُ إِذَاعَةً : ١ ــ ه / أذاع به : أفشاه ونشره ﴿وَإِذا جاءَهُمْ أَمْرٌ مِنَ الأَمْنِ أَوِ الخَوْفِ أَذَاعُوا به﴾ [قرآن]، ٢ ــ النشرةَ / الحديثَ / الأغنيةَ : نقلها بواسطة الجهاز اللاسلكي عبرَ الاذاعة (المسموعة / المرئية).
اِنْذَاعَ يَنْذَاعُ اِنْذِياعًا : ــ الخَبَرُ : انتشر.
إِذَاعَةٌ : ١ مص أَذَاعَ، ٢ ج إذاعات : مَبْنَى الإذاعة : «أنا ذاهب للإذاعة الآن» ◆ الإذاعة المرئية : التلفزيون الإذاعة المسموعة : الراديو دار الإذاعة / مَحَطَّةُ الإذاعة : مكان الإرسال الإذاعي.
اِنْذِياعٌ : مص انْذَاعَ.
ذُيُوعٌ : مص ذَاعَ.
مِذْيَاعٌ ج مذاييع : ١ جهاز الراديو، ٢ من لا يكتم السر «رجل مذياع».
مُذِيعٌ ج ــ ون مؤ مذيعة ج مذيعات : مَنْ يتولى النقل في دور الاذاعة المسموعة والمرئية ◆ مذيعُ الرَّبْطِ بين الفقَرَاتِ : من يربط بين فقرات البرامج الاذاعية مذيع النَّشْرَةِ الإخبارية : قارىء نشرة الأخبار.
