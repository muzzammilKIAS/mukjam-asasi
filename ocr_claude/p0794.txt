@أطغى
أَطْغَى يُطْغِي إطْغاء مُطْغٍ (المُطْغِي) مُطْغًى : ــ ه : جعله طاغيًا.
إِطْغاءٌ : مص أطْغَى.
طاغوتٌ ج طواغيتُ : (انظر الفبائيا).
طاغِيةٌ ج طُغاةٌ : شديد الظُّلْم «كان فِرْعَوْن طاغِية».
طُغْيانٌ : ١ مص طَغَى، ٢ [في علم الاجتماع] تجاوز الحد المعقول في الظلم.
§ط ف ء
طَفَأَ يُطْفَأُ تَطْفِئَةً : ــ النارَ ونحوها : أخمدها، قضى عليها.
أَطْفَأَ يُطْفِئُ إطْفاءً : ــ النّارَ أو الحَماسَ أو الفِتْنة أو نحوها : أخمدها، قَضى عليها ﴿كُلَّما أَوْقَدُوا نارًا لِلْحَرْبِ أَطْفَأَهَا الله﴾ [قرآن].
اِنْطَفَأَ يَنْطَفِئُ انْطِفاءً : ــ تِ النارُ أو الحماسُ أو الفِتنة أو نحوها : خَمَدَت.
إطْفاءٌ : مص أطْفَأَ.
إِطْفائِيّة ج إطْفائياتٌ : مركز/دائرة الإطفاء.
اِنْطِفاءٌ : مص انْطَفَأَ.
تَطْفِئَةٌ : مص طَفَأَ.
مَطَافِئُ مف مِطْفَأة : أدوات إخماد الحريق ◆ رِجال المَطافِئ : الرِّجال الذين يُكافِحون الحَريق.
مِطْفَأةٌ ج مطافئُ : أداة إخماد الحريق ◆ مطفأة السجائر : وعاء تطفأ فيه السجائر.
§ط ف ح
طَفَحَ يَطْفَحُ طَفْحًا فهو طَافِحٌ : امْتَلأَ حتى فاض «طَفَحَ الإناءُ»، «طَفَحَت البِئر» ◆ طَفَحَ الكيْلُ : بَلَغَ الأمرُ حَدًّا لا يُحْتمل طَفَحَ وَجْهُهُ بالبِشْرِ أو الفَرَحِ : ظَهَرَ البِشْرُ أو الفرح فيه «طفح بالحيوية».
طَفِحَ : ــ تِ البَشَرَةُ أو الجلد : ظهر عليه الطفح.
طَفْحٌ : ١ مص طَفَحَ «طفح المجارى»، «طفح المياه»، ٢ مرض جلدي تصحبه بثور ودمامل.
طَفَّحَ : ــ ه : جعله يطفح.
§ط ف ر
طَفَرَ يَطْفِرُ طَفْرًا فهو طافر : قَفَزَ «طَفَرَ الدَّمْعُ من عَيْنَيه».
طَفْرٌ : مص طَفَرَ.
طَفْرَةٌ ج طَفَرَاتٌ : ١ قَفْزة، ٢ انتقال سريع من حالة إلى أخرى «حقّق العلم طفرة كبيرة».
§ط ف ف
طفيف (تُستعمل مع غير المعدود) : قليل «كَمِيّة طَفيفة»، «بَرْد طفيف».
§ط ف ق
طَفِقَ يَطْفَقُ طَفْقًا : ــ يَفْعل كذا : أُخذَ يفعل كذا، جعل يفعل كذا ﴿وطَفِقَا يَخْصِفَانِ عَلَيْهِما مِنْ وَرَقِ الجَنَّةِ﴾ [قرآن].
طَفْق : مص طَفِقَ.
§ط ف ل
أَطْفَلَ يُطْفِلُ إطْفالًا : ــ تِ المرأةُ : رُزِقَت بِطِفل.
تَطَفَّلَ يَتَطَفَّلُ تَطَفُّلًا : ١ تَدَخَّلَ فيما لا يعنيه أو ما ليس من اختصاصه «رجل متطفل»، «نظرة تطفل»، ٢ ــ على الشخص : ذَهَب إليه من غير دَعْوة.
إطْفال : مص أطْفَلَ.
تَطَفُّلٌ : مص تَطَفَّلَ.
تَطَفُّلِيٌّ : منسوب الى التطفل «نظرة تطفلية».
طَفْلٌ ج طُفُول وطِفالٌ : ١ طين يتصلب على هيئة رقائق بتأثير ضغط ما فوقه من الصخور، ٢ مادة إذا أضيف إليها الماء تكونت منها طينة تقبل التشكل، ومن مثلها تصنع الأواني الفخارية.
طِفْلٌ ج أَطْفَالٌ : وَلَد صغير «كانَ أَبًا لثلاثة أطفال» ﴿وإذا بَلَغَ الأطْفَالُ مِنْكُمُ الحُلُمَ فَلْيَسْتَأْذِنُوا﴾ [قرآن] ◆ روضة الأطفال : (انظر : روضة) طبيب الأطفال : (انظر : طبيب).
