↩ حَمَلُوهُ عَلَى نَعْشٍ.
نَعَّشَ يُنَعِّشُ تَنْعِيشًا : ١ ــ هُ : رَفَعَهُ، ٢ ــ هُ : قَالَ لَهُ : أنْعَشَكَ الله.
أَنْعَشَ يُنْعِشُ إنْعَاشًا : ١ ــ هُ : أنْهَضَهُ وأقَامَهُ «أنْعَشَ الدَّوَاءُ الْمريضَ»، «أنعش اقتصاد البلد»، ٢ ــ هُ : سَدَّ فَقْرَهُ ◆ أنْعَشَهُ من كَبْوَتِه : أنْهَضَهُ وقَوَّى جَاشَهُ.
اِنْتَعَشَ يَنْتَعِشُ انْتِعَاشًا : ــ الشّخصُ / الحَيوانُ : نَشِط ونَهَضَ «اعْتَدَل الجوُّ فانْتَعَشَ النَّاسُ»، «انْتَعَشَتِ الطّيورُ بَعْدَ فُتورِهَا».
اِنْتِعَاشٌ : ١ مص انْتَعَشَ، ٢ نَشَاطٌ ونَهْضَةٌ «انْتِعَاشٌ اقتِصَادِيٌّ»، «انْتِعَاشٌ فِكْرِيّ».
إنْعَاشٌ : ١ مص أنْعَشَ، ٢ إعَادَةُ الحَيَاةِ إلى شخْصٍ أو حيوانٍ فَقَدَ مَظَاهِرَها مِنْ غَرَقٍ أَوْ صَدْمَةٍ كهربائيَّةٍ أو نحوِها «أنعَشَ المُمَرِّضُ الغَريقَ»، «سَيَّارَةُ إسْعَافٍ مُزَوَّدَةٌ بِأجْهِزَةِ الإنْعَاشِ»، «غرفة الانعاش في المستشفى».
تَنْعِيشٌ : مص نَعَّشَ.
مُنْعِشٌ : مُنَشِّطٌ :«دَوَاء مُنْعِشٌ»، «كَلَامٌ مُنْعِشٌ»، «مَوَاقِف أخْلاقِيَّةٌ مُنْعِشَةٌ».
نَعْشٌ : ١ مص نَعَشَ، ٢ ج نُعُوشٌ : ما يُحْمَلُ عليه المَيِّتُ ◆ بَنَاتُ نَعْشٍ الكُبْرى [في الفلك] : سَبْعَةُ كواكِبَ تُشاهَد جِهَةَ القُطبِ الشَّمَالِيِّ وبِقُرْبها سَبْعَةُ أُخرى تُسَمَّى بنات نعشٍ الصُّغرى.
§ن ع ق
نَعَقَ يَنْعِقُ نَعْقًا ونَعِيقًا ونُعَاقًا فهو ناعق : ١ ــ الغُرَابُ : صَاحَ، ٢ ــ الرَّاعِي بِغَنَمِه : صَاحَ بهَا وزَجَرَهَا.
ناعِقٌ ج نَعَقَةٌ ونُعَّاق : ٢ فَاعِلٌ من نَعَقَ «غُرَابٌ ناعِقٌ»، «رُعَاةٌ نَعَقَةٌ» ◆ أتَى كُلُّ ناعِقٍ وناعِرٍ : كلَّ النَّاسِ فلانٌ ناعِقَةُ بَنِي فُلان : صَائحٌ باسمِهم، ٢ [في الفلك] النَّاعِقَانِ : كَوْكَبَانِ من كواكب الجَوْزاءِ.
نُعَاقٌ : مص نَعَقَ.
نَعْقٌ : مص نَعَقَ.
نَعِيقٌ : مص نَعَقَ.
§ن ع ل
نَعَلَ يَنْعَلُ نَعْلًا : ١ ــ هُ : ألْبَسَهُ نَعْلًا «نَعَلَتِ الأُمُّ وَلَدَهَا»، ٢ ــ الدَّابَّةَ : ألْبَسَ حافِرَهَا أَوْ خُفَّها ما يَقِيهَا.
نَعَّلَ يُنَعِّلُ تَنْعِيلًا : ١ ــ الدَّابَّةَ : نَعْلَها، ٢ ــ الحِذاءَ أو الخُفَّ : وَضَعَ في أسْفَلِه جِلْدًا.
اِنْتَعَلَ يَنْتَعِلُ انْتِعَالًا : ــ الشّخصُ : لَبِسَ النَّعْلَ ◆ انْتَعَلَ الأرضَ : سَافَرَ فِيهَا راجِلًا بِدُون دَابَّةٍ.
اِنْتِعَالٌ : مص انْتَعَلَ.
تَنْعِيلٌ : مص نَعَّلَ.
ناعِلٌ : ١ فَاعِلٌ من نَعَلَ، ٢ ذُو نَعْلٍ، عكسه حَافٍ «رجُلٌ ناعِلٌ»، ٣ حِمَارُ الوَحْشِ.
نَعَّال : صانع النَّعْل.
نِعالة : حرفة النَّعَّال.
نَعْلٌ : ١ مص نَعَلَ، ٢ ج نِعالٌ وأنْعُلٌ : حِذاءٌ، ٣ حَدِيدٌ مُقَوَّسٌ لِحِمَايَةِ حَافِرِ الدَّابَّةِ أو جِلْدٌ يُوقى به أسفل الخف.
§ن ع م
نَعُمَ يَنْعُمُ نُعومَةً فهو نَاعِمٌ : ١ ــ الشيءُ : دَقَّ ولَانَ مَلْمَسُهُ، ٢ ــ عَيْشُه : طابَ وكانَ مَيْسُورًا.
نَعِمَ يَنْعَمُ نَعْمًا ونَعِيمًا فهو ناعم : ١ ــ الشَّيْءُ : لَانَ مَلْمَسُهُ، ٢ ــ عَيْشُهُ : كان مَيْسُورًا، ٣ ــ بَالُهُ : هَدَأَ وَاسْتَرَاحَ، ٤ ــ بِهِ : سُرَّ واسْتَمْتَعَ «نَعِمْتُ بِلقَائِهِ»، «نَعِم به عَيْنًا».
نِعْمَ : فِعْلٌ غيرُ مُتصرِّف لإنشاءِ المَدْح عكسه بِئْسَ «نِعْم ما صَنَعْتَ» ﴿نِعْمَ ٱلْمَوْلَى ونِعْمَ النَّصيرُ﴾ [قرآن]، وتُلحق بِهَا (ما) ﴿إنْ تُبْدُوا الصَّدَقَاتِ فَنِعِمَّا هِيَ﴾ [قرآن].
