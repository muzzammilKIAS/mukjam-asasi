§ر خ م
رَخَمَ / رَخُمَ يَرْخُمُ رَخَامَةً رَخيم : ــ الصوتُ : لان وسهل.
رَخَّمَ يُرَخِّمُ تَرْخِيمًا : ١ ــ الشيءَ : سهَّله ولَيَّنه، ٢ [في النحو] ــ الاسمَ : حذف آخره تخفيفا وبخاصةٍ في النداء مثل يا فاطمُ (بدلا من : يا فاطمةُ)، ٣ ــ البيتَ : غطّى أرضه بالرخام.
تَرْخِيمٌ : مص رَخَّمَ.
رُخَامٌ واحدته رُخَامَةٌ : ضَرْبٌ من الحجر يمكن صقل سطحه بسهولة : «غَطَّى مدخل بيته بالرخام».
رَخَامَةٌ : مص رَخُمَ.
رَخَّامٌ ج ــ ون : بائع الرُّخام أو صانعه.
رَخَمٌ واحدته رَخَمَةٌ : طائر غزير الريش أبيض اللون مبقع بسواد؛ له منقار طويل قليل التقوس رمادي اللون إلى الحمرة، وجناحه طويل مذبب.
رَخيمٌ : رقيق سهل «صَوْتٌ رخيم»، «كلامٌ رخيم الحواشي».
§ر خ و
رَخا١ يَرْخو رَخاءً ورَخاوَةً رَخِيٌّ : ــ الشيءُ : اتسع «رَخا عَيْشُهُ».
رَخا٢ يَرْخو رَخاوَةً رَخْوٌ / رُخْوٌ / رِخْوٌ : ــ الشيءُ : صار هشًّا لينا.
رَاخى يُراخِي مُرَاخاةً مُرَاخٍ (المُرَاخِي) مُرَاخًى : ــ الشخصُ بين العملين : باعد بينهما وتوقف بعض الوقت بينهما «يخال الجبان فراره يراخي أجله» ◆ راخيْتُهُ عني : باعدته.
أَرْخى يُرْخِي إرْخاءً مُرْخٍ (المُرْخِي) مُرْخًى : ١ ــ الشخصُ : صار في رَخاء، ٢ ــ الشيءَ : جعله رخوا، ٣ ــ السِّتْرَ : أسدله «أرخى الليلُ سُدُولَهُ»، ٤ ــ الشيءَ : طوّله ووسَّعه : «أرخى له القيد»، «أرخى الدابة» : إذا طوَّل لها من حبلها ◆ أرخى عِمامَتَهُ : أَمِنَ واطمأنَّ، أرخى له العِنَانَ : خلّاه وشأنه.
تَرَاخى يَتَراخى تَراخِيًا مُتَراخٍ (المُتَراخِي) : ــ عنه : فتر وتأخر وتقاعس «تراخى عن الأمر» ◆ تَرَاخَت السَّماء : أبطأ مطرها تَرَاخى ما بَيْنَهُمَا : تباعد.
اِرْتَخى يَرْتَخِي ارْتِخاءً مُرْتَخٍ (المُرْتَخِي) : ١ ــ الشيءُ : صار رخوا، ٢ ــ الشخصُ : فترت همته وضعف.
اِسْتَرْخى يَسْتَرْخِي اسْتِرْخاءً مُسْتَرْخٍ (المُسْتَرْخِي) : ١ ــ الشخصُ : استلقى مُرْخِيًا عضلاته، ٢ ــ به الأمر : انبسط له واتسع وحَسُنَ وسَهُلَ بعد الشدة والضيق.
اِرْتِخاءٌ : مص ارتخى.
إرْخاءٌ : مص أَرْخى.
اِسْتِرْخاءٌ : مص استَرْخى.
تَرَاخٍ (التَّراخي) : مص تَرَاخى.
رَخاءٌ : مص رَخا١ «هو في رخاء من العيش».
رُخاءٌ : ريح رُخاءٌ : لينة لا تحرِّك شيئا : ﴿فَسَخَّرْنا لَهُ الرِّيحَ تَجْرِي بِأَمْرِهِ رُخاءً حَيْثُ أَصابَ﴾ [قرآن].
رَخاوَةٌ : مص رَخا١،٢.
رَخْوٌ / رُخْوٌ / رِخْوٌ : ١ لَيِّنٌ سَهْلٌ : «عيشنا ــ والحمد لله ــ رخو»، ٢ من الأصوات : ما تم إخراجه بتضييق مجرى الهواء كالزاي والسين.
رَخِيٌّ : ١ واسع ناعم «عيش رخي»، ٢ ــ البالِ : هادئ النفس في نعمة وخصب وسعة حال.
مُراخاةٌ : مص رَاخى.
§ر د ء
رَدَأَ يَرْدَأُ رَدْءًا : ١ ــ الحائطَ : دَعَمَهُ وقوّاه، ٢ ــ الشخصَ : أعانه.
رَدُؤَ يَرْدُؤُ رَدَاءَةً رَدِيءٌ : ١ ــ الشيءُ : فَسَدَ «ردؤ الطقس»، «ردؤ خطه»، ٢ ــ الرجلُ : صار وضيعا خسيسا.
رَدَاءَةٌ : مص رَدُؤَ «رداءة الجو»، «رداءة الخط».
رَدْءٌ : مص رَدَأَ.
