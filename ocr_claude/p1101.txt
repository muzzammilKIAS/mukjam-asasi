@لمسة
لَمَّجَ يُلَمِّجُ تَلْمِيجًا : ــ هُ : أَطْعَمَهُ لُمْجَةً «ما لَمَّجُوا ضَيْفَهُمْ بِشَيْءٍ»، «لَمَّجَ المُدِيرُ التَّلاَمِيذَ خُبْزًا وَزُبْدَةً وَجُبْنًا».
تَلَمَّجَ يَتَلَمَّجُ تَلَمُّجًا : ــ الشّخصُ : أَكَلَ لُمْجَةً.
تَلْمِيجٌ : مص لَمَّجَ.
تَلَمُّجٌ : مص تَلَمَّجَ.
لَمْجٌ : مص لَمَجَ.
لُمْجَةٌ ج لُمَجٌ : مَا يُؤْكَلُ من طعام خَفِيف بين الغَدَاءِ والعَشَاء «اللُّمْجَةُ ضَرُورِيّةٌ لِنُمُوِّ الأَطْفَالِ».
§ل م ح
لَمَحَ يَلْمَحُ لَمْحًا فهو لاَمِحٌ : ١ ــ البَصَرُ : امْتَدَّ إلى الشّيْء، ٢ ــ الشّيْءَ وإِلَيْهِ : أَبْصَرَهُ بِنَظَرٍ خَفِيف أو اخْتَلَسَ النَّظَرَ إليه «لَمَحَهُ يَجْرِي».
لَمَّحَ يُلَمِّحُ تَلْمِيحًا : ــ الشّخصُ إلى الشّيْءِ : أَشَارَ إليه ولم يُصَرِّحْ «لَمَّحَ إلى المَوَدَّةِ القائمة بَيْنَهُمَا».
لاَمَحَ يُلاَمِحُ مُلاَمَحَةً : ــ هُ : نظر إليه خِلْسَةً.
أَلْمَحَ يُلْمِحُ إِلْمَاحًا : ١ ــ الشّيْءَ : أَبْصَرَهُ بِنَظَرٍ خَفِيف، ٢ ــ إِلَيْهِ : اسْتَرَقَ النَّظَرَ إِلَيْهِ، ٣ ــ إليه شيئا وبِهِ : أَشَارَ «أَلْمَحَ إِلَيْهِ بِأَنَّهُ مُخْطِيءٌ».
إِلْمَاحٌ : مص أَلْمَحَ.
تَلْمِيحٌ : ١ مص لَمَّحَ، ٢ ج تَلاَمِيحُ : إشارة «في كلاَمِهِ تَلاَمِيحُ لأمورٍ هامّة»، «تَلْمِيحًا إلى كَذَا أَقُولُ...».
لَمْحٌ : مص لَمَحَ ◆ في لَمْحِ البَصَرِ : بِسُرْعَة «عَادَ في لَمْحِ البَصَرِ».
لَمْحَةٌ : نظرة عاجلة.
مَلاَمِحُ مف مَلْمَحٌ : ١ ما يَظْهَرُ من أَوْصَافِ الوَجْهِ ومن مَظْهَرِ الإنسانِ «ذَكَرَ له مَلاَمِحَ فُلاَنٍ فَعَرَفَهُ»، ٢ مَشَابِهُ «هذه البِنْتُ لَهَا مَلاَمِحُ أُمِّهَا»، ٣ [في الرّسم] المَلاَمِحُ والظِّلاَلُ : أماكِنُ مُضَاءَةٌ وأُخرى مُظْلِمَةٌ «رَسَّامٌ بارِعٌ في المَلاَمِحِ والظِّلاَلِ».
§ل م ز
لَمَزَ يَلْمُزُ/يَلْمِزُ لَمْزًا فهو لاَمِزٌ : ــ هُ : أَشَارَ إليه بِعَيْنِهِ أو بِرَأْسِهِ أو بِشَفَتَيْهِ مع كلام خفيّ لِذِكْر العُيُوب «تَلْمُزُ العَجُوزُ بِجَارَاتِهَا».
لَمْزٌ : مص لَمَزَ.
لُمَزَةٌ : (للذّكَرِ والأُنثى) : عَيَّابٌ للنّاسِ في وُجوهِهِمْ «رجل لُمَزَةٌ لاَ يَسْلَمُ مِنْ لِسَانِهِ أَحَدٌ» ﴿وَيْلٌ لِكُلِّ هُمَزَةٍ لُمَزَةٍ﴾ [قرآن].
لَمَّازٌ ج ــون : عَيَّابٌ للنّاسِ.
§ل م س
لَمَسَ يَلْمُسُ/يَلْمِسُ لَمْسًا فهو لاَمِسٌ : ١ ــ الشّخصُ الشّيْءَ : مَسَّهُ بِيَدِهِ، ٢ ــ هُ : أَحَسَّ به «لمس تغييرا في سلوكه»، ٣ ــ المرأة : جامعها ◆ لَمَسَ الحَقِيقَةَ : اهْتَدَى إلى الصّواب لَهُ شُعَاعٌ يَكَاد يَلْمِسُ البَصَرَ : يذهب به.
لاَمَسَ يُلاَمِسُ مُلاَمَسَةً : ١ ــ الشّخصُ الشّيْءَ : مَسَّهُ، ٢ ــ الرّجُلُ المَرْأَةَ : جامَعَهَا.
تَلَمَّسَ يَتَلَمَّسُ تَلَمُّسًا : ــ الشّخصُ الشّيْءَ : تَطَلَّبَهُ مَرَّةً بعد أخرى «تَلَمَّسَ المكفوفُ الحَائِطَ»، «تَلَمَّسَ طَرِيقَه بصعوبة».
اِلْتَمَسَ يَلْتَمِسُ اِلْتِمَاسًا : ــ الشّخصُ الشّيْءَ : طَلَبَهُ «اِلْتَمَسَ مِنْهُ عَمَلاً»، «تَلْتَمِسُ مِنْهَا مُسَاعَدَةً» ◆ اِلْتَمَسَ لَهُ عُذْرًا : أَوْجَدَهُ له.
اِلْتِمَاسٌ : مص اِلْتَمَسَ.
تَلَمُّسٌ : مص تَلَمَّسَ.
لَمْسٌ : ١ مص لَمَسَ، ٢ الـ ــ : إحْدَى الحواسّ الخَمْس الظّاهرة تُدْرَكُ بها الحَرَارَةُ واليُبُوسَةُ ونحو ذلك عند المَسِّ «حَاسَّةُ اللَّمْسِ قَوِيَّةٌ عِنْدَ المَكْفُوفِ».
لَمْسَةٌ ج لَمَسَاتٌ : مَرّة من اللَّمْسِ ◆ لَمْسَةٌ أخيرةٌ : آخِرُ تَدَخُّل في عمل فَنِّيّ قَبْلَ عَرْضِهِ أو تَسْلِيمِهِ «لَمَسَاتٌ أخيرة لِلْكِتَابِ قبل تَقْدِيمِهِ للطّبْعِ»، «لَمَسَاتٌ أخيرة لِلْوَحَةِ الزَّيْتِيَّةِ قَبْلَ عَرْضِهَا».
