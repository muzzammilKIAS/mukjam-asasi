@النظام
المِتْرِي : مَجْمُوعَة المَقَايِيسِ التي أُسَاسُها المِتْرُ.
النَّظَّامُ، ابراهيم بن سيّار ،(ت ٢٣١ هـ / ٨٤٥ م) : متكلم معتزلي نشأً بالبصرة وتوفي ببغداد، رأس فرقة النّظامية، أخذ عنه الجاحظ.
نَظْمٌ : مص نَظَمَ.
نظيم : مَنظوم ومُتَناسق «نظيم من اللؤلؤ».
§ن ع ب
نَعَبَ يَنْعَبُ نَعِيبًا ونُعَابًا فهو ناعب : ــ الغُراب : صَاحَ وصوَّت.
مِنْعَبٌ : صَيَّاحٌ أحْمَقُ «رجُلٌ مِنْعَبٌ».
نُعَابٌ : مص نَعَبَ.
نَعِيبٌ : مص نَعَبَ.
§ن ع ت
نَعَتَ يَنْعَتُ نَعْتًا : ١ ــ الشيءَ أو الشَّخصَ : وَصَفَه : «نَعَتَه بالكَرَمِ»، ٢ [في النّحو] ــ الكَلِمَةَ : أتْبَعَها بنَعْتٍ.
مَنْعُوتٌ : ١ مَوْصُوفٌ «اسمٌ مَنْعُوتٌ»، «مَنْعوتٌ بالكَرَمِ والسَّخَاءِ»، ٢ [في النّحو] : اسم متبوع بنعت «حضر الصانع الماهر».
نَعْتٌ : ١ مص نَعَتَ، ٢ ج نُعُوتٌ : صِفَةٌ «جَمع نُعُوتَ الخَيْرِ كُلِّها»، ٣ [في النّحو] تابع مشتق يكمل متبوعه «حضر الصانع الماهر».
§ن ع ج
نَعِجَ يَنْعَجُ نَعَجًا فهو ناعج : ١ ــ اللَّوْنُ : كان خالِص البَيَاضِ، ٢ ــ البعيرُ : سَمِنَ، ٣ ــ الشَّخصُ : أكَلَ لحْمَ الضَّأْنِ فَثَقُل على مَعِدَتِه.
نَعَجٌ : مص نَعِجَ.
نَعْجَةٌ ج نِعَاجٌ ونَعَجَاتٌ : أُنْثَى الضَّأْنِ، شَاةٌ.
§ن ع ر
نَعَرَ يَنْعَرُ نَعْرًا ونَعِيرًا ونُعَارًا فهو ناعر : ١ ــ الدَّابَّةُ : صاحَتْ وصَوَّتَتْ بِخَيْشُومِها، ٢ ــ العِرْقُ بالدَّمِ : فارَ منهُ الدَّمُ ◆ مِنْ أيْنَ نَعَرْتَ إلَيْنا : مِنْ أين أتَيْتَ ؟ نَعَرَ فلان في الفِتْنَةِ : نَهَض فِيها وتَكَلَّمَ.
ناعُورٌ ج نَوَاعِيرُ : ١ نَاعُورةٌ، ٢ جَناحُ الرَّحَى، ٣ عِرْقٌ لا يَجِفُّ دَمُهُ.
ناعُورةٌ ج نَوَاعِيرُ : دُولابٌ ذُو دِلَاءٍ أَوْ نحوِها يَدُورُ بِدَفْعِ الماءِ أو جَرِّ الماشِيَةِ فَيَخْرُجُ الماءُ من البِئْرِ أَوِ النَّهرِ إلى الحَقْلِ.
نُعَارٌ : مص نَعَر.
نَعْرٌ : مص نَعَر.
نَعْرَةٌ ج نَعَرَاتٌ : ١ مَرَّةٌ من نَعَر، ٢ صَوْت الخَيْشُومِ.
نُعَرَةٌ ج نُعَرٌ ونُعَرَاتٌ : ١ خَيْشُومٌ، ٢ ذُبَابَةٌ زرقاءُ تَسْقُط على الدَّوابِّ فَتُؤْذِيها، ٣ كِبْرٌ وخُيَلَاءُ وعَصَبِيَّةٌ «في فلانٍ نُعَرَةٌ»، «نُعَرَةٌ إقليمِيَّةٌ»، «نُعَرَةٌ عُنْصُرِيَّةٌ»، «نُعَرَةٌ قَبَلِيَّةٌ».
نَعِيرٌ : مص نَعَر.
§ن ع س
نَعَسَ يَنْعُسُ نُعْسًا ونَعَسًا ونُعَاسًا فهو ناعِس : ــ الشَّخصُ : فَتَرَتْ حَواسُّه فَقَارَبَ النَّوْمَ ◆ نَعَسَ حَظُّهُ : تَعِسَ نَعَسَتِ السُّوقُ : كَسَدَتْ.
أنعس يُنْعِس إنعاسًا : ــ الشخصَ : حمله على النعاس.
تَناعَسَ يتناعَسُ تناعُسًا : تظاهر بالنعاس.
ناعِسٌ ج نُعَّسٌ مُؤ ناعِسَةٌ ج نَوَاعِسُ : فاتِرُ الحواسّ شبه نائم.
نُعَاسٌ : ١ مص نَعَسَ، ٢ أوَّلُ النَّوْمِ.
نَعْسٌ : مص نَعَسَ.
نَعَسٌ : مص نَعَسَ.
نَعْسَانُ مؤ نَعْسَى جمعها نِعَاسٌ : نائم.
§ن ع ش
نَعَشَ يَنْعَشُ نَعْشًا فهو ناعِش : ١ ــ هُ : أنهضه وأقامه «نَعَشَ الشجرة»، «نَعَشَهُ من فَقْرِه»، ٢ ــ الرَّبيعُ النَّاسَ : أعَاشَهُمْ وأخْصَبَهُم، ٣ ــ النَّاسُ المَيِّتَ :
