@شجون
↩ الحديث ذو شجون : متشعّب متفرع.
شُجُونٌ : ١ مص شَجَنَ١، ٢ مف شَجَنٌ.
§ش ج و ــ ى
شَجَا يَشْجُو شَجْوًا شاجٍ (الشاجي) مَشْجُوٌّ : ١ ــ الأمرُ فلانا : حزنه ؛ يقال «شجاه تذكر الإلف» إذا شوّقه وهيج حزنه، ٢ ــ الحديثُ الرجلَ : أطربه.
شَجِيَ يَشْجَى شَجًى شَجٍ (الشَّجِي) : ١ ــ الآكلُ : اعترض الشَّجَا في حلقه، ٢ ــ الرجلُ بالهمّ : لم يجد منه مخرجا، ٣ ــ المُحِبُّ : اهتمَّ وحزن واهتاج للذكرى.
أَشْجَى يُشْجِي إِشْجَاءً : ١ ــه الهَمُّ : شَجَاه، ٢ ــه بكذا : أغصّه به.
إِشْجَاءٌ : مص أَشْجَى.
شَجٍ (الشَّجِي) مؤ شَجِيَةٌ : من شجاه الهم والحزن.
شَجْوٌ : مص شَجَا، الهم والحزن.
شَجًى : ١ مص شَجِيَ، ٢ ما اعترض ونشب في الحلق من عظم أو طعام أو نحوهما : «في حلقه شَجًى».
شَجِيٌّ مؤ شَجِيَّةٌ : شَجٍ «ويل الشجيّ من الخَلِيِّ» [مثل]، أي ويل للمهموم من الفارغ.
§ش ح ب
شَحَبَ / شَحُبَ يَشْحُبُ شُحُوبًا شاحب : ١ ــ جِسْمُهُ : تغير وهُزِلَ، ٢ ــ لونه : تغير ونَصَلَ (من جوع أو مرض أو نحوهما) «شحب وجهه».
شُحُوبٌ : مص شَحَبَ / شَحُبَ.
§ش ح ت
شَحَتَ : سَأَلَ وألح في السؤال.
شَحَّات : السائل الملحّ.
شَحَجَ يَشْحَجُ شَحِيجًا شاحج : ــ الحمارُ والبغلُ : صوّت.
شاحِجٌ : الـ ــ : البغل أو الحمار.
شَحِيجٌ : مص شَحَجَ.
§ش ح ح
شَحَّ (شَحِحْتُ / شَحَحْتُ) يَشَحُّ / يَشِحُّ / يَشُحُّ شَحًّا / شُحًّا شَحِيحٌ : ١ ــ المالُ أو الماءُ أو الطعامُ أو نحوها : قلّ وندر، ٢ ــ فلان بالشيء : بَخِلَ : ﴿وأُحْضِرَتِ الأَنْفُسُ الشُّحَّ﴾ [قرآن].
شَاحَّ يُشَاحُّ مُشَاحَّةً : ــ فلانا : خاصمه وما حكه، ويقول العلماء «لا مُشَاحَّةَ في الاصطلاح» أي لا مجادلة في المتعارف عليه.
تَشَاحَّ يَتَشَاحُّ تَشَاحًّا : ــ الخصمان : بدا حرص كل منهما على الغلبة.
تَشَاحٌّ : مص تَشَاحَّ.
شَحٌّ / شُحٌّ : مص شَحَّ.
شَحِيحٌ ج أَشِحَّاءُ وأَشِحَّةٌ مؤ شحيحة ج شَحَائِحُ وشحيحات : بخيل عكسه جواد، كريم : «لا تكن شحيحا بعلمك» ◆ الأيام الشحائح : التي لا مطر فيها شحيح النظر : قليل البصر.
مُشَاحَّةٌ : مص شَاحَّ.
§ش ح ذ
شَحَذَ١ يَشْحَذُ شَحْذًا فهو شاحذ : ١ ــ السكينَ / السيفَ : أَحَدَّ سِنَانَهُ، فالسيف شَحِيذٌ ومشحوذ، ٢ ــ ذِهْنَهُ : أعمله وتعمق في التفكير «الحاجة تشحذ القريحة»، ٣ ــه ببصره/بعينه : حدجه وأمعن النظر فيه.
شَحَذَ٢ يَشْحَذُ شِحَاذَةً شَحَّاذ : ــ الفقيرُ الناسَ / من الناس : سألهم مُلِحًّا.
شِحَاذَةٌ : مص شَحَذَ٢.
شَحَّاذٌ ج ــ ون : سائل مُلِحٌّ.
شَحْذٌ : مص شَحَذَ١.
مِشْحَذٌ ج مَشَاحِذُ : مِسَنٌّ (أداةٌ لِسَنِّ السكين ونحوه).
مَشْحَذَةٌ : أداة للشَّحْذ «هذا الكلام مَشْحَذَةٌ للفهم» : أي يُحِدُّهُ ويثيره.
