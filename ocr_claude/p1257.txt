@أهدف
هُدَّابٌ : ١ غَبِيٌّ ثقيل، ٢ هُدَّابُ النَّخْلِ : وَرَقُهُ، ٣ هُدَّابُ الثَّوْبِ : الخُيوط التي تَبْقَى في طَرَفَيْه من عَرْضَيْه دونَ حاشِيَتِهِ.
§هـ د ج
هَدَجَ يَهْدِجُ هَدْجًا وهَدَجَانًا فهو هَادِجٌ : ١ ــ الشّيْخُ : مَشَى في ارْتعاش «هَدَجَ في مِشْيَتِهِ»، ٢ ــ تِ الريحُ : صَوَّتَتْ.
تَهَدَّجَ يَتَهَدَّجُ تَهَدُّجًا : ١ ــ الصّوتُ : تَقَطَّعَ في ارتعاشٍ «تَهَدَّجَ صوتُه من الخَوْفِ»، ٢ ــ القومُ على فلانٍ : أظهَرُوا مَحَاسِنَهُ.
هَدَّاجٌ : صيغة مبالغة لمن يمشي مرتعشا.
هَوْدَجٌ : (انظر : ألفبائيا).
§هـ د د
هَدَّ١ (هَدَدْتُ) يَهُدُّ هَدًّا وهُدُودًا فهو هَادٌّ : ١ ــ البِنَاءَ : هَدَمَهُ بِشِدَّةِ صَوْتٍ «هَدَّ الحائِطَ لتوسيعِ الغُرْفَةِ»، ٢ ــ هُ الأمرُ : أوْهَنَهُ وَبَلَغَ مِنْهُ «هَدَّتْهُ المُصيبَةُ».
هَدَّ٢ (هَدَدْتُ) يَهِدُّ هَدًّا هِدٌّ : ١ ــ الحَائِطُ ونحوُه : سقط، ٢ ــ الشّخصُ : ضعف وهرم.
هَدَّدَ يُهَدِّدُ تَهْدِيدًا : ــ هُ : خَوَّفَهُ وَتَوَعَّدَهُ بالعُقُوبَة «هَدَّدَ سَلامَتَهُ»، «هدَّدَهُ بالاستقالة».
تَهَدَّدَ يَتَهَدَّدُ تَهَدُّدًا : ــ هُ : خَوَّفَهُ وَتَوَعَّدَهُ بِشِدَّةٍ «تَهَدَّدَهُ بالسِّجْنِ».
تَهَدُّدٌ : مص تَهَدَّدَ.
تَهْدِيدٌ : ١ مص هَدَّدَ، ٢ ج ــ ات : تَخْوِيف وَتَوَعُّد «تهديدٌ بالضّرب»، «تهديد بالتّشهير بِهِ»، «تهديدات بضرب مواقع الفدائيين».
تَهْدِيدِيٌّ : منسوب إلى التهديد «بيان عَسْكَرِيّ تَهْدِيدِيّ»، «مُكالَمَة هاتِفِيّة تَهْدِيديّة»، «تكلم بلهجة تَهْدِيديّة».
مَهْدُودٌ : ١ مُهَدَّمٌ «دَارٌ مَهْدُودَة»، ٢ بالغ الضَّعْفِ والوَهَن «رجلٌ مَهْدُودُ القُوَى».
هَدٌّ : مص هَدَّ٢،١.
هِدٌّ : مهدود.
هُدُودٌ : مص هَدَّ١.
§هـ د ر
هَدَرَ١ يَهْدُرُ هَدْرًا وَهَدَرًا فهو هَادِرٌ : ــ الدَّمُ وغيْرُه : بَطَلَ (مَنِ اطَّلَعَ فِي دَارٍ بِغَيْرِ إِذْنٍ فَقَدْ هَدَرَتْ عَيْنُهُ) [حديث].
هَدَرَ٢ يَهْدِرُ هَدِيرًا وهَدْرًا فهو هَادِرٌ : رَدَّدَ صوتَه «هَدَرَ الحَمامُ»، «هَدَرَ الجَمَلُ»، «هَدِيرُ الأمْوَاجِ»، «هَدِيرُ الآلات» ◆ هدرتِ القِدْرُ : غلى الماء فيها.
أَهْدَرَ يُهْدِرُ إِهْدَارًا : ١ ــ الشّيْءَ : أبْطَلَهُ، ٢ ــ كرامَةَ فلان : أسْقَطَهَا، ٣ ــ دَمَهُ : أبَاحَهُ وأسْقَطَ القِصَاصَ فيه والدِّيَةَ.
تَهَادَرَ يَتَهَادَرُ تَهَادُرًا : ــ القومُ : أبْطَلُوا دِمَاءَهُمْ بَيْنَهُمْ وأَبَاحُوهَا.
إِهْدَارٌ : مص أَهْدَرَ.
تَهَادُرٌ : مص تَهَادَرَ.
هَدْرٌ : ١ مص هَدَر٢،١، ٢ ساقط باطل ◆ ذَهَبَ دَمُهُ هَدْرًا : لَمْ يُدرَكْ بِثَأْرِهِ.
هَدَرٌ : ١ مص هَدَر١، ٢ الأسْقَاط من النّاسِ لا خير فيهم.
هَدِيرٌ : مص هَدَر٢.
هدروجين : (انظر : إدرجين).
§هـ د ف
هَدَفَ يَهْدُفُ هَدْفًا فهو هادِفٌ : ١ ــ الشّخصُ : كَسِلَ وضَعُفَ، ٢ ــ إلى الشّيْءِ : قَصَدَ وأسْرَعَ، ٣ ــ إلى الأمرِ : جَعَلَهُ هَدَفا وغَرَضًا يَسْعَى إليه «هَدَف إلى مُسَاعَدَةِ الفُقَرَاءِ» (مو).
أَهْدَفَ يُهْدِفُ إِهْدَافًا : ١ ــ الشّخصُ : قَرُبَ وَدَنَا، ٢ ــ الشّخصُ : إليه : لَجَأَ، ٣ ــ الشّخصُ على المُرْتَفَعِ : أشْرَفَ، ٤ ــ لهُ : نهض واسْتَقْبَلَ، ٥ ــ فلانٌ للخمسين : قَارَبَهَا.
