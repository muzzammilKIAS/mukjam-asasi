@لزقة
لَذْلاَذٌ : سريع خفيف.
لَذْلَذَةٌ : مص لَذْلَذَ.
§ل ذ ى
لَذِيَ يَلْذَى لَذًى لاَذٍ (اللاَّذِي) : ــ الشَّخْصُ بالأمْرِ : لَزِمَهُ ولم يُفارقه.
لَذًى : مص لَذِيَ.
الَّذِي مؤ التي مثناه اللَّذَانِ واللَّذَيْنِ ج الَّذِينَ : اسم موصول مُبْهَم معرفة مذكر ولا يتمُّ إلا بِصِلَةٍ «جَاء الَّذِي دَعَوْتُهُ».
§ل ز ب
لَزَبَ يَلْزُبُ لُزُوبًا فهو لازِبٌ : ١ ــ الشَّيْءُ : ثُبَتَ واشْتَدَّ، ٢ ــ تِ السَّنَةُ : أَجْدَبَتْ وانْعَدَمَ نَبَاتُهَا، ٣ ــ به : لَصِقَ «لَزَبَ الطِّينُ برِجْلِهِ».
تَلاَزَبَ يَتَلاَزَبُ تَلاَزُبًا : ــ الشَّيْءُ : تَرَاكَمَ.
تَلاَزُبٌ : مص تَلاَزَبَ.
لاَزِبٌ : ١ ثابتٌ لازِم «صار الأمر ضَرْبَةَ لازِبٍ»، ٢ لاصِقٌ مُتَماسِكُ الأجْزاء ﴿إِنَّا خَلَقْنَاهُمْ مِنْ طِينٍ لاَزِبٍ﴾ [قرآن].
لَزْبَةٌ ج لَزَبَاتٌ ولَزَبَاتٌ ولِزَبٌ : ١ مَرّة من لَزَبَ، ٢ شِدّة وقَحْطٌ «سَنَةٌ لَزْبَةٌ».
لُزُوبٌ : مص لَزَبَ.
§ل ز ج
لزج يلْزَجُ لزجا ولُزوجا ولُزوجة لزِجٌ : ١ ــ الشيء : تمطط وتمدد ولم ينقطع، ٢ ــ الشيء بالشيء : علق «لزج العسل بإصبعه».
تَلَزَّجَ يَتَلَزَّجُ تَلَزُّجًا : ١ ــ الشَّيْءُ : صار لَزِجًا يَلْصَقُ بعضُهُ ببعض، ٢ ــ الشَّعَرُ : تَلَبَّدَ من الوسخ.
تَلَزُّجٌ : مص تَلَزَّجَ.
لَزَجٌ : مص لَزِجَ.
لَزِجٌ : ١ وصف للسائل سريع الالتصاق، ٢ صفة لمادة غير مكتملة السيولة مثل الشمع أو القار.
لُزُوجٌ : مص لَزِجَ.
لُزُوجَةٌ : ١ مص لَزِجَ، ٢ تَمَاسُكُ أجزَاءِ المادّة بعضِها ببعض بحيثُ لا يتغيَّر شكلُها بسُهُولة كالقطران والعَسَلِ وغيرهما (مج).
§ل ز ز
لَزَّ (لَزَزْتُ) يَلُزُّ لَزًّا ولَزازًا لازٌّ : ١ ــ الشَّيْءُ بالشَّيْءِ : لَصِقَ به، ٢ ــ الشَّيْءُ بالشَّيْءِ : أَلْزَمَهُ إيّاه، ٣ ــ هُ إلى كَذَا : اضطَرَّهُ إليه «لَزَّهُ إلى الكَذِبِ»، ٤ ــ البَابَ : أغلقَهُ.
تَلَزَّزَ يَتَلَزَّزُ تَلَزُّزًا : ــ الشَّيْءُ : اجْتَمَعَ وانضَمَّ بعضُهُ إلى بعضٍ.
الْتَزَّ يَلْتَزُّ الْتِزَازًا : ــ بالشَّيْءِ : الْتَصَقَ به.
الْتِزَازٌ : مص الْتَزَّ.
تَلَزُّزٌ : مص تَلَزَّزَ
لَزازٌ : مص لَزَّ.
لَزٌّ : ١ مص لَزَّ، ٢ حَلْقَةُ البَابِ ◆ فُلانٌ كَزٌّ لَزٌّ : ممسِكٌ بخيلٌ.
لَزَزٌ : خشبةٌ يُشَدُّ بها البابُ، ويُقال لها مِتْرَسٌ.
§ل ز ق
لَزِقَ يَلْزَقُ لُزُوقًا فهو لازِقٌ : ــ الشَّيْءُ بالشَّيْءِ : لَصِقَ به وعَلِقَ «لَزِقَ الطِّينُ بِرِجْلِهِ».
لَزَّقَ يُلَزِّقُ تَلْزِيقًا : ١ ــ الشَّيْءَ : أَلْصَقَهُ «لَزَّقَ الصُّورَةَ»، ٢ ــ الشَّيْءَ : فَعَلَهُ من غيرِ إحْكَامٍ ولا إتْقَانٍ.
تَلْزِيقٌ : مص لَزَّقَ.
أَلْزَقَ يُلْزِقُ إلْزاقًا : ــ ه : جعله يلزق به.
لازَقَ يُلازِقُ مُلازَقَةً : كان لازقا به، «جارٌ مُلازق».
الْتَزَقَ يَلْتَزِقُ الْتِزَاقًا : ــ بالشَّيْءِ : لَزِقَ.
لِزَاقٌ : مَا يُلْصَقُ به الشَّيْءُ «أَلْصَقَ النَّجَّارُ الخَشَبَتَيْنِ باللِّزَاقِ».
لَزْقَةٌ ج لَزْقَاتٌ : قطعة من قُمَاش أو نحوها فيها دَواء توضَعُ على موضع الأَلَمِ في الجسم لِتَخْفِيفِهِ.
