@سطح
§س ط ح
سَطَحَ يَسْطَحُ سَطْحًا فهو ساطح : ــ الشيءَ : بَسَطه، سوّاه «سَطَحَ اللهُ الأَرْضَ».
سَطَّحَ يُسَطِّحُ تَسْطيحا : ــ الشيءَ : سَطَحَهُ.
تَسَطَّحَ يَتَسَطَّحُ تَسَطُّحًا : ــ الشيءُ : انْبَسَط.
اِنْسَطَحَ يَنْسَطِحُ انْسِطاحًا : ١ انْبَسَطَ، ٢ امْتَدَّ على قفاه.
اِنْسِطاحٌ : مص انْسَطَحَ.
تَسَطُّحٌ : مص تَسَطَّحَ.
تَسْطيحٌ : مص سَطَّحَ.
سَطْحٌ¹ : مص سَطَحَ.
سَطْحٌ² ج سُطُوحٌ : ١ سطح كل شيء : أعلاه «سطح البيت»، ٢ [في الهندسة] ماله طول وعَرْض.
سَطْحيٌّ : غير عميق «آراء سَطْحية».
سَطيحٌ ج سُطَحاءُ : شخص سطيح : لا يقدر على القيام أو القعود لِعِلَّةٍ.
مُسَطَّحٌ ج ــ ات : ١ مُنْبَسِط «أَنْفٌ مُسَطَّح»، ٢ ما كان ذا سطح مستو «مسطحات مائية»
§س ط ر
سَطَرَ يَسْطُرُ سَطْرًا : ــ الكتابَ والرسالة ونحوهما : كتبهما ﴿وكِتابٍ مَسْطورٍ﴾ [قرآن].
سَطَّرَ يُسَطِّرُ تَسْطيرًا: ١ ــ الكتابَ أو الرسالةَ ونحوهما: كتبهما، ٢ ــ الورقةَ : رسم فيها خطوطا بالمِسْطَرة، ٣ ــ قصةً ونحو ذلك : ألَّفها ◆ سَطَّر الأكاذيب : ألَّفها.
اِسْتَطَرَ يَسْتَطِرُ اسْتِطارًا : سَطَرَ ﴿وكلُّ صغير وكَبير مُسْتَطَرٌ﴾ [قرآن].
سَيْطَرَ : (انظر ألفبائيا).
أساطيرُ مف أُسْطُورة : الأباطيل والأحاديث العجيبة.
اِسْتِطارٌ : مص اسْتَطَرَ.
أُسطورة ج أساطيرُ : (انظر ألفبائيا).
تَسْطيرٌ : مص سَطَّرَ.
ساطورٌ ج سَواطيرُ : سكّين عريض ثقيل يستعمله القصّاب لكسر العظم.
سَطْرٌ : ١ مص سَطَرَ ٢ ج أسطُرٌ وسطورٌ : صَفٌّ (وخاصة في الكتابة) «في هذه الصَّفحة عِشرون سَطْرًا»، ٣ خطٌّ مستقيم على الورق «اكْتُبْ فَوْقَ السَّطْرِ» ◆ يقرأ بين السطور : يفهم المعنى الضمني.
مِسْطَرَةٌ ج مَساطِرُ : آلة ذات حافة مُسْتَقيمة قد تُدَرَّج، تستخدم لرسم المستقيمات أو قياس أطوالها ◆ مسطرة حاسبة : آلة ذات مقاييس مدرجة على صفة خاصة تستعمل لاستخراج نتائج العمليات الحسابية وقيم بعض المقادير الرياضية.
مُسْطَرِينٌ : آلةٌ تُسْتَخْدَمُ في البناء، يُسَوَّى بها الآجُرّ ونحوه.
§س ط ع
سطع يَسْطَعُ سُطوعًا فهو ساطع : ١ ــ النورُ أو البَرْقُ أو نحوهما : انتشر أضاء، لَمَعَ «كان النورُ ساطِعًا فلم أَسْتَطِعْ فَتْحَ عَيْنَيَّ»، ٢ ــ ت الرائحة : فاحت، انتشرت، ٣ ــ الأمرُ : وضح «سَطَعَ الحقُّ».
ساطع الحصري (انظر ألفبائيا).
سُطوعٌ : مص سَطَعَ.
§س ط ل
أُسْطولٌ : (انظر ألفبائيا).
سَطْلٌ ج سُطولٌ : إناء لنقل الماء أو حفظه.
أُسْطُوانةٌ : (انظر ألفبائيا).
§س ط و
سَطا يَسْطو سَطْوًا ساطٍ (السّاطي) : ١ ــ عليه وبه : بَطَش به، قَهَره ﴿يَكادونَ يَسْطونَ بالذينَ يَتْلونَ عَلَيْهِمْ آياتنا﴾ [قرآن]، ٢ ــ على المتاع : انْتَهبه «سَطا اللُّصوصُ على أمواله»، ٣ ــ الماءُ : كَثُرَ «سَطا ماءُ النَّهْر فَأَغْرَقَ المَزْروعات».
سَطْوٌ : مص سَطا.
