@هر
هِرٌّ ج هِرَرَةٌ مؤ هِرَّةٌ ج هِرَرٌ : قِطٌّ ويُقَالُ أيضا : مِينَّور.
هَرِيرٌ : ١ مص هَرَّ٢، ٢ صوت الكلب دون النباح ◆ أَدْبَرَ هَرِيرُهُ وَأَقْبَلَ هَرِيرُهُ : يُقَالُ للرّجل إذا شاخ وساءَ خُلُقُه.
هَرِيرَةٌ : كَرَاهِيَةٌ «أَجِدُ في وَجْهِهِ هَرِيرَةً».
§هـ ر س
هَرَسَ يَهْرِسُ هَرْسًا فهو هَارِسٌ : ١ ــ الشَّيْءَ : دَقَّهُ دَقًّا شَدِيدا «هَرَسَ القَمْحَ»، ٢ ــ الطعامَ : أكله أكلا عنيفا.
مِهْرَاسٌ ج مَهَارِيسُ : ١ حَجَرٌ مَنْقُورٌ مُسْتَطِيل يُدَقُّ فيه، وقد يكونُ من النُّحاسِ أو غيره، ٢ خَشَبَةٌ يُدَقُّ بها الحَبُّ.
هَرَّاسٌ : صانع الهريسة أو بائعها.
هَرْسٌ : مص هَرَسَ.
هَرِيسٌ : الحَبُّ المَهْرُوس بالمِهراسِ قبل طبخه.
هَرِيسَةٌ : ١ طَعام يُطْبَخُ من القَمْحِ المَدْقُوقِ واللَّحْمِ، ٢ نوع من الحَلْوَى يُصنعُ من الدّقيق والسّمن والسُّكَّرِ، ٣ خليط من الفلفل الأحمر الجاف والتوابل تُطْبَخ بها الأطعِمَة لتُكْسِبَهَا مَذَاقًا حَارًّا (بلدان المغرب).
§هـ ر ش
هَرِشَ يَهْرَشُ هَرَشًا فهو هَرِشٌ : ــ الشَّخصُ : سَاءَ خُلُقُهُ.
هَرَّشَ يُهَرِّشُ تَهْرِيشًا : ١ ــ بَيْنَ القوم : أَفْسَدَ بَيْنَهم وأَغْرَى بَعْضَهم بِبَعْض، ٢ ــ بَيْنَ الكِلابِ : حَرَّشَهَا لِيَنْقَضَّ بعضُها على بَعْض.
هَارَشَ يُهَارِشُ هِرَاشًا ومُهَارَشَةً : ١ ــ الشَّخصَ : وَاثَبَهُ وخَاصَمَهُ، ٢ ــ الكِلابَ : حَرَّشَهَا.
تَهَارَشَ يَتَهَارَشُ تَهَارُشًا : ــ تِ الكِلابُ : وَثَبَ بعضها على بعض وتقاتلت.
تَهْرِيشٌ : مص هَرَّشَ.
مُهَارَشَةٌ : مص هَارَشَ.
هِرَاشٌ : مص هَارَشَ.
هَرْشٌ : مص هَرِشَ.
هَرِشٌ : أحمق سيء الخُلُق.
§هـ ر ع
هَرِعَ يَهْرَعُ هَرَعًا فهو هَرِعٌ : ١ ــ الدَّمُ : سَالَ، ٢ ــ الشَّخصُ : كانَ سَرِيعَ المَشْيِ، ٣ ــ الطفل : كان سريع البكاء.
هُرِعَ يُهْرَعُ : أَسْرَعَ أو عَدا في اضطراب ﴿وَجَاءَهُ قَوْمُهُ يُهْرَعُونَ إِلَيْهِ﴾ [قرآن].
أَهْرَعَ يُهْرِعُ إِهْرَاعًا : ــ الشخصُ : مشى أو أَسْرَعَ في عَدْوِهِ.
أُهْرِعَ يُهْرَعُ : ١ ــ الشخصُ : هُرِعَ، ٢ أُرْعد من غضب أو ضعف أو خوف أو حُمَّى.
إِهْرَاعٌ : مص أَهْرَعَ.
هُرَاعٌ : مَشْيٌ في اضطراب وسُرْعَة.
هَرَعٌ : ١ مص هَرِعَ، ٢ [في الطب] : نوبةُ الهِسْتِيرِيَا.
هَرِعٌ : سريع المشي أو البكاء.
§هـ ر ف
هَرَفَ يَهْرِفُ هَرْفًا فهو هَارِفٌ : ١ ــ الشخصُ : هَذَى وخلَط في كلامه «هو يَهرِفُ بما لا يعرِفُ»، ٢ ــ بفلان : بالغ في مدحه إلى حدّ الهذيان.
هَرْفٌ : مص هَرَفَ.
§هـ ر ق
هَرَقَ يَهْرَقُ هَرْقًا فهو هَارِقٌ : ــ الماءَ ونحوه : صَبَّهُ.
هَرَاقَ يَهْرِيقُ هِرَاقَةً : ــ الماءَ : سَكَبَهُ والدَّمَ أَسَالَهُ.
أَهْرَقَ يُهْرِقُ إِهْرَاقًا : ــ الماءَ ونحوَه : صَبَّه «أَهْرَقَ المُقَاتِلُ دِمَاءَ أعْدَائِهِ».
مُهْرَقٌ : ١ مَصْبُوبٌ «مِيَاهٌ مُهْرَقَةٌ»، ٢ ج مَهَارِقُ : صَحِيفَة بَيْضَاء يُكْتَبُ فِيها، ٣ نَسِيجُ حرير أبيضَ يُسْقَى الصَّمْغَ ويُصْقَلُ ثُمَّ يُكْتَبُ عليهِ.
