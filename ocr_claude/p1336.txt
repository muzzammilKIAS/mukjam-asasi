وَنْيٌ : مص وَنَى.
وَنًى : مص وَنَى.
§و هـ ب
وَهَبَ يَهَبُ وَهْبًا وَهِبَةً فهو وَاهِبٌ : ١ ــ هُ : غَلَبَهُ في العَطَاء والهِبَة، ٢ ــ المالَ الشَّخصَ ولَهُ : أعطاهُ إيّاهُ بلاَ عِوَض ◆ هَبْنِي فَعَلْتُ كَذَا : احْسِبْنِي وَاعْدُدْنِي وَهَبَنِي الله فِدَاكَ : جَعَلَنِي فِدَاكَ، دُعَاء بالخَيْر.
أَوْهَبَ يُوهِبُ إِيهَابًا : ١ ــ الشَّيْءُ له : دَامَ أو كَثُرَ واتَّسَعَ، ٢ ــ الشَّيْءَ للشَّخص : أمكنَهُ أن يأخُذَهُ، ٣ ــ الأمرَ للشَّخص : أعَدَّهُ له ◆ أَوْهَبْتُ لِكَذَا : قَدَرْتُ عَلَيْه.
اِسْتَوْهَبَ يَسْتَوْهِبُ اِسْتِيهَابًا : ــ هُ : سألَهُ الهِبة.
إِيهَابٌ : مص أَوْهَبَ.
مَوْهِبَةٌ ج مَوَاهِبُ : ١ عَطِيَّة، ٢ شيءٌ مَوْهُوبٌ «الشِّعْرُ مَوْهِبَةٌ»، «له مَوَاهِبُ مُمْتَازَة في الرِّيَاضيات».
مَوْهُوبٌ ج ــ ون : مُبْدِعٌ «شَاعِرٌ مَوْهُوبٌ»، «رَسَّامَاتٌ مَوْهُوبَاتٌ».
هِبَةٌ : ١ مص وَهَبَ، ٢ ج هِبَاتٌ : عَطِيّة تُعْطَى بِلاَ عِوَض، ٣ [في الشّرع] عقد يمَلِّكُ به الواهبُ الموهُوبَ له مَالا مُعَيَّنا بلا عوض.
وَهْبٌ : مص وَهَبَ.
وَهَّابِيٌّ : ١ منسوب إلى الوَهَّابِيَّة، ٢ ج ــ ون : من يتبع مذهب الوَهَّابِيَّة.
الوَهَّابِيَّة : (انظر : ألفبائيا).
وَهَجَ يَهِجُ وَهْجًا وَوَهِيجًا وَوَهَجَانًا فهو وَهَّاجٌ : ١ ــ تِ النّارُ أوِ الشّمسُ : اتَّقَدَتْ، ٢ ــ اليومُ أو اللَّيْلَةُ : اشتَدَّ حَرُّهما.
أَوْهَجَ يُوهِجُ إيهَاجًا : ــ النّارَ : أَوْقَدَهَا.
تَوَهَّجَ يَتَوَهَّجُ تَوَهُّجًا : ١ ــ تِ النّارُ أو الشّمس : تَوَقَّدَت، ٢ ــ النَّهارُ : اشتَدَّ حَرُّهُ.
إِيهَاجٌ : مص أَوْهَجَ.
تَوَهُّجٌ : مص تَوَهَّجَ.
وَهْجٌ : مص وَهَجَ.
وَهَجٌ : ١ اتّقاد النار أو الشّمس، ٢ حَرُّ النّارِ أو الشّمس من بعيد «وَهَجُ التَّنُّور»، ٣ ــ الطِّيبِ : انتِشَارُ رَائِحَتِهِ.
وَهَجَانٌ : مص وَهَجَ.
وَهَّاجٌ : شَدِيدُ الوَهَجِ «حَرٌّ وَهَّاجٌ»، «نُورٌ وَهَّاجٌ»، «نَجْمٌ وَهَّاجٌ» ﴿وَجَعَلْنَا سِرَاجًا وَهَّاجًا﴾ [قرآن].
وَهِيجٌ : مص وَهَجَ.
§و هـ د
وَهَّدَ يُوَهِّدُ تَوْهِيدًا : ــ له الفِرَاشَ : مَهَّدَهُ.
تَوْهِيدٌ : مص وَهَّدَ.
وَهْدَةٌ ج وَهْدٌ وِهَادٌ وَوَهَدَاتٌ : ١ أَرضٌ مُنْخَفِضَة، ٢ [جيولوجيا] أرض حفرتها السّيول المتدفقة من مكان عال حفرا عميقا.
§و هـ ر ا ن
وَهْرَانُ : مدينة على البحر الأبيض المتوسط شمال غربي الجزائر، عاصمة ولاية وهران.
§و هـ ق
وَهَقَ يَهِقُ وَهْقًا فهو وَاهِقٌ : ١ ــ الشَّخصُ الدَّابَّةَ : جَعَلَ الوَهَقَ في عُنُقِهَا، ٢ ــ هُ عن كَذَا : حَبَسَهُ.
وَهْقٌ : مص وَهَقَ.
وَهْقٌ/وَهَقٌ ج أَوْهَاقٌ : حَبْلٌ في طَرَفِهِ أُنْشُوطَةٌ يُطْرَحُ في عُنُقِ الدَّابَّةِ وغيرها حَتَّى تُؤْخَذ.
§و هـ ل
وَهِلَ يَوْهَلُ وَهَلاً وَوِهِلَ فهو وَاهِلٌ : ١ ــ الشَّخصُ : ضَعُفَ، ٢ ــ الشَّخصُ : جَبُنَ.
وَهَّلَ يُوَهِّلُ تَوْهِيلاً : ــ هُ : خَوَّفَهُ وَفَزَّعَهُ.
تَوْهِيلٌ : مص وَهَّلَ.
وَهْلٌ : مص وَهِلَ.
وَهِلٌ : ضعيف جَبَان.
وَهْلَةٌ ج وَهَلاَتٌ : ١ نَزْعَةٌ، ٢ أَوَّلُ شَيْءٍ «لَقِيتُهُ أَوَّلَ وَهْلَةٍ» «مِنَ الوَهْلَةِ الأُولَى».
