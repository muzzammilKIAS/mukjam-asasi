@شغب
شَغَبٌ : مص شَغَبَ.
مُشَاغَبَةٌ : مص شَاغَبَ.
§ش غ ر
شَغَرَ يَشْغَرُ شُغُورًا فهو شاغر : ــ المكانُ : خلا وفرغ «شغَرَ المنصب».
شَاغَرَ يُشَاغِرُ شِغَارًا ومُشَاغَرَةً : ــ الرجلُ الرجلَ : زَوَّجَهُ أخته على أن يزوجه الآخر أخته (بغير مهر في الحالتين)، وقد نهى الرسول ﷺ عنه وأبطله بعد أن كان معروفا في الجاهلية فقال : «لا شِغَارَ في الإسلام» [حديث].
شَاغِرٌ ج شَوَاغِرُ : خالٍ «توجد وظيفة شاغرة في هذه الإدارة».
شِغَارٌ : مص شَاغَرَ ◆ زواج الشِّغار : (انظر : شَاغَرَ).
شُغُورٌ : مص شَغَرَ.
مُشَاغَرَةٌ : مص شَاغَرَ.
§ش غ ف
شَغَفَ يَشْغَفُ شَغْفًا وشَغَفًا فهو شاغف : ــ ه الحُبُّ : أصاب قلبه : ﴿شَغَفَهَا حُبًّا﴾ [قرآن].
شَغِفَ يَشْغَفُ شَغَفًا شَغِفٌ وشَغُوفٌ : ــ به / بحبه : أَحَبَّهُ وأُولِعَ به.
شُغِفَ يُشْغَفُ : ــ به / بحبه : شَغِفَ «شُغِف به حبا».
شَغَافٌ ج شُغُفٌ : ــ القلبِ : غلافه «مَسَّتْ هذه الحادثة شَغَافَ القلوب».
شُغَاف : مرض يصيب شغاف القلب.
شَغْفٌ : مص شَغَفَ.
شَغَفٌ : مص شَغَفَ وشَغِفَ «أقبل بشغف زائد».
§ش غ ل
شَغَلَ يَشْغَلُ شَغْلًا وشُغْلًا فهو شاغل : ١ ــ المستأجرُ الدارَ : سكنها، ٢ ــ الوظيفةَ : حصل عليها، ٣ ــ فلانا عن الشيء : لهاه عنه وصرفه «شغلتني عنك الشواغل»، ٤ ــ نَفْسَه بكذا : وجه همَّه إليه ◆ شَغَلَ البالَ / الفكرَ : أصاب النفس بالقلق «لقد شغلت بالي بتأخرك عن الحضور» شغل أوقات فراغه : ملأها ببعض الأعمال.
شُغِلَ يُشْغَلُ : ــ عنه بكذا : تلهى به.
شَغَّلَ يُشَغِّلُ تَشْغِيلًا : ١ ــ المديرُ العاملَ : أعطاه وظيفة، ٢ ــ الأستاذُ طُلَّابَهُ : حَمَّلهم بأعباء كثيرة، ٣ ــ الآلةَ : أدارها.
شَاغَلَ يُشَاغِلُ مُشَاغَلَةً : ــ ت الأمُّ طِفْلَهَا : ألهته وشغلته.
تَشَاغَلَ يَتَشَاغَلُ تَشَاغُلًا : ١ ــ الشخصُ : أظهر أنه مشغول، ٢ ــ به : شُغِلَ.
اِنْشَغَلَ يَنْشَغِلُ اِنْشِغَالًا : مطاوع شَغَلَ.
اِشْتَغَلَ يَشْتَغِلُ اشْتِغَالًا : ١ ــ بكذا : عَمِلَ : «اشتغل بالعلم»، ٢ ــ عنه : تلهى عنه بغيره، ٣ ــ المحرِّكُ : دار.
اِشْتِغَالٌ : مص اشْتَغَلَ.
أَشْغَالٌ : مف شُغْلٌ ◆ أشغالٌ شاقَّةٌ : حكم بالسجن مع التكليف ببعض الأعمال الشاقة خلال فترة السجن أشغال شاقة مؤبدة : حكم بالسجن مع الأشغال الشاقة لمدة ٢٥ عاما وزارة الأشغال : الوزارة المسؤولة عن المرافق والخِدْمات العامة.
اِنْشِغَالٌ : مص انْشَغَلَ.
تَشَاغُلٌ : مص تَشَاغَلَ.
تَشْغِيلٌ : مص شَغَّلَ «مكتب تشغيل».
تَشْغِيلَةٌ ج تشغيلاتٌ [في الكيمياء] : وصف لعملية صناعية كاملة تتم على دفعات مبتدئة بالمواد الخام وتنتهي بها مصنَّعة.
شَاغِلٌ ج شَوَاغِلُ : ما يملأ فكر الشخص وعقله «وجد شاغلا عنه في كذا..».
شَغَّالٌ ج شَغَّالَةٌ وشَغَّالُون : ١ خادم من خدم المنازل، ٢ مَنْ يقوم بأنواع العمل غير الصناعي مثل شغَّالة
