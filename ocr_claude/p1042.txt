@كسوف
↩ ٢ ج ــ ون : مَهْمُومٌ «رَجُلٌ كاسِفٌ»، «هو كاسِفُ البالِ»، ٣ عَابِسٌ «كاسِفُ الوَجْهِ».
كُسُوفٌ : مص كَسَفَ «كُسُوفُ الشّمس» (وهو للقمر خسوف).
§ك س ك س
كَسْكَسَ يُكَسْكِسُ كَسْكَسَةً : ١ ــ الشّيءَ : دَقَّهُ دَقًّا شَدِيدًا، ٢ ــ الطّحينَ أو السَّمِيدَ : صنعَهُ كُسْكُسًا.
كَسْكَاسٌ : وِعَاءٌ يُطْبَخُ فيهِ الطَّعَامُ بالبُخَارِ.
كُسْكُسٌ/كُسْكُسِيٌّ : طَعَامٌ يشيع في المغرب العَرَبيّ يُتَّخَذُ مِن طَحينِ القَمْحِ ويُنْضَجُ على البُخَارِ «عَشَاؤُهُ كُسْكُسٌ بالسَّمَكِ»، «قَدَّمَ لِضُيُوفِهِ كُسْكُسِيًّا بِلَحْمِ الضَّأْنِ».
كَسْكَسَةٌ : ١ مص كَسْكَسَ، ٢ [في اللغة] إلحاقُ كاف المؤنّث سينا عند الوقف دون الوصل في لهجة قبيلة هوازن، فيقولون : أعْطَيْتِكِسْ وَمِنْكِسْ في أعْطَيْتِكِ ومِنْكِ.
§ك س ل
كَسِلَ يَكْسَلُ كَسَلاً كَسِلٌ وَكَسْلانُ : ــ الشخصُ : فَتَرَ وتَثَاقَلَ وتَوانَى، عكسه نَشِطَ «كَسِلَ التّلميذُ فلم يكتب تمارينه».
تَكَاسَلَ يَتَكَاسَلُ تَكَاسُلاً : ١ ــ الشّخصُ : كَسِلَ، ٢ ــ الشخصُ : تعمَّدَ الكَسَلَ «تَكاسَلَ الطّالِبُ النَّجيبُ».
تَكَاسُلٌ : مص تَكَاسَلَ.
كَسَلٌ : مص كَسِلَ.
كَسْلانُ/كَسْلانُ مؤ كَسْلانَةٌ وَكَسْلَى جمعهما كُسَالَى : مُتثاقِلٌ فاتِرٌ متوانٍ ﴿وَإِذَا قَامُوا إِلَى الصَّلاةِ قَامُوا كُسَالَى﴾ [قرآن].
كَسُولٌ : ١ كَسْلانُ، ٢ نَعْتٌ لِلْجَارِيَةِ المُنَعَّمَةِ الّتي لا تَكَادُ تُفَارِقُ مَجْلِسَهَا.
كَسَلاَ : مدينة سودانية في شمال شرقي البلاد وقاعدة مديرية كسلا.
§ك س و
كَسَا يَكْسُو كَسْوًا كَاسٍ (الكاسِي) مَكْسُوٌّ : ١ ــ هُ ثَوْبًا : أَلْبَسَهُ إيَّاهُ، ٢ ــ هُ شِعْرًا : مَدَحَهُ به ◆ كَسَا حَدِيثَهُ مُلَحًا : جعله مَرِحًا.
أَكْسَى يُكْسِي إِكْسَاءً مُكْسٍ (المُكْسِي) مُكْسًى : ١ ــ الشخصَ ثوبا : أَلْبَسَهُ إيَّاهُ، ٢ ــ كَلامَهُ كَذَا : أضفَى عَلَيْهِ «أَكْسَى حَدِيثَهُ مُلَحًا ونَوَادِرَ».
اِكْتَسَى يَكْتَسِي اكْتِسَاءً مُكْتَسٍ (المُكْتَسِي) : ١ ــ الشخصُ : لَبِسَ كُسْوَةً، ٢ ــ تِ الأرضُ بالنّباتِ : تَغَطَّتْ بِهِ.
اِكْتِسَاءٌ : مص اكتَسَى.
إِكْسَاءٌ : مص أَكْسَى.
كِسَاءٌ ج أَكْسِيَةٌ : لِبَاسٌ، ثِيابٌ «أَكْسِيَةُ الشّتاءِ».
كَسْوٌ : مص كَسَا.
كُسْوَةٌ/كِسْوَةٌ ج كُسًى : ١ لِبَاسٌ «كسوة الشتاء»، «كُسْوَةُ البَيْتِ»، ٢ بَدْلَةٌ «لَبِسَ كِسْوَةً زَرْقاءَ جَمِيلَة» ◆ الكِسْوَةُ الشَّرِيفَةُ : لِبَاسٌ تُكْسَى بِهِ الكَعْبَةُ بِمَكَّةَ المُكَرَّمَة ويُغَيَّرُ كُلَّ عام.
§ك ش ت ب ا ن
كُشْتُبَانٌ/كُشْتِبَانٌ : قِمَعٌ صغيرٌ يُغطّي طَرَفَ إصْبَعِ الخَيَّاطِ لِيَقِيهِ وَخْزَ الإبرِ.
§ك ش ح
كَشَحَ يَكْشَحُ كَشْحًا فهو كَاشِحٌ : ١ ــ تِ الدّابَّةُ : أدْخَلَتْ ذَنَبَهَا بينَ رِجْلَيْهَا، ٢ ــ الطّائِرُ : رجَعَ عن الماءِ مُسْرِعًا ◆ كَشَحَ الظَّلاَمُ : أدبر.
كُشِحَ يُكْشَحُ : ١ ــ الشّخصُ : كُوِيَ على الكَشْحِ، ٢ ــ القومُ عن الماء : ذَهَبُوا عَنْه وتَفَرَّقُوا.
كَاشَحَ يُكَاشِحُ مُكَاشَحَةً : ــ هُ بالعَدَاوَةِ : عاداهُ.
كَاشِحٌ ج ــ ون : عَدُوٌّ مُضْمِرٌ لِلْعَدَاوَةِ.
كُشَاحٌ : داء يصيبُ الكشح «ذات الجنب».
