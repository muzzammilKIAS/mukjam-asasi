@شد
شَدٌّ : ١ مص شَدَّ²، ٢ [في الهندسة] : القوة التي تميل إلى زيادة طول الجسم أو أبعاده.
شَدَّةٌ ج شَدَّاتٌ : ١ حَمْلَةٌ في الحرب : «شدَّ على العدو شدة مباغتة»، ٢ رأس شين توضع على الحرف (ـّ) دلالة على تضعيفه.
شِدَّةٌ : ١ مص شد¹، ٢ أمر يصعب تحمله «شِدَّةُ الحر»، «شدة العيش» «شدة الألم»، «شدة القتال»، «شدة المناقشة»، «أخذه بالشدة»، ٣ [جيولوجيا] : أقصى إجهاد يتحمله جسم صلب دون أن يتمزق.
شَدِيدٌ ج شِدَادٌ وأَشِدَّاءُ مؤ شديدة ج شَدِيدَاتٌ وشدائدُ : ١ قويٌّ يغلب الناس : ﴿عَلَّمَهُ شديدُ القُوَى﴾ [قرآن]، «ليس الشَّديد بالصُّرَعَةِ، إنما الشَّدِيدُ الذي يملك نفسه عند الغضب» [حديث]، ويقال كذلك : «عطر شديد الرائحة» «أحمر شديد الحمرة»، «عقاب شديد»، ٢ صعب : «لا تكن شديدًا في معاملة أبنائك»، ٣ [في علم الأصوات] صوت شديد ينحبس الهواء عند النطق به انحباسا تاما ثم يُسَرَّح تسريحا فجائيا مثل صوت الباء (انفجاري) ◆ خطاب شديد اللهجة : قاس في عبارته شديد الوَطْأَةِ : عنيف ثقيل التحمل.
مُشَادَّةٌ : ١ مص شَادَّ، ٢ ج مشادّاتٌ : معركة : «جرت بينهما مشادة كلامية».
مِشَدٌّ ج مِشَدَّاتٌ : نِطَاقٌ تَشُدُّهُ المرأة على بطنها وأردافها لِتَدِقَّ (كورسيه).
§ش د ر
شادِرٌ ج شَوَادِرُ : (انظر ألفبائيا).
§ش د ف
شادوفٌ ج شَوَادِيفُ : آلة لري الأرض.
§ش د ق
تَشَدَّقَ يَتَشَدَّقُ تَشَدُّقًا : ١ ــ الرجلُ : حَرَّكَ شِدْقَيْهِ للمضغ، ٢ ــ المتكلمُ بالكلام : لَوَى شِدْقَيْهِ تَفَاصُحًا.
أَشْدَقُ مؤ شدقاءُ جمعهما شُدْقٌ : واسع الشِّدْقَيْنِ.
تَشَدُّقٌ : مص تَشَدَّقَ.
شِدْقٌ / شَدْقٌ ج أَشْدَاقٌ وشُدُوقٌ : جانب الفم مما تحت الخد «ضحك ملء شدقيه»، ويستعمل مجازا لجانب الشيء، فيقال : «نزل بشدق الوادي».
الشِّدْيَاقُ : (انظر ألفبائيا).
§ش د ن
شَدَنَ يَشْدُنُ شُدُونًا شادن : ــ الظبيُ : ترعرع واستغنى عن أمه.
أَشْدَنَ يُشْدِنُ إِشْدَانًا : ــت الظبيةُ : شَدَنَ ولدها.
إِشْدَانٌ : مص أَشْدَنَ.
شادِنٌ ج شوادنُ : ولد الظبية.
شُدونٌ : مص شَدَنَ.
مُشْدِنٌ ج مشادِنُ : ظبية ــ : شدن ولدها.
§ش د ه
شُدِهَ يُشْدَهُ : ــ الشخصُ : دُهش بالأمر وتحير «بقي / وقف مشدوها».
أَشْدَهَ يُشْدِهُ إِشْدَاهًا : ــ ه الأمرُ : حَيَّرَهُ وأدهشه.
اِنْشَدَهَ يَنْشَدِهُ انْشِدَاهًا : ــ الشخصُ : تَحَيَّرَ.
إِشْدَاهٌ : مص أَشْدَهَ.
اِنْشِدَاهٌ : مص انْشَدَهَ.
§ش د و
شَدَا يَشْدُو شَدْوًا شادٍ (الشادي) : ١ ــ بالشعر : تَرَنَّمَ وتغنى، ٢ ــ من الأدب والعلم : حَصَّلَ منه طَرَفًا، ٣ ــ شَدْوَ فُلَانٍ : تَشبه به.
شَادٍ (الشَّادِي) ج شُدَاةٌ : ١ المغني، ٢ طالب الأدب والعلم.
شَدْوٌ : مص شَدَا.
