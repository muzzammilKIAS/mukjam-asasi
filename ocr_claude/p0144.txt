بَرَدَ يَبْرُدُ بَرْدًا و بُرودًا فهو بارد : ١ ــ الجوُّ : هبطت حرارته، ٢ ــ الشخصُ : فتَرَ وقلّ حماسُه «جَدَّ في الأمر ثم بَرَدَ»، ٣ ــ الشيءَ : جعله باردًا، ٤ ــ الحديدَ ونحوه بَرْدًا : سَحَلَه أي أخذ منه بالمبرد، ٥ ــ بريدًا : أرسله.
بَرُدَ يَبْرُدُ بُرودةً فهو بارد : ــ الجو : صار باردًا.
بَرَّدَ يُبَرِّدُ تبريدًا : ١ ــ عن الشخص : خفّف «بَرَّد غليله»، «لا تُبَرِّدوا عن الظالم» [حديث]، ٢ ــ الشيءَ : جعله باردًا «بَرَّد الشراب»، ٣ ــ البَيْتَ ونحوه : جعله باردًا بإحدى وسائل التبريد أو تكييف الهواء، ٤ ــ الطعامَ ونحوه : وضعه في الثلاجة، ٥ ــ الشخصَ : فَتَّره وأضعف همّته.
أَبْرَدَ يُبْرِدُ إبرادًا : ١ ــ الرسالة / بالرسالة : أرسلها بالبريد، ٢ ــ الماءَ : بَرَّدَهُ.
تَبَرَّدَ يَتَبَرَّدُ تَبَرُّدًا : بالماءِ : اغتسل به باردًا.
اِبْتَرَدَ يَبْتَرِد اِبْتِرادًا : ١ ــ الشخصُ : اغتسل بالماء البارد، ٢ شَرِبَ الماءَ ليبرِدَ جوفُه.
اِبتِرادٌ : مص ابْتَرَدَ.
إبْرادٌ : مص أَبْرَدَ.
بارِدٌ : عكس حار «يتميز الشتاء بجوّه البارد» ◆ استقبال بارد : خال من العاطفة. إنسانٌ بارِدٌ / بارِدُ الطبع : مفرط في هدوئه لا يستجيب بسرعة. تبغ بارد : معتدل. حُجة باردة : ضعيفة واهية. حربٌ باردة : حرب الدعاية والكلام دون استعمال السلاح. سلام بارد : حالة سلام يشوبه الفتور [استعمال حديث] «وصفت العلاقات بين مصر وإسرائيل بأنها سلام بارد». ضرب في حديد بارد : بذل جهدا ضائعا. عَيْشٌ بارِدٌ : هَنيءٌ سهلٌ. غنيمة باردة : تُنال بدون تعب «الصومُ في الشتاء الغنيمةُ الباردةُ». [حديث] نكتة باردة : مُتكلِّفة لا حرارة فيها.
