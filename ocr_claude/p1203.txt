@متنطع
مُنَاضَلَةٌ : مص نَاضَلَ.
نِضَالٌ : مص نَاضَلَ «نضال من أجل الحرية»، «في نضال مع الفقر».
نِضَالِيٌّ : منسوب إلى النضال «مَوَاقِفُ نِضَالِيَّةٌ مُشَرِّفَةٌ».
نَضْلٌ : مص نَضَلَ.
§ن ض و
نَضَا يَنْضُو نَضْوًا فهو ناضٍ : ــ الثوبَ : خلعه وألقاه عنه.
انتضى ينتضي انتضاءً : ــ السيفَ : سَلَّه وأخرجه من غمده.
§ن ط ح
نَطَحَ يَنْطَحُ نَطْحًا فهو ناطح : ــ هُ الثَّوْرُ ونَحوُه : أصَابَه بقَرْنِهِ «نَطَحَ الكَبْشُ الصَّبِيَّ» ◆ نَطَحَ فُلانًا عن كذا : دَفَعَهُ وأزَالَهُ.
نَاطَحَ يُنَاطِحُ مُنَاطَحَةً : ــ هُ : نَطَحَ كلُّ مِنْهُما الآخَرَ «نَاطَحَ كَبْشِي كَبْشَهُ».
تَنَاطَحَ يَتَنَاطَحُ تَنَاطُحًا : ١ ــ الكَبْشَانِ : نَطَحَ كلُّ مِنْهُما الآخَرَ، ٢ ــ تِ الأمْواجُ : تَلاطَمتْ ◆ هَذَا أمْرٌ لا يَتَنَاطَحُ فيه كَبْشَانِ : لَا يَخْتَلِفُ فِيه اثْنَانِ.
تَنَاطُحٌ : مص تَنَاطَحَ.
مُنَاطَحَةٌ : ١ مص نَاطَحَ ج مُنَاطَحَاتٌ : صِرَاعُ ذَوَاتِ القُرُونِ «مُنَاطَحَةُ الأكْبَاشِ».
نَاطِحَةٌ ج نَوَاطِحُ : مذ نَاطِحٌ «بَقَرَةٌ نَاطِحَةٌ» ◆ نَاطِحَةُ السَّحَابِ ج ناطحات : بناءٌ عالٍ ذاهِبٌ في السَّمَاءِ، صَرْحٌ.
نَطْحٌ : مص نَطَحَ.
نَطِيحَةٌ ج نَطْحَى ونَطَائِحُ : شَاةٌ مَنْطُوحَةٌ تَمُوتُ ⟦?⟧ يَحِلُّ أكْلُهَا.
§ن ط ر
نَطَرَ يَنْطُرُ نَطْرًا فهو ناطر : ١ ــ الزَّرْعَ ونَحوَه : حَفِظَه وسَهَرَ عليهِ، ٢ ــ هُ عنه : أبْعَدَهُ في قُوَّةٍ وغِلْظَةٍ.
نَطْرٌ : مص نَطَرَ.
ناطور ج نواطير : حارس الزرع.
نُطَّارٌ ج نَطَاطِيرُ : خَيَالٌ يُنْصَبُ بين الزَّرْعِ ونحوِه لِتَخْوِيفِ الطُّيُورِ والبَهَائِمِ كَيْ لا تُفْسِدَهُ.
§ن ط س
نَطِسَ يَنْطَسُ نَطَسًا فهو نَطِسٌ : ــ الشخصُ : أدقَّ النَّظَرَ في الأُمورِ واسْتَقْصَاهَا.
نَاطِسٌ ج نُطَّسٌ : جَاسُوسٌ.
نِطَاسِيٌّ ج ــ ون ونُطُسٌ : ١ طَبِيبٌ حَاذِقٌ، ٢ عَالِمٌ مَاهِرٌ.
نَطَسٌ : مص نَطِسَ.
نَطِسٌ ج ــ ون : دقيق النظر، ماهر.
§ن ط ط
نَطَّ (نَطَطْتُ) يَنِطُّ نَطًّا ونَطِيطًا فهو نَاطٌّ : ١ ــ الشَّخْصُ ونَحْوُه : وَثَبَ «نَطَّتِ القِطَّةُ»، ٢ ــ الشَّخْصُ في الأَرْضِ : ذَهَبَ فيها، ٣ ــ في كلامه : هَذَرَ.
نَطٌّ : مص نَطَّ.
نَطَّاطٌ : ١ كثير النَّطِّ «قِطٌّ نَطَّاط»، ٢ ج ــ ون : مِهْذَارٌ كثيرُ الكَلَامِ.
نَطِيطٌ : مص نَطَّ.
§ن ط ع
نَطَعَ يَنْطَعُ نَطْعًا فهو ناطِعٌ : ــ اللُّقْمَةَ : أُكِلَ منها ثُمَّ رَدَّها إلى المائِدَةِ.
تَنَطَّعَ يَتَنَطَّعُ تَنَطُّعًا : ١ ــ الشَّخْصُ في الشَّيْءِ : غَالَى وتَكَلَّفَ فيه «تَنَطَّعَ الشّابُّ في شهواته»، ٢ ــ الشَّخْصُ في الكَلام : تَفَصَّحَ فِيه وتَعَمَّقَ.
تَنَطُّعٌ : مص تَنَطَّعَ.
مُتَنَطِّعٌ ج ـون : طَائِشٌ مغرور «شَابٌّ مُتَنَطِّعٌ»، «فَتَاةٌ متنطِّعَةٌ».
