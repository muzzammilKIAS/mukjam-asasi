@إيجاز
↩ ولم يُطِلْ، ٤ ــ في كلامِهِ : اخْتَصَرَهُ وقَلَّلَهُ «تَكَلَّمَ في إيجَازٍ».
إِيجَازٌ : ١ مص أَوْجَزَ، ٢ [في البلاغة] : تضمين اللَّفظ القليل المعنى الكثير ﴿وَلَكُمْ فِي الْقِصَاصِ حَيَاةٌ﴾ [قرآن].
مُوجَزٌ ج مَوَاجِزُ : خلاصةٌ لِكلاَم أو مَقَالَة «أُرْدِفَ بَحْثُهُ بِمُوجَزٍ فيه ما قَلَّ وَدَلَّ»، «تُقَدِّم الاذاعة مَوَاجِزَ للأخْبَارِ كل ساعة».
وَجْزٌ : مص وَجَزَ.
وُجُوزٌ : مص وَجَزَ.
وَجِيزٌ : قَصِير، مُخْتَصَر «عِبَارة وجيزة»، «جاءَ بعد فترة وجيزة».
§و ج س
وَجَسَ يَجِسُ وَجْسًا ووَجَسَانًا فهو وَاجِسٌ : ١ ــ الشيءُ : خَفِيَ، ٢ ــ الشخصُ : فَزِعَ مِمَّا سَمِعَهُ أو وَقَعَ في قَلْبِهِ من صَوْتٍ أو غيرِهِ «وَجَسَ خِيفَةً من هذا الأمرِ».
أَوْجَسَ يُوجِسُ إيجَاسًا : ١ ــ الشخصُ : وَقَعَ في نفسِه الخَوْفُ، ٢ ــ ت الأُذُنُ : سَمِعَتْ حِسًّا، ٣ ــ الشَّخصُ الأمرَ : أضْمَرَهُ «أوْجَسَ الْمَلَلَ»، ٤ ــ القَلْبُ شَيْئا : أحَسَّ به أو خافَهُ «أوْجَسَ قَلْبُها فَزَعا» ﴿فَأَوْجَسَ فِي نَفْسِهِ خِيفَةً مُوسَى﴾ [قرآن].
تَوَجَّسَ يَتَوَجَّسُ تَوَجُّسًا : ١ ــ الشخصُ : تَسَمَّعَ إلى الصَّوْتِ الخَفِيّ، ٢ ــ تِ الأُذُنُ : سَمِعَتْ حِسًّا، ٣ ــ الصَّوْتَ : سَمِعَهُ خائِفا ◆ تَوَجَّسَ مِنْهُ شَرًّا : أحَسَّ به وتَخَوَّفَ من وُقُوعِهِ.
إِيجَاسٌ : مص أَوْجَسَ.
تَوَجُّسٌ : مص تَوَجَّسَ.
وَاجِسٌ : هَاجِسٌ، خَاطِرٌ.
وَجْسٌ : ١ مص وَجَسَ، ٢ صوت خَفِيّ.
وَجَسَانٌ : مص وَجَسَ.
§و ج ع
وَجِعَ يَوْجَعُ وَجَعًا فهو وَجِعٌ : ــ الشخصُ : مَرِضَ وتَأَلَّمَ.
أَوْجَعَ يُوجِعُ إِيجَاعًا : ١ ــ هُ : جَعَلَهُ يَتَأَلَّمُ «أَوْجَعَهُ الضَّرْبُ»، «أَوْجَعَتْهُ مَصَائِبُ البِلاَدِ»، ٢ ــ في العَدُوِّ : أَثْخَنَ فيه ونَالَ منه.
تَوَجَّعَ يَتَوَجَّعُ تَوَجُّعًا : ١ ــ الشَّخصُ : اشْتَكَى من الألم، ٢ ــ الشَّخصُ لِفُلان مِمَّا نَزَلَ بِهِ : رَثَى له مِنه «تَوَجَّعَ الصَّدِيقُ لِصَدِيقِهِ من فِقْدَانِ آنِيَتِهِ».
إِيجَاعٌ : مص أَوْجَعَ.
تَوَجُّعٌ : مص تَوَجَّعَ.
وَجَعٌ : ١ مص وَجِعَ، ٢ ج أَوْجَاعٌ : اسْمٌ جامِعٌ لِكُلِّ مَرَض وَألَم «وَجَعُ الأسْنَانِ»، «أوْجَاعُ الرَّأسِ».
وَجِعٌ ج ــ ون ووَجْعَى مؤ وَجِعَةٌ ج وَجِعَاتٌ ووَجَاعَى : مريض متألّم.
وَجِيعٌ : مُوجِعٌ «ضَرْبٌ وَجِيعٌ».
§و ج ف
وَجَفَ يَجِفُ وَجْفًا ووُجُوفًا ووَجِيفًا فهو وَاجِفٌ : ١ ــ الشَّيْءُ : اضطَرَبَ، ٢ ــ القَلْبُ : خَفَقَ ﴿قُلُوبٌ يَوْمَئِذٍ وَاجِفَةٌ﴾ [قرآن].
أَوْجَفَ يُوجِفُ إيجَافًا : ــ دابَّتَهُ : حملها على الاسْرَاعِ في السَّيْرِ ﴿فَمَا أَوْجَفْتُمْ عَلَيْهِ مِنْ خَيْلٍ وَلاَ رِكَابٍ﴾ [قرآن].
إِيجَافٌ : مص أَوْجَفَ.
وَجْفٌ : مص وَجَفَ.
وُجُوفٌ : مص وَجَفَ.
وَجِيفٌ : مص وَجَفَ.
§و ج ل
وَجِلَ يَوْجَلُ وَجَلاً فهو وَجِلٌ : ــ الشَّخصُ : خَافَ وفَزِعَ ﴿الَّذِينَ إِذَا ذُكِرَ اللَّهُ وَجِلَتْ قُلُوبُهُمْ﴾ [قرآن].
أَوْجَلَ يُوجِلُ إيجَالاً : ــ هُ : أخَافَهُ.
وَجَلٌ : مص وَجِلَ.
