@تشاكس
تَشَاكَسَ يَتَشَاكَسُ تَشَاكُسًا : ــ الرجلان : تخالفا وتعاسرا ﴿فِيهِ شُرَكَاءُ مُتَشَاكِسُونَ﴾ [قرآن].
تَشَاكُسٌ : مص تَشَاكَسَ.
شَكَاسَةٌ : مص شَكِسَ.
شَكْسٌ : مص شَكِسَ.
مُشَاكَسَةٌ : مص شَاكَسَ.
§ش ك ك
شاكوش ج شواكيش : المطرقة الصغيرة.
شَكَّ¹ (شَكَكْتُ) يَشُكُّ شَكًّا شَاكٌّ : ١ ــ عليه الأمرُ : التبس، ٢ ــ في الأمر : ارتاب ﴿فَإِنْ كنتَ في شَكٍّ مِمَّا أَنْزَلْنَا إِلَيْكَ﴾ [قرآن].
شَكَّ² (شَكَكْتُ) يَشُكُّ شَكًّا شَاكٌّ : ١ ــ الشيءَ : خَرَقَهُ، ٢ ــ الجلد : وَخَزَهُ، ٣ ــ فلانا بالرمح : طَعَنَهُ.
شَكَّكَ يُشَكِّكُ تَشْكِيكًا : ١ ــ الرَّجُلَ : أوقعه في الشك : «شككني أمرك»، ٢ ــ البائعُ المشتري : أعطاه السِّلْعَةَ بالأجل.
تَشَكَّكَ يَتَشَكَّكُ تَشَكُّكًا : ــ في الأمر : شَكَّ فيه «تشككت في صحة أقوالك».
انْشَكَّ يَنْشَكُّ انْشِكَاكًا : مطاوع شَكَّ.
انْشِكَاكٌ : مص انْشَكَّ.
تَشَكُّكٌ : مص تَشَكَّكَ.
تَشْكِيكٌ : مص شَكَّكَ.
شَكٌّ : ١ مص شَكَّ «وضعه موضع الشك»، ٢ ج شُكُوكٌ : حالة نفسية يتردد معها الذهن بين الإثبات والنفي ويتوقف عن الحكم ◆ أفعال الشك واليقين [في النحو] : مثل ظن وحسب وعلم، وتختص بجواز كون فاعلها ومفعولها ضميرين متصلين صاحبهما واحد نحو : «ظننتُنِي قادرا على هذا العمل» أي ظننت نفسي قادرا بدون شك : أمر مسلم لا يقبل الإنكار لا شك في كذا / لا يتطرق / لا يرق إليه الشك / لا سبيل إلى الشك فيه : مُسَلَّم بصحته.
شَكَّاكٌ ج شَكَّاكُونَ وشُكَّاكٌ : كثير الشك.
الشَّكَّاكُونَ : فرقة من الفلاسفة يترددون بين إثبات حقائق الأشياء وإنكارها، ويسمون في الفلسفة الإسلامية «اللاأدرية».
شَكَّةٌ ج شَكَّاتٌ : المرة من الشك : «شكة دبوس».
شَكُوكٌ : مثير للشَّكِّ «أمر شكوك».
§ش ك ل
شكل يشكُلُ شَكْلًا فهو شاكل : ــ الكتاب : ضبطه بالشكل.
شَكِلَ يَشْكَلُ شَكَلًا وشُكْلَةً أَشْكَلُ : ١ ــ اللونُ : خالطه لونٌ غيره، ٢ ــ : خالط بياضَهُ حُمْرَةٌ.
شَكَّلَ يُشَكِّلُ تَشْكِيلًا : ١ ــ الكتابَ : ضبطه بالشُّكْلِ، ٢ ــ الفنانُ الشيءَ : صَوَّره، ومنه : «الفنون التشكيلية»، ٣ ــ الحكومة واللجنة : سمى أعضاءها ◆ شَكَّلَ خطرًا : تسبب في وقوع الضرر «تشكل الحرب العراقية الإيرانية خطرا على المنطقة كلها».
شاكَلَ يُشَاكِلُ مُشَاكَلَةً : ــ ه : شابهه وماثله : «أنت لا تشاكل أباك في فضله وعلمه».
أَشْكَلَ يُشْكِلُ إِشْكَالًا : ــ الأمرُ : التبس واشتبه ◆ إشكال التنفيذ [مرافعات] : منازعة تتعلق بإجراءات تنفيذ الحكم.
تَشَكَّلَ يَتَشَكَّلُ تَشَكُّلًا : ــ الشيءُ : تَمَثَّلَ وتَصَوَّرَ «تشكل الجنين في بطن أمه».
تَشَاكَلَ يَتَشَاكَلُ تَشَاكُلًا : ــ الشيئان : تشابها وتماثلا : «رَقَّ الزجاجُ وراقت الخمر فتشابها فَتَشَاكَلَ الأمْرُ»
اسْتَشْكَلَ يَسْتَشْكِلُ اسْتِشْكَالًا : ١ ــ الأمرُ : التبس، ٢ [في القضاء] ــ على الحكم / في تنفيذ الحكم : أُورِدَ عليه إشكالا لا يستدعي وقف التنفيذ.
اسْتِشْكَالٌ : مص اسْتَشْكَلَ.
إِشْكَالٌ : ١ مص أَشْكَلَ، ٢ ج إشكالات : مُشْكِلَةٌ : «أثار المتحدثُ إشكالات عدة في حديثه».
