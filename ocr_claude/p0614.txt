@سخط
سُخْطٌ : مص سَخِطَ.
§س خ ف
سَخُفَ يَسْخُفُ سُخْفًا وسَخافةً سَخيف : ضَعُف، رَقَّ «سَخُف عَقْلُهُ فسَخُفت آراؤُه».
سَخَّفَ يُسَخِّفُ تَسْخِيفًا : ــ هُ : ١ أَضْعَفَهُ «سَخَّفَ الكِبَرُ عَقْلَه»، ٢ نَسَبَه إلى السُّخْف «سَخَّفَ بعضُ الناس آراءَهُ فانْسَحَبَ من المَجْلس».
تَسْخِيفٌ : مص سَخَّفَ.
سَخافَةٌ : مص سَخُفَ.
سُخْفٌ : مص سَخُفَ.
سَخيفٌ¹ : ضعيف «هذا رَأْي سَخيف».
سَخيفٌ² ج سُخَفاءُ : شَخْص سَخيف : ضَعيف الرأي.
§س خ ل
سَخْلة ج سَخْلٌ، و سِخالٌ : الذَّكَر و الأُنثى من وَلَد الضَّأْن والمَعْز.
§س خ م
سَخَّمَ يُسَخِّمُ تَسْخِيمًا : سَوَّد «سَخَّم اللهُ وَجْهَهُ».
أَسْخَمُ ج سُخْمٌ مؤ سَخْماء ج سُخْمٌ وسَخْماواتٌ : أسْود «لَيْلٌ أَسْخَمُ».
تَسْخيمٌ : مص سَخَّم.
سُخامٌ : ١ سواد القِدْر «تَلَوَّثت يَداه بالسُّخام»، ٢ الفَحْم، ٣ [في علم النبات]: مرض يصيب الورق والأغصان في بعض النباتات كالعنب والبرتقال فيحدث عليها طبقة سوداء.
سَخَمٌ : سَواد.
سُخْمَةٌ : ١ سواد، ٢ غضب.
§س خ ن
سَخُنَ يَسْخُنُ سُخونَةً ساخِن وسَخين : صار حارًّا «سَخُن الماءُ».
سَخَنَ يَسْخُنُ سُخونَةً وسَخانَةً سَخِينٌ : ــ الشيءُ : سَخُنَ.
سَخِنَ يَسْخَنُ سَخَنًا وسُخْنَةً وسَخين : ــ تِ العيْن : لم تَقَرَّ (لأن دموع الحزن تكون ساخنة).
سَخَّنَ يُسَخِّنُ تَسْخِينًا : ــ هُ : جعله ساخِنًا «سَخِّنْ لنا الطَّعام».
أَسْخَنَ يُسْخِنُ إسْخانًا : ــ ه : سَخَّنَهُ ◆ أَسْخَن الله عينه : أَنْزَلَ به ما يُبْكيه، عكسه : أَقَرَّ اللهُ عَينَه.
إسْخانٌ : مص أَسْخَنَ.
تَسْخينٌ : مص سَخَّنَ.
ساخِنٌ : حارّ «هواء ساخِن».
سَخانَةٌ : مص سَخُنَ.
سَخّانٌ ج ــ ات : جهاز تسخين ماء الأنابيب الموصولة بالحنفيات.
سَخَنٌ : مص سَخِنَ.
سُخْنٌ : ساخِن.
سُخْنَةٌ : ١ مص سَخِن، ٢ حُمَّى «أُصيب بالسُّخْنة» ◆ عَلَيْكَ بالأمر عند سُخْنَتِه : في أَوَّله (قَبْلَ أن يَبْرُد).
سُخُونَةٌ : ١ مص سَخُنَ وسَخَنَ، ٢ سخونة النفاس [في الطب] : ارتفاع الحرارة في المدة التي تلي الولادة.
سَخين : ساخِن.
§س خ و / س خ ي
سَخا يَسْخو سَخاءً ساخٍ (السّاخِي) : بالشيء : جاد به «سَخا بماله للمحتاجين».
سَخُوَ يَسْخو سَخاوةً سَخِيّ : صار كريمًا.
سَخِيَ يَسْخى سَخًى : ١ سَخا، ٢ سَخَت نَفْسُه عن الشيء : تَرَكَهُ تَخَلّى عنه «لم تَسْخَ نَفْسُه عن أيّ شيء من ماله».
سَخاءٌ : مص سَخا.
سَخاوةٌ : مص سَخُوَ.
السخاويّ : (انظر ألفبائيا).
سَخًى : مص سَخِيَ.
سَخِيٌّ ج أَسْخِياءُ : كريم «كان حاتم سَخِيًّا».
