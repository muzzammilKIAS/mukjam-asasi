@خطأ
↩ ونحوه : خضخضه وحَرَّكه «يُخضُّ الدواءُ في القِنّينة قبل الاستعمال»، ٢ ــ الشخصَ : أخافه وأفزعه.
خَضٌّ : مص خَضَّ ◆ لَبَنٌ خَضٌّ : مَخيضٌ رائب.
§خ ض ع
خَضَعَ يَخْضَعُ خُضُوعًا فهو خَاضِعٌ : ١ ــ لَهُ : انقادَ وسَكَنَ وذلَّ «خَضَعَ لرئيسه»، «يخضع المواطن الصالح للقانون والنظام»، ٢ ــ لله : تواضع، ٣ ــ بالقول : لَيَّنَهُ ﴿فَلَا تَخْضَعْنَ بِالْقَوْلِ فَيَطْمَعَ الَّذِي فِي قَلْبِهِ مَرَضٌ﴾ [قرآن] ◆ خاضع للضريبة : يجب عليه أداء الضرائب خَضَعَ للمناقشة : طُرِحَ على بِساط البَحْث.
أَخْضَعَ يُخْضِعُ إخْضاعًا : ــ الشخصَ : جعله يخضع، أرغمه على الخضوع «أخضعَ الفقرُ الرجُلَ».
إخْضَاعٌ : مص أخْضَعَ «عجز الطغاة عن إخضاع الأحرار».
خَضُوعٌ ج ــ ون : مبالغ في الخُضوع (فعول بمعنى فاعل) «أتى الجيلُ الجديدُ خضوعا لِلْمَدَنِيَّةِ الحديثة فثار على التقاليد دون تمييز».
خُضُوعٌ : مص خَضَعَ.
§خ ض ل
خَضِلَ يَخْضَلُ خَضَلًا فهو خَضِلٌ وأخْضَلُ : ــ الشيءُ : نَدِيَ وابتلَّ «خَضِلَ الثوبُ».
خَضَّلَ يُخَضِّلُ تَخْضِيلًا : ــ الشيءَ : نَدَّاه وبَلَّلَهُ «خُضِّلت تربة الوطن بالدماءِ الزكية».
أَخْضَلَ يُخْضِلُ إخْضَالًا : ــ الشيءَ : خَضَّلَهُ بقوة «أخضلتنا السماءُ»، «فَبَكَوا حَتَّى أَخْضَلُوا لِحاهُمْ» [حديث].
اِخْضَلَّ يَخْضَلُّ اخْضِلَالًا : خَضِلَ «اخْضَلَّتْ لحيته بالدموع».
إخْضَالٌ : مص أخْضَلَ.
أَخْضَلُ مؤ خضلاء جمعهما خُضْلٌ : يد ناعم «إنها خضلاء اليد لكنها جريئة القلب».
اِخْضِلَالٌ : مص اخْضَلَّ.
تَخْضِيلٌ : مص خَضَّلَ.
خَضَلٌ : مص خَضِلَ.
خَضِلٌ مؤ خَضِلَةٌ : أخضل «عيش خضل»، «نبات خضل».
§خ ض م
خَضَمَ يَخْضِمُ خَضْمًا : ١ ــ الشيءَ : قطعه، ٢ ــ الطعامَ : أكَلَهُ بجميع فمه.
خَضْمٌ : مص خَضَمَ.
خِضَمٌّ : ١ بَحْرٌ واسع، ٢ ج ــ ون : فُلانٌ خِضَمٌّ : جَوادٌ كريم.
§خ ط أ
خَطِئَ يَخْطَأُ خَطَأً وخِطْئًا فهو خَاطِئٌ ــ الشخصُ : قارف ذنبا (عمدا كان أو سهوا) «نَظْرتك للأحداث نظرة خاطئة».
خَطَّأَ يُخَطِّئُ تَخْطِئَةً وتَخْطِيئًا : ــ د : نسبه إلى الخطأ «إنْ أَخْطَأْتُ فَخَطِّئْنِي».
أَخْطَأَ يُخْطِئُ إخْطَاءً : ١ ــ الرجُلُ : خَطِئَ «أخطأ حساباته»، «أخطأ في حساباته»، «أخطأ التقدير»، ٢ ــ ه السَّهْمُ ونحوه : تجاوزه ولم يُصبهُ «أخطأته الرصاصة»، «أخطأه الحقُّ / الحظُّ / التوفيق»، «مَا أَخْطَأَكَ لَمْ يَكُنْ لِيُصِيبَكَ، وَمَا أَصَابَكَ لَمْ يَكُنْ لِيُخْطِئَكَ» [حكمة].
إخْطَاءٌ : مص أخْطَأَ.
خِطْئَةٌ : مص خطأ.
خِطْءٌ : مص خَطأً.
خَاطِئَةٌ ج خَوَاطِئُ : ذَنْبٌ عظيم ﴿وَجَاءَ فِرْعَوْنُ وَمَنْ قَبْلَهُ وَ الْمُؤْتَفِكَاتُ بِالْخَاطِئَةِ﴾ [قرآن].
خَطَأٌ : ١ مص خَطِئَ، ٢ ج أخطاءٌ : عكس صواب «خَطَأٌ إملائيّ / لغوي»، «خطأ تاريخي»، «خطأ مطبعي»، ٣ [في الفلسفة] مخالفة قاعدة أو نظام كان الواجب احترامه، ٤ [في علم النفس] نقص في جهاز أو طريق أو إجراء يؤثر على صدق النتائج ◆ اِرْتُكِبَ
