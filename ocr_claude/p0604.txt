↩ الارض : غَذّاها بالسباخ (السماد).
أَسْبَخَ يُسْبِخُ إِسْبَاخًا : ــ ت الأرضُ : سَبِخَتْ.
إِسْبَاخٌ : مص أَسْبَخَ.
تَسْبِيخٌ : مص سَبَّخَ.
سِباخٌ مف سَبْخَة : ١ مالم يُفْلَح من الأرض لملوحته، ٢ سَماد (في مصر).
سَبَخٌ : مص سَبِخَ.
سَبِخٌ : أرض سَبِخة : ذات نَزٍّ ومِلْح.
سَبْخَةٌ ج سَبَخَاتٌ وسِباخٌ : منطقة مستنقعية لا تصلح للزراعة لملوحتها.
§س ب ر
سَبَرَ يَسْبُرُ سَبْرًا فهو سَابِر : ــ هُ و ــ غَوْرَه : خبره «سَبَرَ نواياه».
سَبْرٌ : ١ مص سَبَرَ، ٢ قياس عمق ماء البحر.
سَبُّورةٌ ج سَبُّوراتٌ : لوح كبير يعلق أمام جمهور من الناس يكتب عليه ويمحى.
مِسْبَارٌ ج مَسَابِيرُ : أداة تتخذ للفحص أو الاختبار، وهي أشكال تستعمل في الطب أو في الزراعة أو في المعدنيات.
§س ب س ب
سَبْسَبٌ ج سَبَاسِبُ : صحراء «جُزْء كبير من بَلَدِنا سَبْسَبٌ قاحِلٌ».
§س ب ط
سَبُطَ يَسْبُطُ سُبوطًا وسَباطة سَبْطٌ وسَبِطٌ : ــ الشَّعْرُ والاصبَعُ والقامة ونحوها : طَالَ.
سَبِطَ يَسْبَطُ سَبَطا سَبْطٌ : سَبُطَ.
سَباطةٌ : مص سَبُطَ.
سُبَاطَةٌ ج سُباطاتٌ : عنقود النخل يكون فيه ثمره.
سَبْطٌ / سَبِطٌ ج سِباط : ١ طويل «شخص سَبْط»، «سَبْطُ الأصابع»، ٢ شَعْر سَبط : مسترسل غير جعد، ٣ امرأة سبطة : لَيِّنة القَدّ.
سَبْطٌ : مص سَبِطَ.
سِبْطٌ ج أَسْبَاط : ١ حَفيد (ابن الابن أو الابنة) «تَزَوَّجَ ابنُه وأُنْجِبَ فأَصْبَحَ له سِبْط»، ٢ [عند اليهود] قبيلة ﴿وقَطَّعْناهم اثْنَتَي عَشْرة أَسْباطا﴾ [قرآن].
سبطانة : قناة جوفاء يرمى بها الطير بالبندق.
سُبوطٌ : مص سَبُطَ.
§س ب ع
سَبَعَ¹ يَسْبُعُ سَبْعًا فهو سابع : ١ ــ هُمْ : صار سابعهم، ٢ ــ هُمْ : أخذ سُبْعَ أموالهم، ٣ ــ الحَبْلَ ونحوه : جعله على سبع طاقات.
سَبَعَ² يَسْبَعُ سَبْعًا : ــ الوَحْشُ الغَنَمَ ونحوها : افترسها.
سَبَّعَ يُسَبِّعُ تَسْبِيعًا : ١ ــ ت العروسُ : مضى على دخولها أسبوع، ٢ ــ الحامِلُ : ولدت لسبعة أشهر، ٣ ــ الوالدةُ : مضى على ولادتها أسبوع، ٤ ــ المولودُ : مضت على ولادته سبعة أيام، ٥ ــ وا : اكتملوا سبعمئة «سَبَّعَتْ سُلَيْمٌ يوم الفتح» [حديث]، ٦ ــ الشيءَ : صيّره سبعة أو ذا سبعة أركان، ٧ ــ الإناءَ ونحوه غَسَلَهُ سَبْعَ مَرّات.
أَسْبَعَ¹ يُسْبِعُ إِسْبَاعًا : ١ ــ وا : صاروا سبعة، ٢ ــ الشيءَ : صيّره سبعة، ٣ ــ ت الحاملُ : ولدت لسبعة أشهر.
أَسْبَعَ² يُسْبِعُ إِسْبَاعًا : ــ المكانُ : كثُرت فيه السّباع.
إِسْبَاعٌ : مص أَسْبَعَ.
أُسْبُوعٌ ج أَسابيعُ : سبعة أَيّام «قَضَيْنَا أُسْبوعًا في مِصْرَ» ◆ أسبوع الآلام : [عند المسيحيين] الأسبوع الذي يبدأ بيوم الأحد السابق لعيد الفِصْحِ.
تَسْبِيعٌ : مص سَبَّعَ.
سابِعٌ : عدد ترتيبي يوصف به يلي سادس «عَقَدْنا سِتَّةَ اجتماعات وسَنَعْقِدُ الاجْتِمَاعَ السّابعَ غَدًا» ◆ سَابِعُ سَبْعة : أحد سبعة أشخاص ◆ سابع ستة : من / ما يضاف إلى الستة فيجعلها سبعة.
