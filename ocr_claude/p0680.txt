@شرر
↩ [مثل] ٣ ج أَشْرَارٌ وشِرَارٌ : ذو شَرّ، شِرِّير «رجلٌ شَرٌّ»، ٤ فلان شرّ الناس : أكثرهم شرًّا، وهي شَرُّ الناس وشَرَّتُهُنَّ.
شَرَرٌ مف شَرَرَةٌ : شَرَارٌ ﴿إِنَّها تَرْمِي بِشَرَرٍ كالقَصْرِ﴾ [قرآن]، «مُعْظَمُ النارِ من مُسْتَصْغَرِ الشَّرَرِ» [مثل] ◆ عيناه تقدحان بالشرر : تمتلئ نفسه بالغيظ.
شَرَانِيٌّ ج ــ ون : شِرِّيرٌ (نِسْبَةٌ إلى الشَّرّ بزيادة الألف والنون).
شِرَّةٌ : الحِدة، شِدَّة الغضب.
شِرِّيرٌ ج أَشْرَارٌ وأَشِرَّاءُ : كثير الشَّرّ «روح شريرة».
مُشَارَّةٌ : مص شَارَّ.
§ش ر ز
شِيرَازُ : (انظر ألفبائيا).
§ش ر س
شَرِسَ / شَرُسَ يَشْرَسُ / يَشْرُسُ شَرَسًا وشَرَاسَةً شَرِسٌ وأَشْرَسُ : ــ الشخصُ : ساء خُلُقُه، ويقال كذلك : «شَرِسَتْ نَفْسُهُ»، «فيه شَكَاسَةٌ وشَرَاسَةٌ».
تَشَارَسَ يَتَشَارَسُ تَشَارُسًا : ــ القومُ : تعادَوْا وتعاملوا بالسوء.
تَشَارُسٌ : مص تَشَارَسَ.
أَشْرَسُ مؤ شَرْساءُ جمعهما شُرْسٌ : سيء الخلق.
تَشَارُسٌ : مص تَشَارَسَ.
شَرَاسَةٌ : مص شَرِسَ.
شَرَسٌ : مص شَرِسَ.
الإشراس / الشَّراس : مادة يُلصق بها (إسراس، السراس).
§ش ر ش ر
شَرْشَرَ يُشَرْشِرُ شَرْشَرَةً : ١ ــ الماءُ ونحوه : تقاطر وتفَرَّق، ٢ ــ المنشارَ : جعل له أسنانا، ٣ ــ الورقةَ : جعل أطرافها متعرجة كأسنان المنشار.
شَرْشَرَةٌ : ١ مص شَرْشَرَ، ٢ مِنْجَلٌ صغير.
§ش ر ط
شَرَطَ يَشْرُطُ / يَشْرِطُ شَرْطًا : ١ ــ الجلدَ ونحوه : شَقَّه شقا يسيرا : «شَرَطَهُ الحَجَّامُ بمشرطه»، ٢ ــ عليه أمرا : اشترطه عليه وألزمه إياه، ٣ ــ له أمرا : التزمه.
شَرَّطَ يُشَرِّطُ تَشْرِيطًا : ١ ــ جِلْدَ الرجل : شقه عدة شقوق، ٢ ــ المريضَ : طَعَّمَهُ عن طريق وضع الدَّوَاءِ في شَقٍّ في جلده.
شَارَطَ يُشَارِطُ مُشَارَطَةً : ــ ه على كذا : شَرَطَ عليه.
اِشْتَرَطَ يَشْتَرِطُ اشْتِرَاطًا : ــ عليه كذا : شَرَطَ.
تَشَارَطَ يَتَشَارَطُ تَشَارُطًا : ــ الرجلان : شَرَطَ كلٌّ منهما على صاحبه.
اِشْتِرَاطٌ : مص اشْتَرَطَ.
أَشْرَاطٌ مف شَرَطٌ : أَشْرَاطُ السَّاعة : مقدماتها وعلامات وقوعها : ﴿فَهَلْ يَنْظُرُونَ إِلَّا السَّاعَةَ أَنْ تَأْتِيَهُمْ بَغْتَةً فَقَدْ جَاءَ أَشْرَاطُهَا﴾ [قرآن].
تَشَارُطٌ : مص تَشَارَطَ.
تَشْرِيطٌ : مص شَرَّطَ.
شَرْطٌ : ١ مص شَرَطَ، ٢ ج شُرُوطٌ : ما يوضع ليُلتزم في بيع أو نحوه «شروط المعاهدة»، «شروط القبول»، «بِشَرْطِ كذا»، ٣ [في الفقه] ما لا يتم الشيء إلا به دون أن يكون داخلا في حقيقته، ٤ [في النحو] ترتيب أمر على أمر آخر بأداة شرط بحيث إذا وجد الأول وجد الثاني «إن نجحت أعطيتك مكافأة سخية» ◆ أداة شرط : أداة لربط الجواب بالشرط مثل إنْ وإذا بدون قيد أو شرط : بدون أي اشتراطات.
شَرَطٌ ج أشراط : مقدمة الشيء وعلامته (انظر أشراط).
شُرْطَةٌ مف شُرْطِيٌّ ج شُرَطٌ : حَفَظَةُ الأمن في البلاد ◆ شرطة الآداب : الشرطة المكلفة بمراعاة الآداب العامة شرطة الإطفاء : الشرطة المكلفة بإطفاء الحرائق شرطة النَّجدة : الشرطة السريعة صاحبُ الشُّرْطة : رئيسها.
