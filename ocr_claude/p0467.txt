أَدْهَمُ¹ مؤ دَهْمَاءُ جمعهما دُهْمٌ : أَسْوَدُ «فرس أدهم».
أَدْهَمُ² ج أَدَاهِمُ : قَيْدٌ «أوعده بالسجن والأداهم».
اِدْهِمَامٌ : مص اِدْهَمَّ.
اِدْهِيمَامٌ : مص ادْهَامَّ.
دَهْمٌ : مص دَهَمَ.
دَهْمَاءُ ١ مؤ أَدْهَمُ، ٢ عامَّةُ الناسِ وجماعَتُهُمْ.
دُهْمَةٌ : مص دَهِمَ.
مُدَاهَمَةٌ : مص دَاهَمَ.
§د ه ن
دَهَنَ يَدْهُنُ دَهْناً : ١ ــ الشَّعْرَ : طلاه بالدُّهْنِ، ٢ ــ المطرُ الأرضَ : بَلَّها بَلًّا يسيرا، ٣ ــ الرجلُ ابنه بالعصا : ضربه برفق ◆ فلان يَدْهُنُ من قارورة فارغة : مثل يضرب للكذاب يعد ولا يفي.
أَدْهَنَ يُدْهِنُ إِدْهَاناً : ١ ــ الشخصُ : أظهر خلاف ما أضمر بقصد الخداع والغش، ٢ لَيَّنَ في القول وصائع ﴿وَدُّوا لَوْ تُدْهِنُ فَيُدْهِنُونَ﴾ [قرآن].
دَاهَنَ يُدَاهِنُ مُدَاهَنَةً : ١ ــ فُلَاناً : أظهر له خلاف ما أضمر، ٢ ــ ه : داراه ولاينه وصانعه.
اِدَّهَنَ يَدَّهِنُ ادِّهَاناً : ــ الرَّجُلُ : تَطَلَّى بالدُّهن.
اِدِّهَانٌ : مص ادَّهَنَ.
إِدْهَانٌ : مص أَدْهَنَ.
دِهَانٌ ج ــ ات وأَدْهِنَةٌ : ١ ما يُدهن به من الأصباغ ونحوها، ٢ جِلْدٌ أَحْمَرُ ﴿فَكَانَتْ وَرْدَةً كالدِّهَانِ﴾ [قرآن]، ٣ دُرْدِيُّ الزيت.
دَهْنٌ : مص دَهَنَ.
دُهْنٌ ج دُهُونٌ ودِهَانٌ وأَدْهَانٌ : المادَّةُ الدَّسِمَةُ في الحيوان والنبات.
دَهْنَاءُ ج دَهْنَاوَاتٌ : أَرْضٌ رملية (فَلَاة).
الدَّهْنَاءُ : صحراء بالمملكة العربية السعودية، في الجزء الشرقي منها تمتد من النفود الكبرى شمالا إلى الربع الخالي جنوبا بانحناء يتخذ شكل هلال.
دُهْنِيٌّ : منسوب إلى الدُّهْنِ «لا تكثر من أكل المواد الدهنية» ◆ شَعْرٌ دُهْنِيٌّ : تكثر المواد الدهنية فيه.
دَهَّانٌ ج ــ ون : بَائِعُ الدُّهْنِ : محترف الدُّهن.
مُدَاهَنَةٌ : مص دَاهَنَ.
§د ه و / د ه ى
دَهَا يَدْهُو/يَدْهَى دَهْواً ودَهْياً داوٍ (الداهي) مُدْهُوٌّ ومَدْهِيٌّ : ــ ته داهِيَةٌ : نزلت به مصيبة، ويقال : «ما دهاك؟» أي : ماذا أصابك ونزل بك؟
دَهِيَ يَدْهَى دَهَاءً دَاوٍ (الداهي) ودَاهِيَةٌ : ــ الشخصُ : بَصُرَ بالأمر وجاد رأيه فيه.
تَدَاهَى يَتَدَاهَى تَدَاهِياً مُتَدَاهٍ (المتداهي) : ــ الشخصُ : تَكَلَّفَ الدَّهَاءَ.
أَدْهَى : أَسْوَأُ، يقال «هذا الشَّيْءُ أدهى وأَمَرُّ» ﴿بَلِ السَّاعَةُ مَوْعِدُهُمْ والسَّاعَةُ أَدْهَى وأَمَرُّ﴾ [قرآن].
تَدَاهٍ (التَّداهي) : مص تَدَاهَى.
دَاهٍ (الدّاهي) ج دُهاةٌ : بَصير بالأمور.
دَاهِيَةٌ ج دَوَاهٍ (الدَّوَاهي) : ١ شخصٌ ــ : جيِّدُ الرأي بصيرٌ بالأمور، تستعمل للمذكر، والمؤنث والتاء للمبالغة «رجلٌ داهية» «امرأةٌ داهية»، ٢ مُصيبَةٌ أَمْرٌ منكر عظيم ◆ داهيةٌ دهماءُ/دهواءُ/دهياءُ : مصيبة شديدة جداً دواهي الدَّهْرِ : ما يصيب الناس مِن نوائب ومصائب فليذهب في داهية : فليذهب إلى جهنم.
دَهَاءٌ : مص دَهِيَ «عُرِف عمرو بن العاص بالدهاء ورجاحة الرأي».
دَهْوٌ : مص دَهَا.
دَهْيٌ : مص دَهَا.
