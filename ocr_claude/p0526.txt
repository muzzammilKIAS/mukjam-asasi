§ر ش ف
رَشَفَ يَرْشُفُ / يَرْشِفُ رَشْفًا : ــ الماءَ ونحوه : مَصَّه بشفتيه.
أرشف : الماءَ : تَرَشَّفَهُ.
تَرَشَّفَ يَتَرَشَّفُ تَرَشُّفًا : ــ الماءَ ونحوه : رَشَفَهُ وبالغ في رشفه.
اِرْتَشَفَ يَرْتَشِفُ ارْتِشَافًا : ــ الماءَ ونحوه : تَرَشَّفَهُ.
اِرْتِشَافٌ : ١ مص ارْتَشَفَ، ٢ عملية امتصاص الأجسام للسوائل.
رَشُوفٌ : طيّب : «شرب رَشُوف».
تَرَشُّفٌ : مص تَرَشَّفَ.
رَشْفٌ : مص رَشَفَ.
§ر ش ق
رَشَقَ يَرْشُقُ رَشْقًا فهو راشق : ــ ه بشيء : رماه به «رَشَقَهُ بِسَهْمٍ»، «رشقه ببصره / بعينه / بنظرةٍ» «رشقه بلسانه»، «إِيّاكَ وَرَشَقَاتِ اللِّسَانِ» [مثل].
رَشُقَ يَرْشُقُ رَشَاقَةً رَشيقٌ : ١ ــ الشخصُ : اعتدلت قامته وحَسُنَ قَدُّهُ، ٢ ــ الماشي في مِشيَته : خَفَّ وأسرع.
رَاشَقَ يُرَاشِقُ مُرَاشَقَةً : ــ ه بالسهام : بادله الرمي بها.
أرشق : ١ ــ الشيءَ : رشقه، ٢ ــ إليه : نظر بحدّة، ٣ ــ الرامي : رمى شوطًا واحدًا.
تَرَاشَقَ يَتَرَاشَقُ تَرَاشُقا : ــ وا بالسهام / بألسنتهم / بأعينهم : تَرَامَوْا ورَشَقَ كُلٌّ منهم صاحبه.
تَرَاشُقٌ : مص تَرَاشَقَ.
رَشَاقَةٌ : مص رَشُقَ.
رَشْقٌ : مص رَشَقَ.
رَشِيقٌ ج رُشَقَاءُ مؤ رَشِيقَةٌ ج رَشيقاتٌ : معتدل القامة حَسَنُ القَدِّ «شاب رشيق»، «فتاة رشيقة».
رَشيق، ابن ــ أحمد أبو العباس (ت ٤٤٢ هـ / ١٠٥٠ م) : أديب ووزير أندلسي، مات معمرا واشتهر برسائله.
رَشيق، ابن ــ القَيْرواني، أبو علي الحسن (حوالي ٣٨٣-٤٥٧ هـ / ٩٩٥-١٠٦٤ م) : أديب وشاعر ومؤرخ وناقد ولد في المحمدية (الجزائر) وعاش في القيروان (تونس) له «العمدة في صناعة الشعر ونقده»، «قراضة الذهب»، «تاريخ القيروان».
مُرَاشَقَةٌ : مص رَاشَقَ.

§ر ش و
رَشَا يَرْشُو رَشْوًا راشٍ (الراشي) مَرْشُوٌّ : ــ ه : أعطاه رشوة.
اِرْتَشَى يَرْتَشِي ارْتِشَاءً مُرْتَشٍ (المرتشي) مُرْتَشًى منه : ــ الشخصُ من فلان : أخذ منه رشوة : «لَعَنَ اللهُ الراشِيَ والمُرْتَشِيَ» [حديث].
اِسْتَرْشَى يَسْتَرْشِي اسْتِرْشَاءً مُسْتَرْشٍ (المُسْتَرْشِي) : ــ ه العامِلُ : طلب رِشْوَةً على إنجاز عمله.
اِرْتِشَاءٌ : مص ارْتَشَى.
اِسْتِرْشَاءٌ : مص اسْتَرْشَى.
رِشَاءٌ ج أَرْشِيَةٌ : حَبْلٌ «أُطِل الرِّشَاءَ حتى يبلغ الدلو الماء».
رَشْوٌ : مص رَشَا.
