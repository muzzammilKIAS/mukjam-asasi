§س ي ر
سارَ يَسيرُ سَيْرًا ومَسيرةً وتَسْيارًا سائرٌ مَسيرٌ : ١ مشى «يَسيرُ النّاسُ عَلى الرَّصيف»، ٢ ــ هُ و ــ به : جعله يسير ◆ سارَ سيرةً حسنةً : سلك سلوكا حسنًا سارَ السُّنَّةَ أو السّيرةَ : سلكها، اتبعها مِيزْ عَنْكَ : احْتَمِلْ تَغافَلْ، ٣ ــ الكلامُ أو المثل : شاع وذاع.
سَيَّرَ يُسَيِّرُ تَسْيِيرًا : ــ ه : جعله يسير ﴿ويَوْمَ نُسَيِّرُ الجِبَالَ﴾ [قرآن].
سايَرَ يُسايِرُ مسايرةً : ــ ه : سار معه، جاراهُ.
أسارَ يُسيرُ إسارةً : ــ هُ : جَعَلَه يسير.
تَسَيَّرَ يَتَسَيَّرُ تَسَيُّرًا : بِسُنَّةٍ أو سيرةٍ : سلكها، اقتدى بها.
تَسايَرَ يَتَسايَرُ تسايُرًا : ــ ا : سارا مَعًا.
إسارةٌ : مص أسارَ.
تَسْيارٌ : مص سارَ.

تَسْييرٌ : مص سَيَّرَ ◆ تسييرُ الأعمال : إدارتها وتوجيهها تسيير ذاتي : بواسطة إدارة داخلية.
سائِرٌ¹ : اسم فاعل من سارَ «عادوا إلى بُيوتِهم سائِرينَ على أقْدامِهم» ◆ المَثَلُ السائِرُ : الجاري والشائع
سائرٌ² : ١ سائر الأشخاص أو الأشياء : الباقي «حَضَرَ الحَفْلَةَ والداهُ وسائِرُ أفرادِ عائِلَتِه»، ٢ الجميع «حضر الحفل سائر أفراد الأسرة»(محدثة).
سَيْرٌ¹ : مص سارَ ◆ حُسْنُ السَّيْر والسلوك : مراعاة التقاليد واحترام القوانين قانون السير : قواعد المرور.
سَيْرٌ² ج سُيور وأسْيار : خَيْط من جلد ونحوه «اربِطْ سَيْرَ حِذائِكَ» ◆ سير متحرك : أداة متحركة لنقل الحقائب في المطارات ونحوها.
سيرَةٌ ج سِيَرٌ : ١ طريقة، سنّة، سُلوك «كان ذا سيرة حَسَنة»، ٢ الحالة التي يكون عليها الشخص أو الشيء ﴿سنُعيدُها سيرتَها الأولى﴾ [قرآن]، ٣ سيرة الشخص : تاريخ حياته «على طالِبِ الوظيفة أنْ يَكتُبَ في الطَّلَبِ سيرتَه» ◆ السِّيرةُ النَّبويَّةُ : تاريخ حياة الرسول وغزواته وغير ذلك.
سَيّارٌ ج ــ ون : كثير السَّيْر.
سَيّارةٌ ج سَيّاراتٌ : ١ قافلة ﴿وجاءَتْ سَيّارةٌ فأرْسَلوا وارِدَهُمْ﴾ [قرآن]، ٢ عربة آليّة تستخدم في نقل الناس أو البضاعة ◆ سيّارة أجرة : سيارة لنقل الناس مُقابل أَجْر سيّارة إسعاف : سيارة خاصة بنَقْل المرضى إلى المستشفى سيارة رُكّاب : سيارة تستعمل لنقل الناس سيارة شَحْن : سيارة تستعمل لنقل البضائع (وتسمى أيضا شاحِنة).
