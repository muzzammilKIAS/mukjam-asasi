§ش م ل
شَمَلَ / شَمِلَ يَشْمُلُ / يَشْمَلُ شُمُولًا وشَمَلا فهو شامل : ١ ــ الأمْرُ القوم : عَمَّهُمْ «شملهم برعايته»، ٢ ــ الأمرَ برعايته : رعاه وتبناه «هذا الحفل مشمول برعاية وزير الشعون الاجتماعية»، ٣ ــ فلانًا : غَطَّاهُ بالشَّمْلَةِ.
أَشْمَلَ يُشْمِلُ إشْمَالًا : ١ ــ ت الريحُ : جاءت من الشَّمال، ٢ ــ القومُ : هبت عليهم ريح الشَّمال، ٣ ــ فلانٌ : صار ذا شَمْلَةٍ، ٤ ــ فلانا : كساه شَمْلَةً.
اِشْتَمَلَ يَشْتَمِلُ اشْتِمَالًا : ١ ــ الرجلُ بثوبه : أداره على جسده كلِّه حتى لا تخرج منه يده، ٢ ــ الفارسُ بسيفه : تقلده، ٣ ــ الأمرُ على كذا : تضمنه واحتواه : ﴿أم ما اشْتَمَلَتْ عَلَيْهِ أَرْحَامُ الأُنْثَيَيْنِ﴾ [قرآن].
اِشْتِمَالٌ : مص اشْتَمَلَ.
إِشْمَالٌ : مص أَشْمَلَ.
شَمَائِلُ : ١ مف شَمِيلَةٌ : الأخلاق «هو كريم الشمائل» : عالي الأخلاق حسن الصفات ٢ مف شِمال ﴿ثُمَّ لَآتِيَنَّهُمْ.. وَعَنْ أَيْمَانِهِمْ وعن شَمَائِلِهِمْ﴾ [قرآن].
شَمَالٌ : ١ الـ ــ : الجهة التي تقابل الجنوب، ٢ ريح الـ ــ : التي تهب من تلك الجهة، وهي ريح باردة.
شِمَالٌ : ١ ج أَشْمُلٌ وشُمُلٌ وشَمَائِلُ : يسار، عكسه يمين ﴿عَنِ اليَمِينِ وَعَنِ الشِّمَالِ عِزِينَ﴾ [قرآن] ◆ طَيْرُ الشِّمال : ما يُتشاءم به ٢ مف شَمْلَةٌ.
شَمْلٌ : ــ القوم : مجتمعهم ◆ جمع الله شملهم : جمع ما تفرق من أمرهم، وعكسه : فَرَّقَ الله شَمْلَهُمْ.
شَمْلٌ : مص شَمَلَ / شَمِلَ.
شَمْلَةٌ ج شِمَالٌ وشَمَلاتٌ : كساء من صوف أو شعر يُتَغَطَّى ويتلفف به «إن أبا هذا كان ينسج الشَّمال بيمينه» [حديث] .
شَمُولٌ الـ ــ : الخمر : «سَقَاهُ الشَّمُولَ».
شَمُولٌ : مص شَمَلَ.
شُمُولِيٌّ : منسوب إلى الشمول، شامل «نظر إلى الموضوع نظرة شمولية» ◆ الحكم الشمولي : الدكتاتوري.
§ش م م
شَمَّ¹ (شَمِمْتُ / شَمَمْتُ) يَشَمُّ / يَشُمُّ شَمًّا وشَمِيما فهو شامٌّ : ــ الشيءَ : أدرك رائحته ◆ شَمَّ الخَبَرَ : أدركه بفطنته.
شَمَّ² (شَمِمْتُ) يَشَمُّ شَمَمًا أَشَمُّ : ١ ــ الجبلُ : ارتفع أعلاه، ٢ ــ الأنفُ : ارتفعت قصبته، ٣ ــ الرجلُ : ترفع وتكبر.
شَمَّمَ يُشَمِّمُ تَشْمِيمًا : ــ ه الطيبَ : جعله يشمه.
أَشَمَّ يُشِمُّ إشْمَامًا : ١ ــ الرجلُ : مَرَّ رافعا رأسه متكبرا، ٢ ــ فلانًا الطيبَ : عَرَضَهُ عليه ليشمه، ٣ ــ [في النحو] المتكلم الصوت : صبغه بمسحة من صوت آخر مثل إشمام الكسرة الضمة في مثل قيل وبيع، ٤ [في القراءة] أشار إلى الحركة من غير تصويت.
تَشَمَّمَ يَتَشَمَّمُ تَشَمُّمًا : ١ ــ الشيءَ : شَمَّه في مهل، ٢ ــ الخبرَ : تطلبه والتمس معرفته.
اِشْتَمَّ يَشْتَمُّ اشْتِمامًا : ــ ه : شَمَّهُ «اشتم في كلامه رائحة الكذب».
اِشْتِمَامٌ : مص اشْتَمَّ.
إِشْمَامٌ : مص أَشَمَّ.
أَشَمُّ مؤ شَمَّاءُ جمعهما شُمٌّ : مرتفع «جبل أشمّ»، «أنف أشم».
تَشَمُّمٌ : مص تَشَمَّمَ.
تَشْمِيمٌ : مص شَمَّمَ.
