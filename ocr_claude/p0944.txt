@مفعول
مَفْعُولٌ ج للعاقل ــ ون ولغير العاقل مَفاعِيلُ ومَفْعُولات : ١ اسم مفعول من فَعَلَ، مثلا : مَصْنوع، مَعْمول ﴿وَكَانَ أَمْرُ اللهِ مَفْعُولاً﴾ [قرآن]، ٢ تأثير «هذا الدّواء لَهُ مَفْعُولٌ قَوِيٌّ»، ٣ [في النحو] : اسم منصوب تعدّى إليه الفِعل والمفاعيل خمسة : المفعول بِهِ وهو ما وقع عليه الحدث، مثلا : فَتَحَ الرَّجُلُ الْبَابَ، والمفعول لأجله وهو علة الحدث، مثلا : وقف إِجْلالاً للمعَلِّم، والمفعول فيه وهو ظرف الحدث، مثلا : الكتاب أمامَكَ، سافَرَ لَيْلاً، والمفعول معهُ وهو مصاحب الحدث، مثلا صعد والجَبَلَ، والمفعول المطلق وهو مؤكد الحدث أو مبين نوعه أو عدده، مثلا : اسْعَ للعلم سَعْيًا، اسْعَ لِلْعِلْمِ سَعْيَ الْعُلَمَاءِ، زار المدينة المنوّرَةَ زيارتين ◆ اسم مفعول [في الصّرف] : اسم مشتق منَ الفِعْل يدلُّ على ما وقع عليه فعلُ الفَاعِلِ، مثلا : مكتوب، مفتوح، موظّف ساري المفعول : قانونيّ، مُلْزِم «عَقْد ساري المَفْعُولِ»، «جواز سفر ساري المفعول».
§ف ع م
فَعَمَ يَفْعَمُ فَعْمًا فهو فاعِم : ــ الاناءَ : ملأه تماما «فَعَمْتُ الابريقَ ماءً».
فَعُمَ يَفْعُمُ فَعَامة وفُعومَة فهو فَعْمٌ : ــ الاناءُ : امتلأ تماما «فَعُمَ الحَوْضُ بالماءِ».
فَعَّمَ يُفَعِّمُ تَفْعِيمًا : ــ الاناءَ ونحوه : فعمه.
أَفْعَمَ يُفْعِمُ إِفْعَامًا : ــ ه : فعمه «مُفْعَم بالنشاط والحيوية».
إِفْعَامٌ : مص أفعم.
تَفْعِيمٌ : مص فَعَّمَ.
فَعَامَةٌ : مص فَعُمَ.
فَعْمٌ : مص فَعَمَ.
فُعُومَةٌ : مص فَعُمَ.
§ف ع و
أُفْعُوَانٌ مؤ أُفْعَى ج أفاعٍ (الأفاعي) : ذَكَرُ الحَيَّاتِ.
أَفْعَى ج أفاعٍ (الأفاعي) : حَيَّة.
§ف غ ر
فَغَرَ يَفْغَرُ فَغْرًا فهو فاغِرٌ : ــ فمَه : فتحَهُ «فَغَرَ فَمَهُ من الدُّهْشَةِ».
أَفْغَرَ يُفْغِرُ إِفْغَارًا : ــ فمه : فَغَرَه.
اِنْفَغَرَ يَنْفَغِرُ انْفِغَارًا : ــ الفمُ : انفتح.
إِفْغَارٌ : مص أَفْغَرَ.
اِنْفِغَارٌ : مص انْفَغَرَ.
فَغْرٌ : مص فَغَرَ.
§ف ق أ
فَقَأَ يَفْقَأُ فَقْءًا فهو فَاقِيءٌ : ١ ــ العَيْنَ : قَلَعَهَا «فَكُنْتَ كَفَاقِيءِ عَيْنَيْهِ عَمْدًا» [مثل]، ٢ ــ البَثْرَةَ ونحوها : شَقَّهَا لاخراج ما فيها.
فَقَّأَ يُفَقِّئُ تَفْقِئَةً : بالَغَ في الفَقْءِ.
تَفَقَّأَ يَتَفَقَّأُ تَفَقُّؤًا : انْفَقَأَ.
اِنْفَقَأَ يَنْفَقِئُ انْفِقَاءً : ١ ــ ت العينُ : انقلعت، ٢ ــ ت البَثْرَةُ ونحوها : انْشَقَّتْ.
اِنْفِقَاءٌ : مص انْفَقَأَ.
تَفْقِئَةٌ : مص فَقَّأَ.
تَفَقُّؤٌ : مص تَفَقَّأَ.
فَقْءٌ : مص فَقَأَ.
§ف ق د
فَقَدَ يَفْقِدُ فَقْدًا وفِقْدَانا فهو فاقِدٌ : ــ الشيءَ : أضاعه، خسِرَه «فقد ماله»، «فقد حظوته»، «فقد إحساسه» ◆ فَقَدَ أعصابَهُ : أظْهَرَ غَضَبَهُ أو انفعاله فَقَدَ حَيَاتَه : توفّي فقد ذاكِرَته : نسي ما يعرفه عن نفسه وغيره فقد شعُورَهُ : غُشِيَ عليه فقد صبْره : لم يستطع أن يصبر فقد صديقَه أو أباه أو نحو ذلك : مات صديقُهُ أو أبوه الخ فَقَدَ صَوَابه أو عقلَه : جُنَّ فَقَد نور عينيه : أصيبَ بالعَمَى.
