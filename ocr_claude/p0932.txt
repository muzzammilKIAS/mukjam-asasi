§ف ر ه
فَرِهَ يَفْرَهُ فَرَهًا فهو فَرِهٌ وفَارِهٌ : نَشِيطٌ، مَرِحَ «ركب دابة فارهة».
فَرُهَ يَفْرُهُ فَرَاهَة وفُروهَة فهو فَارِهٌ : ١ جَمُلَ، حَسُنَ «اكْتَمَلَتْ أُنوثةُ الفَتاةِ وَفَرُهَت»، ٢ نَشِطَ.
فَارِهٌ ج فُرْهٌ وفُرَّهٌ : ١ جميل، حَسَن الوَجْه «غلامٌ فارِهٌ»، «فَتاةٌ فارِهَةٌ»، ٢ نشيط، خفيف «فَتًى فارِهٌ»، ٢ حاذق ماهر ﴿وَتَنْحِتُونَ مِنَ الْجِبَالِ بُيُوتًا فَارِهِينَ﴾ [قرآن].
فَرَاهَةٌ : مص فَرُهَ.
فَرَهٌ : مص فَرِهَ.
فُرُوهَةٌ : مص فَرُهَ.
فَرْهَدَ يُفَرْهِدُ فَرْهَدَةً : ــ الفتى : حسُن وجَمُل.
تَفَرْهَدَ يَتَفَرْهَدُ تَفَرْهُدًا : ــ الغلام سَمِنَ وجَمُل.
الفَرْهُود ج فَرَاهِيد : الجميل.
§ف ر و
فَرَأً/فَرَا ج فِراء وأَفْراء : حِمار الوحش ◆ كل الصَّيْد في جَوْف الفَرا : يقصد بها أن شخصا واحدا قد يفضُل جماعة ويُغني عنهم.
فَرَّاءٌ ج ــ ون : صانِع الفِراء، بائع الفِراء.
الفَرَّاءُ : (انظر : ألفبائيا).
فَرْوٌ ج فِراءٌ : جُلود بعض الحيوان تُدْبَغُ ويُتَّخَذُ منها ملابس، القطعة منها «فَرْوَةٌ».
فَرْوَةٌ ج فِرَاءٌ : جلدة ذات شَعْر «فروة الرأس»، «فروة الثَّعْلَبِ»، «فروة الذُّبِّ»، «فروة الأرنب» ◆ أبو فروة : أ البُنْدُق (المغرب العربي) ب الخوخ، الدُّرَّاق (لبنان) ج الكَسْتناء، القَسْطل (مصر).
§ف ر ى
فَرَى يَفْرِي فَرْيًا فهو فَارٍ (الفاري) مَفْرِيٌّ : ــ ه الشيءَ : شَقَّهُ «فَرَى بَطْنَ الشَّاةِ»، ٢ ــ ه : قطعه قطعا صغيرة «لأَفْرِيَنَّهُمْ فَرْيَ الأَدِيمِ» [من حديث حسان]، ٣ ــ القولَ : اختلقه، كذب.
اِفْتَرَى يَفْتَرِي افْتِرَاءً مُفْتَرٍ (المُفْتَرِي) مُفْتَرًى . ــ القولَ : اختلقه، كَذَبَ فيه ﴿وَمَنْ أَظْلَمُ مِمَّنِ افْتَرَى عَلَى اللهِ كَذِبًا﴾ [قرآن]
اِفْتِرَاءٌ : مص افْتَرَى.
فَرْيٌ : مص فَرَى.
فِرْيَةٌ ج فِرًى : كَذِبٌ «هذه فِرْيَةٌ اخْتَلَقَها خَصْمِي».
فَرِيٌّ ج أَفْرِيَاءُ : ١ شخصٌ مُخْتَلِق، كاذِب «اقْتَنَع القاضي بأنَّهُ فَرِيٌّ فَرَفَضَ دَعْوَاهُ»، ٢ أمْرٌ مُخْتَلَق «أتى بشيء فَرِيٍّ»، ٣ أمْرٌ عَجِيب ﴿قَالُوا يَامَرْيَمُ لَقَدْ جِئْتِ شَيْئًا فَرِيًّا﴾ [قرآن] ◆ فلان يفرى الفَرِيّ : يأتي بالعجب في عمله «فلم أَرَ عبقريا يفري فريَّه» [حديث].
§ف ز ر
فَزَرَ يَفْزِرُ فَزْرًا فهو فَازِرٌ : ــ ه : شَقَّه، صَدَعه «فَزَرَ الثَّوْبَ».
فَزَّرَ يُفَزِّرُ تَفْزِيرًا : ــ ه : فَزَرَهُ.
اِنْفَزَرَ يَنْفَزِرُ انْفِزَارًا : انْشَقَّ «انْفَزَرَ الثَّوْبُ»، «انْفَزَرَ إطار السَّيَّارَة».
تَفَزَّرَ يَتَفَزَّرُ تَفَزُّرًا : تَشَقَّقَ «تَفَزَّرَ الثَّوْبُ».
اِنْفِزَارٌ : مص انْفَزَرَ.
تَفَزُّرٌ : مص تَفَزَّرَ.
تَفْزِيرٌ : مص فَزَّرَ.
فَازُورَةٌ ج فَوازِيرُ : اللغز والأحجية «فوازير رمضان» (محدثة).
فَزْرٌ : مص فَزَرَ.
§ف ز ز
فَزَّ (فَزَزْتُ) يَفِزُّ فَزًّا فَازٌّ : ١ فَزِعَ «فَزَّ النَّاسُ عِنْدما سمعوا صَوْتَ الانْفِجَارِ»، ٢ ــ هُ : أَفْزَعَهُ، أزْعجهُ «سمع صوتا فَزَّهُ».
أَفَزَّ يُفِزُّ إِفْزَازًا : أَفْزَعَ، أزْعَجَ «حَلِمْتُ حُلْمًا أَفَزَّنِي فصَحَوْتُ من نَوْمِي».
