اِسْتاءَ يَسْتاءُ اسْتِياءً : تَأَلَّمَ أو تَضايَقَ من قَوْل أو فِعْل «اسْتاءَ مِنْ تَصَرُّفِك».
إِساءةٌ : مص أساءَ.
اِسْتِياءٌ : مص اسْتاء.
تَسْوِيء : مص سَوَّأَ.
سَوْءٌ : ١ مص ساء، ٢ قُبْح «رَجُلُ سَوْءٍ»، «عَمَل سَوْء» (أي قبيح)، ﴿وظَنَنْتُمْ ظَنَّ السَّوْءِ﴾ [قرآن].
سُوءٌ : كُلُّ ما يَسوء ﴿لَهُمْ سُوءُ العَذابِ﴾ [قرآن]، ◆ سوء الإدارة أو الاستعمال أو المعاملة إلخ : إدارة سيِّئة أو استعمال سيّء أو معاملة سيِّئة إلخ (وكذلك سوء الأحوال أو الحال أو الحالة وسوء النية إلخ) سوء الحظ : عدم التوفيق لأسباب أقوى من الإرادة سوء السلوك : التعامل الخاطئُ مع الآخرين سوء الظَّنّ : الشَّكّ، سوء الفَهم : الفهم الخاطئُ مَسَّه سوء : أصابه أذى.
سَوْءَة ج سَوْءات (أو سَوْآت) : عَوْرة ﴿قد أَنْزَلْنا عَلَيْكُمْ لِباسًا يُوارِي سَوْآتِكُمْ﴾ [قرآن].
سَواءٌ : (انظر : سوى).
سَيِّءٌ : قبيح، شائن، رَديء، عكسه حَسَنٌ ﴿خَلَطوا عَمَلًا صالِحًا وآخَرَ سَيِّئًا﴾ [قرآن]، أَصْبَحَتِ العَلاقاتُ سَيِّئةً بين البَلَدَيْنِ» ◆ سَيِّءُ الحظ : غير محظوظ سَيِّءُ الخُلُقِ أو السُّمْعة أو الطِّبع إلخ : صاحِب خُلُق رَديء إلخ سَيّء الطالع : غير مَحْظوظ من سَيّء إلى أَسْوَأ : يَزْداد سوءًا.
سَيِّئَةٌ ج سَيِّئاتٌ : ١ ذَنْب، خَطيئة، عكسه حَسَنة ﴿مَنْ عَمِلَ سَيِّئَةً فَلا يُجْزى إلّا مِثْلَها﴾ [قرآن]، ٢ عَيْب، نَقْص ﴿وَ إنْ تُصِبْكُم سَيِّئةٌ يَفْرَحوا بها﴾ [قرآن].
مَساوِئٌ / مَساوِي (عادة في صيغة الجمع) : معايب، نقائص «مساوئٌ / مساوي هذا المشروع أَكْثَرُ مِنْ مَحاسِنِه».
§س و ج
سَوَّجَ يُسَوِّجُ تَسْوِيجًا : ــ المكانَ : أقام سِياجًا حَوْله (انظر ايضا : سَيَّجَ)
تَسْويجٌ : مص سَوَّجَ.
ساجٌ (واحدته ساجة) : شَجَر يَعْظُمُ حَجْمُه له وَرَق كبير يُنْتِج خَشَبًا صُلبا من أَجْوَد الأنواع
سِياجٌ ج ــ ات : سورٌ من أسلاك أو حِجارة أو غيرها يُحيط بِمَنْزِل أو حديقة أو نحوهما.
§س و ح
ساحةٌ ج ساحات وساحٌ : فضاء أمام البناء أو بين الأبنية «جَلَسْنا في ساحة الدّار» ◆ بَرِيء الساحة : غير مُذنب (ويُقال بَرَّأَتِ المحكمةُ ساحَتَه) ساحة الحرب أو القتال أو المعركة : ميدان الحرب إلخ ساحة القضاء : هيئة المحكمة نزل بساحته : نزل به.
§س و خ
ساخَ يَسوخُ سَوْخًا سائخ : ــ ت رجله في الأرض : غاصت.
سَوْخٌ : مص ساخَ.
§س و د
سادَ يَسودُ سِيادةً وسُؤْدُدًا فهو سائدٌ مَسودٌ : أصبح سَيِّدًا، عظم وشرف، مَلَكَ، سيطر «الرأي السائد»، «سادَ قَوْمَه» ◆ ساد الصَّمْتُ المكانَ : أَصْبَحَ لا يُسْمَعُ فيه صوت ساد الهُدوء المكانَ : أصبح هادِئًا.
سَوِدَ يَسْوَدُ سَوَدًا أَسْوَدُ : صار كلون الفحم، عكسه أبيض «دَخَلَ إلى مَنْجَمِ الفَحْمِ فَسَوِدَ وَجْهُهُ ويَداه».
سَوَّدَ¹ يُسَوِّدُ تَسْويدًا : ١ ــ الشيءَ : جعله أسود «سَوَّدَ الفَحْمُ وَجْهَه»، ٢ ــ الرسالة أو الكتابَ : كتبهما للمرة الأُولى أو قَبْلَ وضعهما في صورَتِهما النهائية.
سَوَّدَ² يُسَوِّدُ تَسْويدًا : ــ وا شخصًا عليهم : جعلوه سَيِّدا «نَفْسُ عِصام سَوَّدَتْ عِصاما».
اسْوَدَّ يَسْوَدُّ اسْوِدادًا : صارَ أَسْوَد ﴿يَوْمَ تَبْيَضُّ وُجوهٌ
