@منجلة
تَنَجُّزٌ : مص تَنَجَّزَ.
تَنْجِيزٌ : مص نَجَّزَ.
مُنَاجَزَةٌ : مص نَاجَزَ.
نَاجِزٌ : حاضر نافذ «باعه ناجزا بناجز».
نَجْزٌ : مص نَجَزَ.
§ن ج س
نَجُسَ يَنْجُسُ نَجَاسَةً فهو نَجِسٌ :ـ الشيءُ / الشَّخصُ : أصبح قذرا «نجس الثوب».
نَجِسَ يَنْجَسُ نَجَسًا نَجِسٌ : ١ ــ الشيءُ / الشَّخصُ : نَجُسَ، ٢ [في الشّرع] العُضْوُ أو البَدَنُ : أصبَحَ غيرَ طاهِرٍ ◆ نَجِسَ فُلانٌ : خَبُثَ طَبْعُه ودَنِسَ خُلُقُه.
نَجَّسَ يُنَجِّسُ تَنْجِيسًا : ــ الشيءَ : جعله نجسًا.
تَنَجَّسَ يَتَنَجَّسُ تَنَجُّسًا : وقع في النجاسة.
نَجَاسَةٌ : ١ مص نَجُسَ، ٢ ج نَجَاسَاتٌ : قذارة، ٣ [شرعا] قدر ما يمنع الصلاة من بول أو دم أو خمر أو نحوها.
نَجَسٌ : ١ مص نَجِسَ، ٢ ج أَنْجَاسٌ : خبيثٌ فاجر وقد يستعمل للمفرد والجمع ﴿إِنَّمَا الْمُشْرِكُونَ نَجَسٌ﴾ [قرآن].
نَجِسٌ : ١ قَذِرٌ، ٢ غير طاهر.
§ن ج ع
نَجَعَ يَنْجَعُ نَجْعًا ونُجُوعًا فهو ناجع : ١ ــ الدَّواءُ : نَفَعَ وظَهَرَ أثَرُهُ، ٢ ــ المكانَ : أتاه ونزل به «نَجَعَ البَدْوُ الرُّحَّلُ في مَوَاضِعِ الكَلَأِ».
اِنْتَجَعَ يَنْتَجِعُ انْتِجَاعًا : ١ ــ القومُ : ذهبوا لطلب العُشْب، ٢ ــ الشَّخصَ : قَصَدَهُ يَطلُبُ مُسَاعَدَتَهُ، ٣ ــ العُشْبَ : طلَبَهُ في مَوْضِعِهِ.
اِنْتِجَاعٌ : مص انْتَجَعَ.
نَاجِعٌ : مُفِيدٌ نَافِعٌ «دَوَاءٌ ناجِعٌ»، «مَوَاقِفُ ناجِعَةٌ».
نَجَاعَةٌ : مَا بِهِ نَفْعٌ وإِفَادَةٌ «نَجاعةُ الدَّواءِ»، «نَجَاعَةُ الهواءِ النَّقِيِّ في الجَبَلِ».
نَجْعٌ : ١ مص نَجَعَ، ٢ ج نُجُوعٌ : مَكَانٌ يَحُطُّ فيه القَوْمُ رَحْلَهُمْ لِوُجُودِ الماءِ والعُشْبِ، ويُقَالُ أيضا : مُنْتَجَعٌ.
نُجْعَةٌ : ١ طَلَبُ العُشْبِ وأماكِنِ نُزُولِ المطَرِ «هذه ليست بدار نُجعَة»، ٢ قصد ذوي المعروف لمروفهم «فلان نجعتي».
نُجُوعٌ : ١ مص نَجَعَ، ٢ مف نَجْعٌ.
§ن ج ف
نَجَفَ يَنْجُفُ نَجْفًا فهو ناجف : ــ الشَّيْءَ وَسَّعَ فيه وحفر جَوْفَه «نَجَفَ البِئْرَ».
نَجَّفَ ينجف تنجيفا : نَجَفَ بشدة.
نَجْفٌ : مص نَجَفَ.
نَجَفٌ : ١ ج نِجَافٌ : تلٌّ، ٢ مف نَجَفَةٌ.
نَجَفَةٌ : ١ ج نَجَفٌ ونِجَافٌ : مكانٌ مُسْتطيل كالجدار في وسَط الوادي لا يَعْلُوه الماءُ، ٢ ج نَجَفٌ ونَجَفَاتٌ مجموعة من المصابيح الكَهْرَبِيَّة مُخْتَلِفة الشكل مُنَسَّقَة الوضع باهِرَة الضَّوْءِ ويقال لها : الثُّرَيَّا.
§ن ج ل
نَجَلَ يَنْجُلُ نَجْلًا فهو ناجل : ــ المولودَ : وَلَدَهُ.
نَجِلَ يَنْجَلُ نَجَلًا فهو أَنْجَلُ : ــ تِ العَيْنُ : اتَّسَعَتْ وحَسُنَتْ.
أَنْجَلُ ج نُجْلٌ ونِجَالٌ مؤ نَجْلَاءُ ج نُجْلٌ ونَجْلَاوَاتٌ : وَاسِعُ العَيْنَيْنِ «غَادَةٌ نَجْلَاءُ» ◆ طَعْنَةٌ نَجْلَاءُ : قاتِلَةٌ.
إِنْجِيلٌ : (انظر ألفبائيا).
مِنْجَلٌ ج مَنَاجِلُ : ١ آلةٌ لحصْدِ الزَّرعِ أو لِحَشِّ العُشْبِ، ٢ أبو ــ : طائرٌ قَدَّسَهُ قُدَمَاءُ المِصْرِيِّينَ، وهو لَدَيْهِم رسولُ العِلْمِ والمعرفَةِ.
مِنْجَلَةٌ ج مَنَاجِلُ : أداةٌ مِن فَكَّيْنِ أحدُهما ثابتٌ والآخَرُ مُتَحَرِّكٌ تُستعملُ للقَبْضِ على الأشياءِ المُرادِ قَطْعُها أو تَشْكِيلُها منها ما يُثَبَّتُ بالمنضدة ومنها ما يُثَبَّتُ في
