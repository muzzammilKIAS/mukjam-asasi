@معا
↩ مَعِينٍ﴾ [قرآن]، ٣ خَمْرٌ جارية في نهر ﴿يُطَافُ عَلَيْهِمْ بِكَأْسٍ مِنْ مَعِينٍ﴾ [قرآن].
§م ع و / م ع ي
مَعَا يَمْعُو مُعَاءً مَاعٍ (الماعي) : القِطُّ : صَوَّتَ.
مَعَى يَمْعِي مَعْيًا ماعٍ (الماعي) مَمْعِيٌّ : ــ هُ : أصَابَ مِعَاهُ ◆ مُعِيَ الشَّخصُ : شكا أَمْعَاءَهُ.
مُعَاءٌ : مص مَعَا.
مِعَاءٌ ج أَمْعِيَةٌ : واحد المصران.
مِعَوِيٌّ : منسوب إلى المِعَى «الأمراضُ المِعَوِيَّةُ»، «الحُمَّى المِعَوِيَّةُ» «ديدان معوية».
مَعْيٌ : مص مَعَى.
مِعًى (يذكّر ويؤنّث) ج أَمْعَاءٌ : مِعَاءٌ «الْمِعَى الدَّقِيقُ»، «الْمِعَى الغَلِيظُ»، «المؤمن يأكل في مِعًى واحد» [حديث].
مَعِين : دولة قديمة في اليمن امتدت من أوائل الألف الثاني ق.م حتى القرن السابع ق.م، أعقبتها الدولة السبئية.
§م غ ر
مَغَرَ يَمْغَرُ مَغْرًا : ــ الشَّيْءَ : صَبَغَهُ بِالْمَغْرَةِ «مَغَرَ الثَّوْبَ».
مَغْرٌ : مص مَغَرَ.
مَغْرَةٌ : ١ طِينٌ أحمرُ يُصْبَغُ به، ٢ مَطْرَةٌ خفيفة، ٣ مَغْرَةُ الصَّيْفِ : شِدَّةُ حَرِّهِ.
مُغْرَة : مسحوق اكسيد الحديد يستعمل في أعمال الطلاء.
المَغْرِبُ (المملكة المغربية) : دولة عربية في شمال غربي إفريقيا تمتد سواحلها على البحر الأبيض المتوسط شمالا والمحيط الأطلسي غربا عاصمتها الرباط، وأشهر مدنها الدار البيضاء وفاس وطنجة ومراكش.
المَغْرِبُ العربي : اسم يطلق على المنطقة الجغرافية التي تضم ليبيا وتونس والجزائر والمملكة المغربية وموريتانيا.
§م غ ص
مَغِصَ يَمْغَصُ مَغَصًا فهو مَغِصٌ : ــ الشَّخصُ : أصابه مَغَصٌ.
مُغِصَ يُمْغَصُ : ــ الشَّخْصُ : أصابه مغص.
تَمَغَّصَ يَتَمَغَّصُ تَمَغُّصًا : ١ ــ بَطْنُه : أَصَابَهُ المَغْصُ، ٢ ــ هُ الشَّيْءُ : آذَاهُ «تَمَغَّصَ مِنْ ضَجِيجِ السَّيَّارَاتِ».
تَمَغُّصٌ : مص تَمَغَّصَ.
مَغْصٌ/مَغَصٌ ج أَمْغَاصٌ : وَجَعٌ وتقطيعٌ في الكُلَى أو الأَمْعَاءِ وٱلْتِواءٌ فيها «مغص كُلْوِيّ».
مَغْصٌ : ١ مص مَغِصَ، ٢ مَغَصٌ.
مَغِصٌ : من أصابه مَغَصٌ.
§م غ ط
مَغَطَ يَمْغَطُ مَغْطًا فهو ماغط : ــ الشَّيْءَ : مَدَّهُ لِيَطُولَ «مَغَطَ الجَزَّارُ المُصْرَانَ».
تَمَغَّطَ يَتَمَغَّطُ تَمَغُّطًا : ١ ــ الشَّيْءُ : امتدَّ وطالَ «تَمَغَّطَ المَطَّاطُ»، ٢ ــ الفَرَسُ : مَدَّ قَوَائِمَهُ وتَمَطَّى في جَرْيِهِ.
اِمْتَغَطَ يَمْتَغِطُ امْتِغَاطًا : ١ ــ الشَّيْءُ : امتدَّ وطَالَ «امْتَغَطَ النَّهارُ في فَصْلِ الصَّيْفِ»، ٢ ــ السَّيْفَ : اسْتَلَّهُ.
اِمْتِغَاطٌ : مص امتغط.
تَمَغُّطٌ : مص تَمَغَّطَ.
مَغْطٌ : مص مَغَطَ.
§م غ ط س
مَغْطَسَ يُمَغْطِسُ مَغْطَسَةً : ــ الحَجَرَ ونحوَه : زَوَّدَه بالقُوَّةِ المِغْنَاطِيسِيَّةِ «إبرةٌ مُمَغْطَسَةٌ تتَّجهُ إلى الشَّمالِ».
مَغْطَسَةٌ : مص مَغْطَسَ.
§م غ ن ط
مَغْنَطَ يُمَغْنِطُ مَغْنَطَةً : مَغْطَسَ «إبرة ممغنطة».
مَغْنَطَةٌ : مص مَغْنَطَ.
مِغْنَاطِيسٌ / مِغْنِطِيسٌ : مَعْدِنٌ فيه قُوَّةٌ تَجْذِبُ الحَدِيدَ
