@للطيف
↩ خَفِيٌّ قُرْبَ نجم آخر أشدّ لَمَعَانًا مِنْهُ.
مُلاَصِقٌ : مُجَاوِرٌ «بَيْتُ فُلاَنٍ مُلاَصِقٌ لِبَيْتِي».
§ل ط خ
لَطَخَ يَلْطَخُ لَطْخًا فهو لاَطِخٌ : ــ هُ : بكذا : لَوَّثَهُ وَوَسَّخَهُ به «لَطَخَ التِّلميذُ الوَرَقَةَ بالحِبْرِ»، «لَطَخَتْ ثِيَابَهَا بالوَحَلِ».
لَطَّخَ يُلَطِّخُ تَلْطِيخًا : ــ الشَّيْءَ : لَوَّثَهُ وَوَسَّخَهُ «لَطَّخَ يَدَيْهِ بالدُّهْنِ»، «لَطَّخَ سُمْعَتَهُ»، «لَطَّخَ قَدَمَيْهِ بالوَحَلِ» ◆ لطخ يديه بالدم : ارتكب جريمة قتل.
لَطِخٌ : المُلَطَّخُ، القذر.
تَلَطَّخَ يَتَلَطَّخُ تَلَطُّخًا : ١ ــ الشَّيْءُ بكذا : تَلَوَّثَ «تَلَطَّخَ الكِتَابُ بالحِبْرِ»، ٢ ــ الشَّخصُ بأمر قبيح : تَدَنَّسَ بِهِ «مُتَلَطِّخٌ بالشَّرِّ».
تَلَطُّخٌ : مص تَلَطَّخَ.
تَلْطِيخٌ : مص لَطَّخَ.
لَطْخٌ : ١ مص لَطَخَ، ٢ ج لُطُوخٌ : أحمق بليد (محدثة).
مُلَطَّخٌ ج ــون مؤ مُلَطَّخَةٌ ج مُلَطَّخَاتٌ : مُلَوَّثٌ مُدَنَّسٌ «مُلَطَّخٌ بالخُبْثِ»، «مُلَطَّخَةٌ بالعَارِ».
§ل ط ع
لَطَعَ يَلْطَعُ لَطْعًا فهو لاَطِعٌ : ١ ــ الشَّيْءَ : لَحِسَهُ «لَطَعَ الكَلْبُ الإِنَاءَ»، ٢ ــ الشَّخصَ : ضَرَبَ مُؤَخَّرَهُ بِرِجْلِهِ، ٣ ــ العَيْنَ : لَطَمَهَا.
لَطِعَ يَلْطَعُ لَطَعًا أَلْطَعُ : ١ ــ تِ الأَسْنَانُ : ذَهَبَتْ وبَقِيَتْ أُصُولُهَا «لَطِعَتْ أَسْنَانُ العَجُوزِ»، ٢ ــ الشَّيْءُ : هُزِلَ، ٣ ــ الشَّيْءَ : لحسه، ٤ ــ فُلانًا : ضَرَبَ مُؤَخَّرَهُ بِرِجْلِهِ.
الْتَطَعَ يَلْتَطِعُ الْتِطَاعًا : لَحَسَ
أَلْطَعُ ج لُطْعٌ مؤ لَطْعَاءُ ج لُطْعٌ ولَطْعَاوَاتٌ : مَنْ ذَهَبَتْ أَسْنَانُهُ وَبَقِيتْ أُصُولُهَا.
لَطْعٌ : مص لَطَعَ.
لَطَعٌ : مص لَطِعَ.
لُطَعٌ : اللئيم.
لُطْعَةٌ ج لُطَعٌ : بَيْضُ دودَةِ القُطْنِ تَضَعُهُ على بَاطِنِ الوَرَقَةِ.
§ل ط ف
لَطَفَ يَلْطُفُ لَطْفًا وَلُطْفًا لَطِيفٌ : ــ بِهِ : رفق به وَرَأَفَ «لَطَفَ اللهُ بِهِ».
لَطُفَ يَلْطُفُ لُطْفًا ولَطَافَةً لَطِيفٌ : ١ ــ الشَّيْءُ : رَقَّ عكسه كَثُفَ «لَطُفَ كَلامُهَا»، «لَطُفَ الهَوَاءُ بعْدَ العَصْرِ»، ٢ ــ الشَّيْءُ : رَقَّ، عكسه خَشُنَ «لَطُفَتْ أَخْلاَقُهُنَّ»، ٣ ــ الشَّيْءُ : دَقَّ وصَغُرَ «عُودٌ لَطِيفٌ».
لَطَّفَ يُلَطِّفُ تَلْطِيفًا : ١ ــ العِبَارَةَ أو الكَلاَمَ : جَعَلَهُ لَطِيفًا «لَطَّفَ عِبَارَاتِ رِسَالَتِهِ»، ٢ ــ مِنَ الشَّيْءِ : خَفَّفَ مِنْهُ «لَطَّفَتْ مِن غَضَبِهَا»، «لَطَّفَ الدَّواءُ مِنَ الآلَمِ».
لاَطَفَ يُلاَطِفُ مُلاَطَفَةً : ١ ــ هُ : رَفَقَ بِهِ «لاَطَفَ الفَقِيرَ»، ٢ ــ هُ : أَلاَنَ لَهُ القَوْلَ «لاَطَفَ الخَصْمَ»، «تُلاَطِفُ الأُمُّ صَبِيَّهَا».
أَلْطَفَ يُلْطِفُ إِلْطَافًا : ١ ــ الشَّخصَ بكذا : أَكْرَمَهُ وَبَرَّهُ «كَمْ أَتْحَفَ وأَلْطَفَ»، ٢ ــ له في القَوْلِ : قَالَ له قَوْلا لَطِيفًا «أَلْطَفَ لِلْيَتِيمِ».
تَلَطَّفَ يَتَلَطَّفُ تَلَطُّفًا : ١ ــ الشَّخصُ في الأَمْرِ : تَرَفَّقَ فيه وَعَالَجَهُ بأَدَب، ٢ ــ الشَّخصُ بِهِ : احتالَ لَهُ وَبَالَغَ في مُجَامَلَتِهِ حَتَّى اطَّلَعَ على أَسْرَارِهِ.
تَلاَطَفَ يَتَلاَطَفُ تَلاَطُفًا : ١ ــ القومُ : أَلْطَفَ بَعْضُهُمْ بَعْضًا «تَلاَطَفُوا أَيَّامَ الشِّدَّةِ»، ٢ ــ القومُ في الأمرِ : تَرَفَّقُوا فِيهِ.
اسْتَلْطَفَ يَسْتَلْطِفُ اسْتِلْطَافًا : ــ هُ : وَجَدَهُ لَطِيفًا «اسْتَلْطَفَ الفَتَاةَ»، «اسْتَلْطَفَ طَرِيقَتَهُ في عَرْضِ المَسْأَلَةِ».
اسْتِلْطَافٌ : مص اسْتَلْطَفَ.
إِلْطَافٌ : مص أَلْطَفَ.
تَلاَطُفٌ : مص تَلاَطَفَ.
تَلَطُّفٌ : مص تَلَطَّفَ.
تَلْطِيفٌ : مص لَطَّفَ.
