@موعود
↩ «أدّى وظيفته على الوَجْهِ الأكْمَلِ» (مو)، «أَوْصَدَ بَابَ الوظائِفِ في وجْهِهِ» ◆ عِلْمُ وظائفِ الأعْضَاءِ : قِسْم من أقْسام الطبّ.
وَظِيفِيٌّ : ١ منسوب إلى الوظيفة، ما يتعلّق بالوظيفة «تحليل وَظِيفِيٌّ»، «تعليم وَظِيفيّ»، «علم النّفس الوظيفي»، «علم التربية الوظيفي»، «الرصيد اللّغوي الوظيفي»، ٢ عَمَلِيٌّ «إجراءاتٌ وَظِيفِيّةٌ»، «النحو الوظيفي».
§و ع ب
وَعَبَ يَعِبُ وَعْبًا فهو وَاعِبٌ : ــ الشّيْءَ : أخَذَهُ بِأَجْمَعِهِ.
أَوْعَبَ يُوعِبُ إيعَابًا : ١ ــ القومُ : خَرَجُوا ولَمْ يَبْقَ منهم أحَد، ٢ ــ الشيءَ : أخَذَهُ بِأَجْمعه، ٣ ــ الأَمْرَ : فَرَغَ مِنْهُ.
اِسْتَوْعَبَ يَسْتَوْعِبُ اسْتِيعَابًا : ١ ــ المَكانُ أو غيرُه الشّيْءَ : وَسِعَهُ «استوعبت القاعةُ كُلَّ النّاس»، «استوعبت المدارس كل التلاميذ»، ٢ ــ الشّيْءَ : أخَذه بأجمعه، ٣ ــ هُ : اسْتَأْصَلَهُ، ٤ ــ الحديثَ : تَلَقّاهُ واسْتَوْفَاهُ «استوعَبَ كُلَّ مَسائِلِ الدّرْسِ».
اِسْتِيعَابٌ : ١ مص اسْتَوْعَبَ، ٢ طاقةٌ وقُدْرةٌ «له اسْتِيعابٌ على فهمِ أصْعَبِ المَشَاكِلِ الرّيَاضيّةِ».
إيعَابٌ : مص أَوْعَبَ.
وَعْبٌ : مص وَعَبَ.
§و ع ث
وَعِثَ يَوْعَثُ وَعْثًا ووَعَثًا وَعِثٌ : ١ ــ الطّريقُ : صَعُبَ سُلُوكُهُ، ٢ ــ الأمْرُ : اخْتَلَطَ وفَسَدَ، ٣ ــ ت اليَدُ : انْكَسَرَتْ.
وَعْثٌ : ١ مص وَعِثَ، ٢ ج وُعُوثٌ :طريقٌ صَعْب، ٣ كلّ أمر شاقّ، ٤ عظمٌ مكسور ◆ رَجُلٌ وَعْثُ اللّسَانِ : عاجز عن الكلام.
وَعَثٌ : مص وَعِثَ.
وَعِثٌ : طريق عَسِيرٌ.
وَعْثَاءُ : ١ مَشَقّةٌ وتَعَب «أعُوذُ باللهِ مِن وعْثاءِ السّفَرِ»، ٢ كلّ خَصْلَةٍ مكرُوهَة ◆ رَكِبَ الْوَعْثَاءَ : أذْنَبَ.
§و ع د
وَعَدَ¹ يَعِدُ وَعْدًا وعِدَةً ومَوْعِدًا ومَوْعِدَةً فهو وَاعِدٌ : ــ الشّخصَ الأمرَ وبِهِ : قَالَ له إنّه يُجْريهِ لَهُ أو يُنِيلُهُ إيّاهُ «وَعَدَهُ بِجائِزَة»، «وَعَدَتْ بِشَرَفِهَا أنّهَا ستُنْجِزُ ما الْتَزمَتْ به».
وَعَدَ² يَعِدُ وَعِيدًا فهو وَاعِدٌ : ــ الشّخصَ : وَعَدَهُ شَرًّا وتَهَدَّدَهُ.
وَاعَدَ يُوَاعِدُ مُوَاعَدَةً : ١ ــ هُ : وَعَدَ كُلٌّ منهما الآخَرَ، ٢ ــ هُ المَوْضِعَ أو الوقتَ : عَاهَدَهُ على أنْ يُوَافِيهِ في موضِعٍ أوْ وَقْتٍ مُعَيّن.
أَوْعَدَ يُوعِدُ إيعَادًا : ١ ــ الشّخصَ : تَهَدَّدَهُ «أوْعَدَهُ شَرًّا»، ٢ ــ الشّخصَ : وَعَدَهُ «أوْعَدَهُ خَيْرا».
تَوَعَّدَ يَتَوَعَّدُ تَوَعُّدًا : ــ الشّخصَ : تَهَدَّدَهُ.
تَوَاعَدَ يَتَوَاعَدُ تَوَاعُدًا : القومُ : وَعَدَ بعضُهم بعضا «تَوَاعَدُوا على اللّقاءِ في النّادي الثّقَافِيّ».
اِتَّعَدَ يَتَّعِدُ اتِّعَادًا : ١ ــ القومُ : وَعَدَ بعضُهم بعضا، ٢ ــ الشّخصُ : قَبِلَ الوَعْدَ ووَثِقَ به، ٣ ــ هُ : أوْعَدَهُ.
اِتِّعَادٌ : مص اتَّعَدَ.
إيعَادٌ : مص أوْعَدَ.
تَوَاعُدٌ : مص تَوَاعَدَ.
تَوَعُّدٌ : مص تَوَعَّدَ.
عِدَةٌ : مص وَعَدَ¹.
مُوَاعَدَةٌ : مص واعَدَ.
مَوْعِدٌ : ١ مص وَعَدَ¹، ٢ ج مَوَاعِدُ : مَكان الوَعْدِ أو زَمَانُهُ «كَان على المَوْعِدِ»، «حضر قبل الموعد»، ٣ عَهْدٌ «وَفَى بِمَوْعِدِهِ».
مَوْعِدَةٌ : مص وَعَدَ¹.
مَوْعُودٌ : اسم مفعولٌ من وعَدَ «جَائزة موعودَةٌ» ◆ الْيَوْمُ المَوْعُودُ : يومُ القِيَامَة.
