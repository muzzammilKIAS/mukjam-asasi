@مربع
↩ متساوية وزواياه قوائم، ٢ كل ماله أربعة أركان «بناء مربع» ◆ متر مربع : طول كل ضلع من أضلاعه الأربعة متر.
مَرْبَعٌ ج مَرَابِعُ : موضع يقام فيه زمن الربيع.
مَرْبُوعٌ ج مَرَابِيعُ : وسيط القامة (رَبْعَة) «رجل مربوع».
يَرْبُوعٌ ج يَرَابِيعُ : حيوان ثدي من رتبة القوارض على هيئة الفأر أكبر منه.

رَابِغُ : (انظر ألفبائيا)
§ر ب ق
رَبَقَ يَرْبُقُ / يَرْبِقُ رَبْقًا : ــ الرَّجُلُ الدابَّةَ : ربطها بالرِّبْق، فهي ربيقة ومَرْبُوقة.
رِبْقٌ ج أَرْبَاقٌ : حَبْلٌ فيه عدة عُرًى لربط الدواب، كلُّ عُرْوَةٍ فيها رِبْقَةٌ.
رِبْقَةٌ : ١ واحدة الرِّبق : «فَقَدْ خَلَعَ رِبْقَةَ الإسلام مِنْ عُنُقِهِ» [حديث]، يعني : عَقْد الإسلام، ويقال «رِبْقَةُ الاستعمار» أي قيده، ٢ ج رِبَاقٌ ورِبَقٌ : الكُرْبة «حَلَّ رِبْقَتُهُ»، أي فُرِّج عنه كربته.
§ر ب ك
أَرْبَكَ يُرْبِكُ إِرْبَاكًا : ــ ه : أوقعه في الحَيْرَةِ والاضطراب : «لقد أربكني قرارك المفاجئ».
اِرْتَبَكَ يَرْتَبِكُ ارْتِبَاكا : ١ ــ الشخصُ : تحير واضطرب وتتعتع في كلامه، ٢ ــ الصيدُ في الحِبالة : وقع فيها ولم يعرف كيف يتخلص منها.
إِرْبَاكٌ : مص أَرْبَكَ.
اِرْتِبَاكٌ : مص ارْتَبَكَ.
§ر ب ل
رِئْبَالٌ ج رَبَابِيلُ : رِئْبَالٌ (انظرها).
§ر ب ن
رُبَّانٌ ج رَبَابِينُ ورَبَابِنَةٌ : ١ ــ السفينةِ : رئيس الملاحين فيها : «قيادة السفينة في مياه المحيط تحتاج إلى رُبَّانٍ ماهر»، ٢ ــ كلِّ شيء : معظمه ومجموعه «أخذ بِرُبَّانِهِ»، أي أخذه جميعه.
§ر ب و / ر ب ي
رَبَا يَرْبُو رَبْوًا ورُبُوًّا راب (الرابي) مَرْبُوٌّ : ١ ــ المالُ : زاد ونما، ٢ ــ العجينُ : علا وانتفخ بعد اختماره، ٣ ــ الجرحُ : ورم، ٤ ــ الولدُ في بني فلان : نشأ وترعرع، ٥ ــ الشخصُ : أصابه الربو، ٦ ــ الرابيةَ : صعد فوقها.
رَبِيَ يَرْبَى رُبِيًّا راب (الرابي) : ــ الصغيرُ في بني فلان : ربا ونشأ فيهم.
رَبَّى يُرَبِّي تَرْبِيَةً مُرَبٍّ (المُرَبِّي) مُرَبًّى : ١ ــ الأبُ ابنه : هَذَّبه ونمى قواه الجسمية والعقلية والخلقية، ٢ ــ الشخصُ المالَ : نماه.
رَابَى يُرَابِي مُرَابَاةً مُرَابٍ (المرابي) مُرَابًى : ــ ه : عامله بالربا.
أَرْبَى يُرْبِي إِرْبَاءً مُرْبٍ (المُرْبِي) مُرْبًى : ١ ــ عليه : زاد «أربى على الخمسين»، «أربى عليه في العلم / في الكرم»، ٢ ــ الرجلُ : أخذ أكثر مما أعطى (تعامل بالربا)، ٣ ــ الشيءَ : نَمَّاه وزاده : ﴿يَمْحَقُ اللهُ الرِّبَا ويُرْبِي الصَّدَقَاتِ﴾ [قرآن].
تَرَبَّى يَتَرَبَّى تَرَبِّيًا مُتَرَبٍّ (المتربي) : ــ الولدُ : تعلم وتغذى وتثقف.
إِرْبَاءٌ : مص أَرْبَى.
تَرَبٍّ (التَّرَبِّي) : مص تَرَبَّى.
تَرْبَوِيٌّ : نسبة إلى التربية ◆ مُدَرِّسٌ تربوي : يجمع بين الدراسة الأكاديمية ومناهج التربية وطرق التدريس.
تَرْبِيَةٌ : ١ مص رَبَّى، ٢ [في علم النفس] : تنمية الوظائف الجسمية والعقلية والخلقية كي تبلغ كمالها ◆ أصول التربية (علم) : وظيفته البحث في أسس التعليم وقواعده، التربية (علم) : وظيفته البحث في أسس التنمية البشرية وعواملها وأهدافها الكبرى تربية بدنية /
